# 大文件批量上传性能优化方案（修正版）

## 审查结论

**原方案核心思路正确**，但存在以下**必须修复**的问题：
1. ❌ 并发控制逻辑缺失（会导致串行上传）
2. ❌ pendingQueue 使用数组+find，海量文件时 O(n) 性能差
3. ❌ 无虚拟滚动触底加载逻辑
4. ❌ File 对象永久持有，内存泄漏
5. ❌ 与原有文件夹上传方案脱节

---

## 修正后方案

### 核心架构

```
┌─────────────────────────────────────────────────────────────┐
│  UploadCoreStore                                            │
├─────────────────────────────────────────────────────────────┤
│  @observable displayQueue[]      ← 虚拟滚动数据源(≤30项)     │
│  pendingQueue = new Map()        ← 纯元数据(全部文件)        │
│  @observable queueStats{}        ← 统计信息(自动计算)        │
│  @observable concurrentCount = 0 ← 当前并发数                │
│  @observable isUploading = false ← 上传状态                  │
└─────────────────────────────────────────────────────────────┘
                            │
        ┌───────────────────┼───────────────────┐
        ▼                   ▼                   ▼
   虚拟滚动列表         并发上传池           统计面板
   (react-window)      (最大3并发)         (实时计算)
```

### 3. 文件夹选择处理（兼容原有方案）

```javascript
/**
 * 处理文件夹选择 - 修正版
 * 复用原有：文件夹结构创建、uniqueKey去重、tenant处理
 */
@action
async handleFolderSelect(files, targetFolderId, isPublic) {
  const tenantId = isPublic ? null : localStorage.getItem('tenant_id');
  
  // 【兼容原有】1. 防重复提交检查（复用原有逻辑）
  const topFolderName = files[0]?.webkitRelativePath?.split('/')[0] || 'unknown';
  const totalSize = files.reduce((sum, f) => sum + f.size, 0);
  const folderUniqueKey = `folder-${topFolderName}-${files.length}-${totalSize}-${targetFolderId}-${isPublic ? 'public' : 'private'}`;
  
  if (this.queueStore.uploadingUniqueKeys?.has(folderUniqueKey)) {
    message.warning(`文件夹 "${topFolderName}" 已在上传队列中`);
    return;
  }
  this.queueStore.uploadingUniqueKeys?.add(folderUniqueKey);

  // 2. 【修正】使用 Map 存储元数据，O(1)查询
  this.pendingQueue.clear();
  
  // 【兼容原有】3. 文件名校验 + 去重
  const seenKeys = new Set();
  let validIndex = 0;
  
  for (const file of files) {
    // 复用原有文件名校验
    const validation = validateFileName(file.name);
    if (!validation.valid) continue;
    
    // 生成 uniqueKey（复用原有逻辑）
    const uniqueKey = this.queueStore.generateUniqueKey(file, targetFolderId, isPublic);
    if (seenKeys.has(uniqueKey)) continue;  // 跳过重复
    seenKeys.add(uniqueKey);
    
    // 解析路径（复用原有逻辑）
    const relativePath = file.webkitRelativePath || file.name;
    const pathParts = relativePath.split('/');
    const folderPath = pathParts.slice(0, -1).join('/');
    
    // 【修正】存入 Map，避免数组find的性能问题
    this.pendingQueue.set(validIndex, {
      index: validIndex,
      file,                                    // ⚠️ 上传完成后必须释放
      fileName: file.name,
      fileSize: file.size,
      relativePath,
      folderPath,
      targetFolderId: folderPath ? null : targetFolderId, // 待创建文件夹后更新
      status: 'pending',
      uploadId: null,
      uniqueKey,
      errorMessage: null,
      progress: 0,
      addedToDisplay: false,
    });
    validIndex++;
  }

  // 【兼容原有】4. 创建文件夹结构
  const folderMap = await this.createFolderStructure(files, targetFolderId);
  this.folderMap = folderMap;
  
  // 更新每个文件的 targetFolderId
  for (const [index, item] of this.pendingQueue) {
    if (item.folderPath) {
      item.targetFolderId = folderMap.get(item.folderPath) || targetFolderId;
    }
  }

  // 5. 显示上传面板
  this.uploadUIStore?.showUploadPanel();
  this.isPaused = false;

  // 6. 【修正】加载首批数据到显示队列
  this.loadDisplayBatch(UPLOAD_CONFIG.MAX_DISPLAY_COUNT);
  
  // 7. 【修正】自动计算统计
  this.updateQueueStats();

  // 8. 【修正】启动并发上传池
  this.startConcurrentUpload();
}
```

### 4. 显示队列管理（分批加载）

```javascript
/**
 * 加载指定数量的待传文件到显示队列
 * 用于：初始加载、滚动触底加载
 */
@action
loadDisplayBatch(count) {
  const toAdd = [];
  let added = 0;
  
  // 遍历 Map 找 pending 状态的文件
  for (const [index, item] of this.pendingQueue) {
    if (item.status === 'pending' && !item.addedToDisplay) {
      const uploadId = generateUploadId();
      item.uploadId = uploadId;
      item.status = 'waiting';
      item.addedToDisplay = true;
      
      // 创建 observable 队列项
      const queueItem = {
        id: uploadId,
        name: item.fileName,
        fileSize: item.fileSize,
        status: 'waiting',
        percent: 0,
        speed: 0,
        folderPath: item.folderPath,
        targetFolderId: item.targetFolderId,
        isPublic: this.navigationStore?.isPublic,
        // 【保护】File 对象用非enumerable存储
        ...Object.defineProperty({}, 'file', {
          value: item.file,
          writable: true,
          enumerable: false,
          configurable: true
        }),
      };
      
      toAdd.push(queueItem);
      added++;
      
      if (added >= count) break;
    }
  }
  
  if (toAdd.length > 0) {
    this.displayQueue.push(...toAdd);
    // 添加到队列存储（复用原有逻辑）
    toAdd.forEach(item => this.queueStore.addToQueue(item, this.tenantId));
  }
  
  return added;  // 返回实际添加数量
}

/**
 * 自动计算统计信息
 * 【修正】基于 Map 实时计算，无需手动维护
 */
@action
updateQueueStats() {
  let waiting = 0, uploading = 0, completed = 0, error = 0;
  
  for (const item of this.pendingQueue.values()) {
    switch (item.status) {
      case 'pending':
      case 'waiting': waiting++; break;
      case 'uploading': uploading++; break;
      case 'completed': completed++; break;
      case 'error': error++; break;
    }
  }
  
  this.queueStats = {
    total: this.pendingQueue.size,
    waiting,
    uploading,
    completed,
    error,
  };
}
```

### 5. 并发上传池（核心修正）

```javascript
/**
 * 启动并发上传池
 * 【修正】独立控制并发数，与分批加载解耦
 */
async startConcurrentUpload() {
  if (this.isProcessingQueue) return;
  this.isProcessingQueue = true;
  
  while (this.pendingQueue.size > 0 && !this.isPaused) {
    // 等待并发槽位
    while (this.concurrentCount >= UPLOAD_CONFIG.CONCURRENT_LIMIT) {
      if (this.isPaused) {
        this.isProcessingQueue = false;
        return;
      }
      await sleep(100);  // 等待100ms再检查
    }
    
    // 获取下一个待上传文件
    const nextItem = this.getNextPendingItem();
    if (!nextItem) break;  // 没有更多待传文件
    
    // 并发数+1
    this.concurrentCount++;
    nextItem.status = 'uploading';
    
    // 异步执行上传（不await，实现并发）
    this.executeUpload(nextItem).finally(() => {
      this.concurrentCount--;
      this.updateQueueStats();
      // 【修正】上传完成后释放 File 对象
      this.releaseFileObject(nextItem);
    });
  }
  
  this.isProcessingQueue = false;
}

/**
 * 获取下一个待上传文件
 * 【修正】优先从 displayQueue 中取 waiting 状态的项
 */
getNextPendingItem() {
  // 1. 优先找 displayQueue 中 waiting 状态的
  for (const [index, item] of this.pendingQueue) {
    if (item.status === 'waiting') {
      return item;
    }
  }
  
  // 2. 如果没有，从 pending 中加载更多
  if (this.loadDisplayBatch(UPLOAD_CONFIG.CONCURRENT_LIMIT) > 0) {
    return this.getNextPendingItem();  // 递归获取
  }
  
  return null;
}

/**
 * 执行单个文件上传
 * 【兼容原有】复用 fileUploadStore.uploadFileToFolder 逻辑
 */
async executeUpload(item) {
  try {
    // 更新显示队列状态
    this.updateDisplayItemStatus(item.uploadId, 'uploading');
    
    // 【兼容原有】调用现有上传逻辑
    await this.fileUploadStore.uploadFileToFolder(
      item.file,
      item.targetFolderId,
      item.folderPath,
      this.navigationStore?.isPublic
    );
    
    // 标记完成
    item.status = 'completed';
    this.updateDisplayItemStatus(item.uploadId, 'completed');
    
  } catch (error) {
    item.status = 'error';
    item.errorMessage = error.message || '上传失败';
    this.updateDisplayItemStatus(item.uploadId, 'error', error.message);
  }
}

/**
 * 更新显示队列中的状态
 */
@action
updateDisplayItemStatus(uploadId, status, errorMessage = null) {
  const item = this.displayQueue.find(i => i.id === uploadId);
  if (item) {
    item.status = status;
    if (errorMessage) item.errorMessage = errorMessage;
  }
  // 同时更新 queueStore
  this.queueStore.updateUploadItem(uploadId, { status, errorMessage });
}

/**
 * 【修正】释放 File 对象，防止内存泄漏
 */
releaseFileObject(item) {
  if (item.status === 'completed' || item.status === 'error') {
    item.file = null;
    // 同时清理 displayQueue 中的引用
    const displayItem = this.displayQueue.find(i => i.id === item.uploadId);
    if (displayItem) {
      displayItem.file = null;
    }
  }
}
```

### 7. 批量操作（取消/重试/清理）

```javascript
/**
 * 批量取消所有上传
 */
@action
cancelAllUploads() {
  // 1. 标记暂停
  this.isPaused = true;
  
  // 2. 取消所有上传中的请求
  for (const item of this.displayQueue) {
    if (item.status === 'uploading' || item.status === 'waiting') {
      this.queueStore.cancelUpload(item.id);
      item.status = 'cancelled';
    }
  }
  
  // 3. 清理pendingQueue
  for (const item of this.pendingQueue.values()) {
    if (item.status === 'pending' || item.status === 'waiting') {
      item.status = 'cancelled';
    }
  }
  
  // 4. 释放所有 File 对象
  this.releaseAllFileObjects();
  
  this.updateQueueStats();
}

/**
 * 重试所有失败项
 */
@action
retryAllFailed() {
  for (const item of this.pendingQueue.values()) {
    if (item.status === 'error') {
      item.status = 'waiting';
      item.errorMessage = null;
      item.progress = 0;
    }
  }
  
  this.updateQueueStats();
  this.startConcurrentUpload();  // 重新启动上传
}

/**
 * 清理已完成项（释放内存）
 */
@action
clearCompleted() {
  // 1. 从 pendingQueue 删除 completed 项
  for (const [index, item] of this.pendingQueue) {
    if (item.status === 'completed') {
      this.pendingQueue.delete(index);
    }
  }
  
  // 2. 从 displayQueue 删除
  this.displayQueue = this.displayQueue.filter(i => i.status !== 'completed');
  
  // 3. 从 queueStore 删除
  this.queueStore.clearCompleted();
  
  this.updateQueueStats();
}

/**
 * 释放所有 File 对象（防止内存泄漏）
 */
releaseAllFileObjects() {
  for (const item of this.pendingQueue.values()) {
    item.file = null;
  }
  for (const item of this.displayQueue) {
    item.file = null;
  }
}
```

5. **空间类型区分**：私密空间用 📁 蓝色，公共空间用 ☁️ 金色
