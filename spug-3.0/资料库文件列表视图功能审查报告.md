## 三、功能缺陷与问题

### 3.1 P0级问题（严重）

#### 问题1：分页逻辑缺陷

**位置**: `spug_api/apps/document/views/folder/views.py` 第97-141行

**问题描述**: 分页逻辑采用"文件夹优先"策略，当文件夹和文件混合分页时可能出现异常

```python
# 问题代码
folders = folders_query[offset:offset + page_size]
folder_count = folders_query.count()  # 重复查询
```

**风险**: 
1. 两次查询之间数据可能变化，导致分页不一致
2. `has_more`计算逻辑基于`max(total_folders, total_files)`，可能不准确

**修复建议**:
```python
# 使用统一查询和缓存
folder_count = folders_query.count()
folders = folders_query[offset:offset + page_size]
# 避免重复count查询
```

---

#### 问题2：批量删除权限校验不完整

**位置**: `spug_web/src/pages/document/Explorer/hooks/useFileOperations.js` 第62-123行

**问题描述**: 批量删除时仅在弹窗确认，未在前端逐个校验权限

```javascript
// 问题：selectedItems可能包含用户无权限删除的项目
const selectedItems = selectedRowKeys.map(key =>
  items.find(i => i.key === key)
).filter(Boolean);
```

**风险**: 用户可以通过多选绕过单条权限检查删除他人文件

**修复建议**:
```javascript
// 添加前置权限过滤
const selectedItems = selectedRowKeys
  .map(key => items.find(i => i.key === key))
  .filter(item => canEditItem(item, isPublic, isAdmin, currentUserId));
```

### 3.2 P1级问题（重要）

#### 问题4：搜索防抖实现不规范

**位置**: `spug_web/src/pages/document/Explorer/hooks/useExplorerState.js` 第146-155行

**问题描述**: 使用`useRef`保存防抖函数，但依赖更新可能不及时

```javascript
const handleSearchDebounced = useRef(debounce(handleSearch, 300)).current;
// debounce依赖未正确声明
```

**风险**: `handleSearch`依赖变化时，防抖函数可能使用旧的闭包

**修复建议**:
```javascript
const handleSearchDebounced = useMemo(
  () => debounce(handleSearch, 300),
  [handleSearch]
);
```

#### 问题5：表格排序在前端完成，大数据量性能差

**位置**: `spug_web/src/pages/document/Explorer/index.js` 第316-364行

**问题描述**: 排序逻辑在`useMemo`中前端完成，每次排序都重新排序全部数据

```javascript
const sortedData = useMemo(() => {

```

**风险**: 当文件夹内文件超过1000条时，排序卡顿

**建议**: 后端支持排序参数，前端仅做辅助排序

### 8.1 修复后的批量删除权限校验

```javascript
// useFileOperations.js
const handleDeleteSelected = useCallback(async (selectedRowKeys, items) => {
  const isAdmin = localStorage.getItem('is_supper') === 'true';
  const currentUserId = parseInt(localStorage.getItem('id') || '0');
  
  // 添加权限过滤
  const selectedItems = selectedRowKeys
    .map(key => items.find(i => i.key === key))
    .filter(item => {
      if (!item) return false;
      // 公共空间非管理员只能删除自己的
      if (isPublic && !isAdmin && item.created_by_id !== currentUserId) {
        return false;
      }
      return true;
    });
  
  if (selectedItems.length === 0) {
    message.warning('没有可删除的项（可能无权限）');
    return;
  }
  
  // 如果有过滤掉的项，提示用户
  const filteredCount = selectedRowKeys.length - selectedItems.length;
  
  Modal.confirm({
    title: '批量删除',
    content: `确定要删除选中的 ${selectedItems.length} 项吗？${filteredCount > 0 ? `（已过滤 ${filteredCount} 项无权限内容）` : ''}`,
    // ...
  });
}, [isPublic, refresh, onFolderChange]);
```
