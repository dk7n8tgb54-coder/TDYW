# 台账模板简化：删除适用系统、正常范围、数值上下限、标准说明；必填默认勾选

## 语义定稿（含连带机制）
- **模板不再绑定系统**：模板适用于任何系统；录入时每条目显式选系统（工作台/弹窗已有系统下拉，改为必选），"只选模板按适用系统自动展开"模式移除。
- **模板项目仅剩字段**：项目名称、录入类型（正常/不正常、数字/文本）、单位（数字/文本行）、必填（默认勾选）、执行范围（仅周月维护）。标准/说明、正常范围、数值下限/上限删除。
- **数值范围自动判定机制整体移除**（上下限删除后失效）：后端 auto_judge_number_result、自动建议、超限不参与批量确认、修正原因校验、`is_auto_judged`/`correction_reason` 字段；前端自动建议与修正原因输入。结果全部手动选择，批量确认正常保留（仅保留"已确认异常且填说明的不动"规则）。
- 数字/文本行纯数字仍落 `value_number`（数据整洁，不再参与判定）。
- `is_required` 仅改新建默认值，历史数据不回填。

## 迁移 0017（equipment_lifecycle，一迁移承载本批简化）
- RemoveField `OperationLedgerTemplate.applicable_systems`（Django 同步 drop through 表 `tdyw_el_ledger_template_systems`）
- RemoveField `OperationLedgerTemplateItem`: standard、normal_range、number_min、number_max
- RemoveField `OperationLedgerItem`: standard_snapshot、normal_range_snapshot、number_min、number_max、is_auto_judged、correction_reason
- AlterField `OperationLedgerTemplateItem.is_required` default=True
- 生成后人工审查仅含上述操作；历史明细已存快照值随列删除不可恢复（数据量小）
