# 系统升级管理挂接设备全生命周期管理

目标：① 升级记录/升级方案与系统档案（`LifecycleSystem`）建立正式关联，完全对齐故障管理与运维台账的挂接模式（FK PROTECT + 快照 + 可用性校验 + 按系统查询端点 + 系统详情页签 + 系统履历 + 删除保护）；② 菜单移入「设备全生命周期管理 > 运行维护 > 系统升级管理（子分组，三个子项保留）」；③ 彻底删除自建「升级系统」字典表。

## 一、菜单（spug_web/src/routes.js）
- 「系统升级管理」子分组（routes.js:110-114）从「设备管理」组移入「设备全生命周期管理 > 运行维护」（routes.js:91-99）下，作为嵌套子分组；升级表单/升级方案/统计报表三项路径与组件不变。Sider.js 递归渲染（:16-25, :60-72）天然支持四级，无需改组件。
- 「设备全生命周期管理」与「运行维护」的 auth 追加 `|upgrade.upgrade.view|upgrade.statistics.view`；「设备管理」组删掉升级码与该子分组。权限码字符串不变，已授权角色不受影响。隐藏路由 `/upgrade/workbench/:id` 不动。

## 二、模型与迁移
**upgrade 0022（手写迁移，避免 autodetector 把 RenameField 误判为删列重建）**：
- `UpgradeRecord`：RenameField `system`(CharField)→`system_name`(100, default='')，历史文本保留为快照；AddField `system` FK→`equipment_lifecycle.LifecycleSystem`，PROTECT，related_name='upgrade_records'，null=True（仅历史未匹配行允许空，新记录校验强制必选）；AddField `system_code`(50)/`system_location`(200) 快照；AddIndex (tenant_id, system) 显式命名；RunPython 回填：租户内按名称不分大小写匹配 LifecycleSystem，匹配上写 FK+快照，匹配不上 FK 置空保留文本；反向 no-op。
- `UpgradeTemplate`：RemoveField 旧 `system` 文本列 + AddField 同名 FK（related_name='upgrade_templates', null=True）+ 同名回填（方案是可编辑预设，不做快照）。
- DeleteModel `UpgradeSystem`（用户已确认彻底删除）。
- dependencies 指向 equipment_lifecycle 最新迁移。

**equipment_lifecycle 0015**：`EVENT_TYPE_VALUES` 增 `upgrade`、`EVENT_ACTION_VALUES` 增 `rollback`；同步 `SystemEvent` choices 与 Meta CheckConstraint（先删旧约束再建新）；加 `EVENT_UPGRADE` 常量。

## 三、服务层与校验（对齐 fault_views.py 模式）
- `_get_active_system_for_user`（租户+is_active）与 `_validate_record_system`：新建/换绑只允许可用系统，编辑未变更允许保留停用系统（fault_views.py:135-150 同款）。
- record_service：create 在事务内写快照 + 同事务 `record_system_event(event_type='upgrade', action='create')`；update 变更系统时重写快照（fault_views.py:369-371 同款）；幂等键改用 system id。
- status_log_service.add_log：`complete`/`rollback` 主线状态变更时同事务写履历事件。
- `get_filter_options` systems 改为系统档案可用系统对象列表；新增 `/api/upgrade/candidate-systems/`（对齐 fault candidate-systems，@auth upgrade.upgrade.view）；列表筛选改 system_id；statistics by_system 改按 system_name 快照分组。
- serializers 输出 `system_id/system_code/system_name/system_location`（方案输出 system_id/system_name）；exporters 导出列同步。
- legacy.py 旧接口兼容：`system` 参数映射到 `system_name` 文本过滤，保持旧契约。
- 删除 views/systems.py、urls 中 systems/ 三条路由、constants.py 死常量 PRESET_SYSTEMS。
