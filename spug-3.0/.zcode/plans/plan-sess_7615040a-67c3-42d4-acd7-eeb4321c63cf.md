## 后端改动（ledger_services.py，零迁移）
1. `resolve_item_result(payload)`（当前 L230-237，并行会话已改为"纯手选必填"）：改为**结果可缺省**——
   - 显式传 result：仍校验合法性后采用（API 兼容，存量测试夹具不受影响）；
   - 未传：**派生默认**——choice 行 `value_text == '不正常'`（后端加常量，对齐前端 `NORMAL_ABNORMAL_CHOICES`）→ `abnormal`，其余一律 `normal`。否则会出现"填写值=不正常、结果=正常"的数据矛盾，且异常链（转工单/异常角标）彻底死亡；此派生规则是数据自洽的最小兜底，如不需要可砍（3 行）。
2. `validate_item_result_rules`（当前 L240-246）：**删除"异常项必须填写异常说明"**（L242-243）；保留 force 标志规则。
3. `_apply_item_edits`（当前 L534-557）：**编辑保护**——仅当 payload 显式带 result 或填写值发生变化时才重算 `item.result`；否则保留原结果（防止简化后的编辑把历史结果冲成默认值）。abnormal_desc/na_reason/onsite_action/executor_name 已是 `'x' in row` 才更新，前端不再传即自然保留。
4. create 路径 `_build_item_instance` 无需另改（resolve 改后自动派生）。
5. 不动：correct_ledger、confirm_normal、CSV 导出、详情视图、`ITEM_EDITABLE_FIELDS`、模型层。
