## 目标

新增巡检/周月/季维护台账时，消除"逐个系统先选系统再选模板"的重复操作（用户科室 10+ 套系统）。改造为**模板先行**：模板条目允许只选模板不选系统，生成预览时后端按模板的适用系统自动展开为全部系统的明细。

## 附带修复的关联缺陷（同链路，一并修）

前端 submit 的 entries 分组只有 `{system_id, items}`，**丢了 template_id**（LedgerForm.js:360-393，rows 上也没有该字段）。导致后端 `_build_item_instance` 走 manual 快照分支：模板来源明细被存成 `is_temporary=True`、`template_item` 外键为空、无模板名快照——与"模板来源明细保存全量快照"的设计（models.py:1155-1160）相悖。本次让 rows 携带 `template_id`，提交时按 `(system_id, template_id)` 分组带上，模板明细落库走真正的模板快照分支。后端 create/update 已原生支持 entry 级 template_id，无需改服务层。

## 后端改动（无迁移、无模型变更、无路由/权限变更）

### 1. `ledger_services.py`
- **从 `get_template_for_entry`（L145-158）抽出共用校验** `get_active_template(user, template_id, ledger_type, maintenance_cycle)`：模板存在（加 `apply_tenant_filter` 租户过滤，堵住现有跨租户 template_id 引用口子）、启用、类型/周期匹配，错误文案保持原样；`get_template_for_entry` 改为调用它并追加 `applies_to_system` 校验。三处调用方（`_build_item_instances`、`update_ledger`、`preview_entries`）同步传 user。
- **`preview_entries`（L608-650）支持模板条目展开**：
  - entries 分为显式条目（有 system_id，走现有逻辑）与模板条目（只有 template_id）；两者都不是的报"台账系统条目格式不正确"。
  - 模板条目：取 `get_active_template` → 展开系统 = `template.applicable_systems` 中 **当前用户可见（apply_tenant_filter）且 is_active** 的系统，**排除已在显式条目中出现的系统**（显式优先）；同一模板条目重复出现去重；展开系统按 system_code 排序。
  - 展开条目的 items 生成逻辑与现有完全一致（is_active + matches_cycle 过滤、client_key=`system.id-tpl_item.id` 天然唯一）。
  - 全部展开后为空 → "模板未包含可用的适用系统"；响应结构不变（`[{system, template, items}]`）。
- `create_ledger` / `update_ledger` / `_build_item_instances` 业务逻辑不动（前端提交的 entries 永远带 system_id）。

### 2. `ledger_views.py`
- `LedgerTemplateAvailableView`（L249-275）：`system` 参数改为可选。带 system 时行为不变；不带时返回该类型全部启用模板，每个附加 `applicable_systems: [{id, system_code, name}]`，items_count 的周月 scope 逻辑保留。

## 前端改动（`spug_web/src/pages/equipmentLifecycle/ledger/LedgerForm.js`）

- **模板条目区**：挂载时 `fetchTemplates()` 一次（不带 system 参数），模板数据含 applicable_systems；模板下拉常开，选中系统后按 applicable_systems 客户端过滤（替代现有逐系统 fetch + templateOptions 缓存）；系统下拉 placeholder 改"全部适用系统（可不选）"，可清空。
- **提示**：只选模板未选系统时显示"将展开全部适用系统（N 套）"；模板适用系统为空时显示"该模板未绑定适用系统"。
- **generatePreview**：发送 entries 放宽为"有 template_id 即可"（system_id 可缺省）；无有效条目时提示语相应调整。
- **rows 携带模板来源**：makeRow 增加 `template_id` 字段；预览回填时写入 `entry.template.id`；提交分组键改为 `(system_id, template_id||'')`，entry 带 template_id（无则省略）。手加的临时行照旧无 template_id，与模板行自然分成不同 entry（后端本就允许同系统多 entry）。
- 编辑模式不受影响：模板条目区在编辑模式隐藏，回填行有 id，分组行为与现在一致。
