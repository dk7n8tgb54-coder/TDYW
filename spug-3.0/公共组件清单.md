## 一、导出组件

| 文件 | 功能 | 使用方 |
|------|------|--------|
| `libs/export_utils.py` | Excel 导出工具：`build_excel_response()` / `check_export_limit()` / `build_export_error_response()`，统一工作簿创建/表头样式/列宽/中文文件名编码 | fault / device / interference / upgrade / runlog / duty / logs 共 7 个模块 |
| `libs/font_manager.py` | PDF 中文字体管理：`FontManager` 按 SimHei 优先级（容器内嵌 -> 项目内嵌 -> 系统字体）注册到 reportlab，全局缓存注册状态 | runlog / duty / device / department_duty_log 共 4 个 `pdf_export.py` |
| `libs/fonts/simhei.ttf` | SimHei 中文字体文件 | 由 `font_manager.py` 加载 |

### 导出组件使用模式

**Excel 导出**（统一走 `libs/export_utils.py`）：

```python
from libs.export_utils import build_excel_response, check_export_limit, build_export_error_response

# 1. 查询数据
qs = apply_tenant_filter(Model.objects.all(), request.user)
# ... 筛选 ...

# 2. 上限检查
count, error_resp = check_export_limit(qs)
if error_resp:
    return error_resp
if count == 0:
    return build_export_error_response('当前筛选条件下没有可导出的数据')

# 3. 序列化 + 导出
records = qs.select_related('created_by', 'updated_by')
rows = [obj.to_dict() for obj in records.iterator()]
return build_excel_response(filename, sheet_name, EXCEL_COLUMNS, rows)
```

**PDF 导出**（各模块独立 `pdf_export.py`，共用 `font_manager.py`）：

```python
from libs.font_manager import FontManager, FONT_NAME
# font_manager 自动注册 SimHei，reportlab 直接使用 FONT_NAME
```

## 八、分页与日期过滤组件（2026-07-29 新增）

| 文件 | 功能 | 使用方 |
|------|------|--------|
| `libs/pagination.py` | 统一分页工具：`paginate(request)` 解析页码参数 + `paginate_response(qs, page, page_size, serialize_fn, items_key)` 分页查询+序列化，自动边界约束（page>=1, page_size<=200），类型安全（非法输入回退默认值） | fault / duty / runlog / logs / interference / device / contract_agreement / regulation 共 8 个模块 12 个视图 |
| `libs/date_utils.py` | 统一日期工具：`date_range_filter(qs, field, start, end)` 索引友好的日期范围过滤（__gte/__lt，禁用 __date/__startswith）+ `today_range()` / `month_range()` 返回 [start, end) datetime 元组 + `parse_date()` / `parse_date_or_none()` / `date_to_datetime()` / `date_range()` 辅助函数 | home / runlog / logs / duty 共 4 个模块 8 处 |

### 分页使用模式

```python
from libs.pagination import paginate, paginate_response

# 列表视图 3 行搞定
page, page_size = paginate(request)  # 默认 page_size=20, max=200
data = paginate_response(qs, page, page_size, serialize_fn=lambda x: x.to_view(), items_key='records')
return json_response(data)
# data = {"total": 100, "page": 1, "page_size": 20, "records": [...]}

# 自定义默认值
page, page_size = paginate(request, default_page_size=50, max_page_size=100)
```

### 日期范围过滤使用模式

```python
from libs.date_utils import date_range_filter, today_range, month_range

# 1. 字符串日期范围过滤（索引友好，走 B-tree）
qs = date_range_filter(qs, 'created_at', start_date, end_date)
# 纯日期 'YYYY-MM-DD' -> __lt: dt+1day（含当天所有记录）
# 含时间 'YYYY-MM-DD HH:MM:SS' -> __lte: dt（精确到秒）

# 2. 今日范围（用于 Dashboard 等场景）
start, end = today_range()
qs = qs.filter(created_at__gte=start, created_at__lt=end)

# 3. 本月范围
start, end = month_range()
qs = qs.filter(created_at__gte=start, created_at__lt=end)
```

### 设计要点

- **`date_range_filter` 格式规则**：纯日期（len <= 10）-> `__lt: dt + 1天`（含当天）；含时间 -> `__lte: dt`（精确到秒）
- **禁用 `__date` / `__startswith`**：在 DateTimeField 上绕过 B-tree 索引，强制全表扫描
- **`paginate()` 类型安全**：非法输入（`page=abc`）回退默认值，不抛 500
