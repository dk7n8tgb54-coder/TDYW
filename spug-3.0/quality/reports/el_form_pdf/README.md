## 实际渲染检查结论（逐项）

- 纸张尺寸：pypdf mediabox = A4 纵向/横向；X-El-Pdf-Paper 头一致；
- 内容边距：上 16mm / 左右 14mm / 下 18mm，正文最低文字 770.8pt
  （页高 841.9pt − 18mm=51pt 边距界 790.9pt 之内），页脚绘制于下边距区；
- 分页：内容自动分页，行/明细条目不跨页裁切，分组标题随表格/首条明细
  整体移动（无"页底只剩分组标题"），长表按行切页；
- 中文字体：Noto Sans CJK 渲染清晰；文字层真实可选择、可搜索（非截图）；
- 矩阵：行列对照完整，表头行跨页重复；异常说明与判定值同单元格；
- 空值语义：样张=「待填写」，真实台账=「未填写」，绝不伪装已填。

## 过程中发现并修复的版式缺陷

1. Chromium 打印在 `prefer_css_page_size` 下忽略 margin 参数（内容全出血、
   与页脚重叠）→ 公共适配器 libs.html_pdf 新增显式纸张参数
   `paper={'format','landscape'}`，数字表单路线使用该模式；
2. HTML 携带 `@page { margin: 0 }` 时 CSS 会覆盖打印 margin 参数 →
   数字表单 HTML 不再携带任何 @page 规则，纸张/边距以打印参数为唯一事实；
3. 启用页脚时 Chromium 默认同时渲染页眉（日期+标题）→ worker 显式置空页眉；
4. 信息表自动布局下列宽被长用户名挤压（逐字换行）→ `table-layout: fixed`
   + 全列显式宽度。
