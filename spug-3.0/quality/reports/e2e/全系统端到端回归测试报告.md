## 15. 后续维护方法

1. **运行测试**: `cd quality/e2e && npx playwright test`
2. **新增测试**: 在 `tests/` 对应目录下新增 `.spec.js` 文件
3. **新增 Page Object**: 在 `pages/` 下新增,遵循现有模式
4. **环境配置**: 修改 `environments/local.example.env` 后复制为 `.env`
5. **浏览器扩展**: `npx playwright install firefox webkit` 后在 config 中添加 project
6. **CI 集成**: 设置 `CI=true` 环境变量,Playwright 自动禁用 `.only`
7. **报告查看**: `npx playwright show-report ../reports/e2e/artifacts/html-report`
