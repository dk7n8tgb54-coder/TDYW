## 4. 结果与发现

### 4.1 异常与容错（27 例，全部通过）

覆盖并验证的真实行为契约：

- **非法参数/缺失数据**：系统、运行处置记录、台账、Excel 模板、配置的不存在 ID 增删改查一律返回业务错误（HTTP 200 + error），**无一例 500**；非法分页（page=0/负数/非数字、page_size 超限）被夹紧到 [1,200]；特殊字符关键词（引号/百分号/反斜杠）不破坏列表查询。
- **重复提交**：记录创建同 `client_token` 双提交返回同一条记录、库中仅一条（幂等命中）；本期台账生成重复调用不产生重复台账（幂等壳 + 槽位唯一约束复核）。
- **状态机误用**：未跟进（recorded）直接"完成跟进"被拒；重复完成、作废后完成、重复作废、故障记录上再认定故障等非法流转全部拒绝且**数据库状态不变**（逐例 refresh_from_db 复核）；作废必须填原因。
- **物理文件缺失**（模板/版本 xlsx 被删）：模板 PDF 预览、台账 Excel/PDF 导出均降级为业务错误，**不 5xx、不泄露路径**；其他模板的台账导出**不受影响**（局部失败未扩大）；台账列表在模板文件缺失时正常返回。
- **附件物理文件缺失**：下载降级为业务错误；软删除照常落库（`is_deleted=True`），文件清理失败走 `is_pending_clean` 补偿设计。
- **单条脏数据不扩散**：200KB 超长描述记录入库后，列表/统计/待办接口均正常；emoji 等增补平面字符全链路保真。
- **停用系统口径**：停用后不出现在候选系统，且直接引用其创建记录被后端拒绝（`所属系统不存在、已停用或无权限`）。

### 4.2 安全（24 例，全部通过）

- **跨租户读写**：系统（详情/更新/删除/停用/记录页签/升级记录页签）、运行处置记录（详情/进展/完成/附件上传下载删除）、台账（详情/作废/完成/列表泄露）、Excel 模板（详情/绑定/发布/删除/列表泄露）——另一租户持**全量权限**访问一律被拒，且**数据库状态零变化**（未产生跨租户写入）。
- **附件跨模块越权**：`upgrade` 模块附件经运行处置记录端点下载被拒（module/object_type 强校验）；记录附件经台账端点删除被拒；同租户同模块同对象的正常删除作为对照组通过。
- **权限后端独立校验**：无权限用户访问 6 类列表全部被拒；仅查看用户对系统/记录/台账/升级创建及附件上传全部被拒（未登录、无效令牌同样拒绝）。
- **上传校验**：非 xlsx 内容伪造 `.xlsx` 上传被拒且不落库；缺文件上传被拒。
- **敏感信息泄露**：404/业务错误与"文件丢失"错误的响应体均不含 Traceback、容器内绝对路径、settings 路径等内部信息。
- **超管 vs 普通用户**：普通用户跨租户读取被拒；超管按设计放行（与 AGENTS.md"超管例外"一致），已作为契约固化（若未来收紧超管策略，该用例会明确报错提示）。

### 4.3 跨模块回归契约（8 例，全部通过）

- **系统档案 ↔ 系统升级管理**：经 API 创建的升级记录出现在系统详情"升级记录"页签（total=1 且 ID 一致）；删除升级记录后页签同步移除；对不存在系统创建升级被拒。
- **模板发布版本不可变 × 台账版本快照**：v1 创建的台账在 v2 发布后详情仍引用 v1；`available` 接口只暴露当前版本；绕过前端用旧版本 ID 创建台账被后端独立拒绝。
- **台账异常明细转设备故障闭环**：草稿台账不能转故障（先完成填写才可）；转换生成统一主表故障记录（`record_type=fault`、`source_ledger_item` 来源外键落库）；默认"部件故障但不影响系统运行"——系统健康状态保持 normal、`impact_status` 为空；同一明细二次转换被拒（再处置拦截）。
