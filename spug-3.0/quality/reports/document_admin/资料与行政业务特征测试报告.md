## 二、页面、API、View、Model、表关系

### RadioLicense
- URL: `/radio-license/` (list/create/delete), `/radio-license/<pk>/` (detail/edit)
- Model: `RadioLicense` (tdyw_radio_license)
- 无 is_deleted 字段（回收站已移除，硬删除）
- 有 tenant_id（TenantModelMixin）
- status 是 DB 字段（normal/expiring/expired）

### StationFrequencyApproval
- URL: `/radio-license/approvals/`
- Model: `StationFrequencyApproval` (tdyw_station_frequency_approval)
- 与 RadioLicense 独立（无 FK 关系）

### ContractAgreement
- URL: `/contract-agreement/`
- Model: `ContractAgreement` (tdyw_contract_agreement)
- contract_type 有 CheckConstraint: device_purchase/info_access/service_guarantee
- 无 is_deleted（硬删除）
- 有 tenant_id

### DocumentFilePrivate / DocumentFolderPrivate
- URL: `/document/folder/`, `/document/file/`
- 无 is_deleted（硬删除）
- 有 tenant_id（Private 类）
- DocumentFilePrivate.delete() 检查路径在 storage/documents/ 下

### DocumentFolderPublic / DocumentFilePublic
- 无 tenant_id（公共空间跨租户共享）

### DocumentTransfer
- 有 tenant_id, transfer_type (UPLOAD/DOWNLOAD/COPY), status (PENDING/UPLOADING/MERGING/COMPLETED/FAILED/CANCELED)

### DocumentSystemFolder
- code 唯一, folder PROTECT, 无 tenant_id（全局）

### Regulation
- URL: `/regulation/`
- **无 tenant_id**（全局共享，所有租户可见）
- 无 is_deleted（硬删除）
- 使用 RegulationAttachment（非 EvidenceAttachment）
- 权限编码: document.regulation.*

### EvidenceAttachment
- 多态设计: module (CharField, 无白名单), object_id (CharField, 无 FK)
- 有 tenant_id, is_deleted (软删除)
- 有 file_hash_sha256, file_hash_md5

|---|---|---|
| RadioLicense | EvidenceAttachment (module=radio_license) | evidence 存储 |
| ContractAgreement | EvidenceAttachment (module=contract_agreement) | evidence 存储 |
| Document | DocumentFilePrivate/Public (内置) | storage/documents/ |

## 四、当前业务规则摘要

1. 执照/合同/批复使用 tenant_id 隔离，无软删除（硬删除）
2. 规章无 tenant_id（全局共享）
3. 文档私人空间有 tenant_id，公共空间无 tenant_id
4. 系统目录无 tenant_id（全局共享）
5. EvidenceAttachment 多态设计，无 FK 约束，删除业务对象后附件记录残留
6. Celery 到期扫描任务已注册到 Beat Schedule，重复执行幂等
7. DocumentFilePrivate.delete() 检查文件路径在安全区域内
