# 覆盖缺口说明

## 环境限制导致的未覆盖场景

### 1. kkFileView 预览服务
- **未覆盖**: 文件预览功能（kkFileView 正常/失败/超时）
- **原因**: 测试环境未运行 kkFileView 容器
- **影响**: 预览地址生成、回源地址、降级行为未验证

### 2. Celery Worker 异步执行
- **未覆盖**: 分片上传合并的异步执行、清理任务的异步执行
- **替代**: 使用 `.apply()` 同步执行任务函数验证业务逻辑
- **影响**: 任务队列调度、重试机制、超时处理未验证

### 3. Redis 缓存
- **未覆盖**: 权限缓存刷新、磁盘用量缓存
- **原因**: 测试环境 Redis 配置不确定

### 4. 物理文件存储
- **未覆盖**: storage/documents/ 目录下的真实文件操作
- **原因**: 测试使用临时目录，文件路径不在安全区域内
- **影响**: 文件删除、复制、移动的真实物理副作用未完整验证

### 5. 分片上传完整流程
- **未覆盖**: 前端分片上传 -> 后端合并的完整 HTTP 流程
- **覆盖**: DocumentTransfer 状态机转换、数据库记录验证
- **建议**: 后续在集成测试环境验证完整上传链

### 6. 前端测试
- **未覆盖**: 前端页面、表单、状态展示
- **原因**: 项目无稳定前端测试框架
- **建议**: 后续建立 Playwright 端到端测试

## 业务含义不明确导致的未覆盖场景

### 1. 执照编辑API返回error
- API POST /radio-license/ with id 编辑时可能返回 error
- 原因待调查（可能是幂等性检查或字段校验）

### 2. 长期合同 valid_end_date 空值
- 合同 valid_end_date 传空字符串时行为不确定

### 3. 文件夹重名API校验
- API 层可能未校验唯一性（DB 层有 UniqueConstraint）

### 4. Regulation 无 tenant_id
- 可能是业务设计（规章全局共享），也可能是遗漏
