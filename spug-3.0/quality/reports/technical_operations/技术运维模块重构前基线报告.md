## 3. 当前模块架构概览

### 3.1 设备模块（device）

- **DeviceResume**: 设备档案/台账，软删除，租户隔离
  - device_sn: 设备编号（租户内唯一）
  - responsible_user_name: 文本字段（非外键）
  - current_status: CharField（'1'-'5'）
  - 无资产编号字段
  - 无正式系统关系外键

- **DeviceEvent**: 设备事件/履历
  - device_resume_id: **IntegerField**（非外键！）
  - device_name/device_sn: 冗余文本副本
  - 事件改名后不会自动更新
  - 手工创建，非自动生成

### 3.2 故障模块（fault）

- **FaultRecord**: 故障记录
  - system_name/device_code: 文本字段（非外键到设备表）
  - handler/recorder: 文本字段（非外键到用户表）
  - 无外键关联到 DeviceResume

- **FaultPart**: 故障部件
  - 无外键关联到 FaultRecord
  - system_name: 文本字段
  - name: 部件名称（无资产编号）
  - 无独立部件实例表

### 3.3 系统升级模块（upgrade）

- **UpgradeRecord**: 升级记录
  - system: 文本字段（非外键到 UpgradeSystem）
  - owner: 文本字段（非外键到用户表）
  - 无外键关联到设备表

- **UpgradeSystem**: 系统候选项（字典表）
  - 有 tenant_id（租户级别字典，非全局主数据）
  - 有 is_active/sort_order 字段
  - 删除后升级记录中的 system 文本不变

- **UpgradeRecordStep/UpgradeStatusLog**: upgrade_id 为 IntegerField（非外键）

### 3.4 干扰模块（interference）

- **Interference**: 干扰记录
  - 无外键关联到设备表
  - frequency: 文本字段
  - report_dept: 文本字段
  - 复杂状态流（draft/submitted/reviewed/reported/handled/closed/voided）
  - 有 snapshot_hash 字段

### 3.5 告警模块（alert）

- **Alert**: 告警记录
  - **无 tenant_id**（全局数据）
  - 使用 ModelMixin（非 TenantModelMixin）
  - level: error/warning/info
  - status: active/resolved
  - alert_key: 去重键

- **AlertRead**: 已读记录
  - user_id: IntegerField（非外键）
  - unique constraint: (alert_id, user_id) 保证幂等

## 4. 关联方式盘点

### 文本关联（非外键）

| 源 | 字段 | 目标概念 | 风险 |
|---|---|---|---|
| FaultRecord | system_name | 系统名称 | 改名后断裂 |
| FaultRecord | device_code | 设备编号 | 改编号后断裂 |
| FaultPart | system_name | 系统名称 | 与 FaultRecord 不关联 |

## 5. 数据迁移风险

### 高风险

1. **DeviceEvent.device_resume_id 为 IntegerField**: 重构时需改为外键，需数据清洗
2. **FaultRecord 无设备外键**: system_name/device_code 为文本，无法自动关联设备
3. **UpgradeRecord.system 为文本**: 不关联 UpgradeSystem，改名后断裂
4. **DeviceEvent 冗余文本**: device_name/device_sn 不自动更新，可能不一致

### 中风险

5. **FaultPart 无 FaultRecord 外键**: 独立记录，无法追溯故障
6. **AlertRead.user_id 为 IntegerField**: 改为外键需验证用户存在性
7. **UpgradeRecordStep/StatusLog.upgrade_id 为 IntegerField**: 改为外键需验证记录存在性
8. **DeviceResume CHECK 约束**: device_delete_fields_valid 可能影响迁移

### 低风险

9. **DeviceResume.responsible_user_name 为文本**: 可改为外键但影响较小
10. **Alert 无 tenant_id**: 全局数据设计，重构需确认是否需要租户隔离
