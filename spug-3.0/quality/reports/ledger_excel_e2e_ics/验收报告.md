## 一、空格丢失层定位结论（逐层实证）

链路：原始 XLSX → 后端解析 → layout JSON → 前端预览 → 填充值写回 XLSX → LibreOffice PDF。

| 层 | 实证方式 | 结论 |
|---|---|---|
| 原始 Excel | openpyxl `repr()` 逐字符 | A13=`维护记录：`+30空格+`温度：`+7空格+`湿度：`；E25=5空格+`年`+3空格+`月`+3空格+`日` |
| 后端解析（excel_template_services.parse_workbook） | 容器内真实调用后 `repr()` | **保真**（`_cell_value` 原样返回字符串） |
| JSON 保存（draft_layout / record.values） | 详情接口回读逐字符比对 | **保真**（`ensure_ascii=False`，无 normalize） |
| openpyxl 写回 XLSX | 保存重读 + sharedStrings XML 检查 | **保真**（内联字符串正确带 `xml:space="preserve"`） |
| LibreOffice PDF | pdfminer LTChar 级字形坐标 | **保真**（30/7/5/3 空格逐字形渲染，见 `11` 步骤实测） |
| **前端 HTML 预览（LayoutTable）** | 代码层定位 | **唯一丢失层**：`white-space` 默认 `normal` 折叠连续空格/换行 |

**根因**：`LayoutTable.js` 的 `cellCss` 只在单元格开启 wrap_text 时才设置
`white-space: pre-wrap`，其余单元格走浏览器默认 `normal`，`「温 度」`、
`「     年   月   日」`、维护记录留空线在预览中被折叠。后端数据从未丢。

**修复**：
- 前端（LayoutTable.js）：非 wrap 单元格 `white-space: pre`（保留空格换行，
  单行裁剪行高稳定），wrap 单元格 `pre-wrap + word-break: break-word`，
  无样式单元格同样按 `pre`；溢出继续 `overflow: hidden`，布局宽度不跳动。
- 后端（excel_template_services._typed_value）：文本填写值不再 `strip()`，
  原样写入单元格；受控类型（单选/日期）仅对匹配副本清理，落库候选原文。

## 二、PDF 打印参数（模板级 + 版本快照 + 单次覆盖）

- 保存位置：模板草稿 `draft_layout` JSON 的 `pdf_params` 键（零迁移）；
  发布随版本快照固定（`OperationLedgerExcelTemplateVersion.layout`），
  历史台账导出永远读创建时版本；导出高级设置可单次覆盖不改模板。
- 打印模式 `preset` 四档：
  - `original` 原始 Excel 打印设置：apply 整体跳过，源文件页面设置原样交给
    LibreOffice（纸张/方向/边距/缩放全沿用上传文件）；
  - `a4_auto` A4 自动适配（默认推荐）：A4 + 方向自动（按内容宽度逐表解析，
    纵向放不下自动转横向）+ 宽度适合 1 页 + 高度自动分页；
  - `single_page` 单页表单：宽 1 页 × 高 1 页，缩放过小导出前预检告警；
  - `custom` 逐项自定义（历史快照缺省值，与 2026-09-30 行为一致）。
- 新增参数：`print_area`（打印区域，A1:E25 或逗号分隔多段，越界拒绝）、
  `horizontal_centered`/`vertical_centered`（水平/垂直居中）、
  `orientation: auto`（自动方向）。
- 播种判别：源文件存在 fit 缩放/百分比缩放/打印区域任一（用户真实配置过
  打印）→ `original`；仅有 WPS 样板纸张方向 → `a4_auto`（避免样板 A4
  无缩放导致宽表横向溢出分页——ICS 样例正是此场景，修复前 4 页横向溢出）。
- 导出链路（复用 excel_pdf_service + LibreOffice）：复制源文件 → 写填写值
  → sanitize 打印区域 → apply_pdf_params（original 跳过）→ LO 转换 → 返回。
- 预检 `estimate_pdf_warnings`：横向溢出/单页缩放过小/空白工作表/分页行
  越界/打印区域越界/必填未填；只告警不阻断，真实失败才返回业务错误。
