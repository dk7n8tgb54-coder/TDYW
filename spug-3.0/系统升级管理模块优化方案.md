# 系统升级管理模块优化方案

## 一、当前功能概览

| 功能模块 | 说明 |
|---------|------|
| 升级记录列表 | 增删改查、筛选、导出Excel |
| 升级详情 | 多标签页展示（基本信息、检查清单、依赖关系、问题记录、经验总结） |
| 统计报表 | 升级结果分布、类型统计、系统统计、趋势分析 |

---

## 二、可优化点

### 1. 数据展示优化

| 优化项 | 现状 | 建议 |
|-------|------|------|
| 列表字段显示 | 固定列 | 支持列显示/隐藏配置（TableCard已支持） |
| 列表排序 | 不支持 | 添加列头排序功能 |
| 分页记忆 | 无 | 记住用户分页偏好（每页条数） |
| 行高亮 | 无 | 根据状态（进行中/已完成）行背景色区分 |

### 2. 筛选功能优化

| 优化项 | 现状 | 建议 |
|-------|------|------|
| 负责人筛选 | 文本输入 | 改为下拉选择（从已有数据中提取） |
| 版本筛选 | 无 | 添加版本号筛选 |
| 筛选记忆 | 无 | 记住用户筛选条件 |
| 快捷筛选 | 无 | 添加"本月升级"、"待处理"等快捷标签 |

### 3. 表单功能优化

| 优化项 | 现状 | 建议 |
|-------|------|------|
| 升级单号 | 手动输入 | 自动生成单号（格式：UPG-YYYYMMDD-序号） |
| 系统选择 | 文本输入 | 改为下拉选择（从已有数据中提取） |
| 负责人选择 | 文本输入 | 改为用户选择器 |
| 依赖关系 | 输入单号 | 改为下拉选择已有升级记录 |
| 时间冲突检测 | 无 | 保存时检测同一系统同一时间是否有冲突 |

### 4. 统计报表优化

| 优化项 | 现状 | 建议 |
|-------|------|------|
| 图表展示 | 纯表格 | 添加饼图、柱状图、折线图可视化 |
| 时间筛选 | 有 | 但"时间维度"选择后未实际生效 |
| 导出报表 | 无 | 支持导出统计报表为PDF/图片 |
| 对比分析 | 无 | 支持环比、同比分析 |

### 5. 交互体验优化

| 优化项 | 现状 | 建议 |
|-------|------|------|
| 批量操作 | 无 | 支持批量删除、批量导出 |
| 操作确认 | 有 | 删除前确认，建议添加"撤销"功能 |
| 数据刷新 | 手动 | 添加自动刷新（处理中状态每30秒刷新） |
| 通知提醒 | 无 | 升级计划前1天邮件/站内信提醒 |

### 6. 代码结构优化

| 优化项 | 现状 | 建议 |
|-------|------|------|
| 状态管理 | MobX Class | 保持不变，但建议拆分 store（列表/表单/详情分离） |
| 组件拆分 | 较合理 | Form.js 较长（246行），可拆分为子组件 |
| 类型定义 | 无 | 添加 TypeScript 类型定义 |
| 常量提取 | 内联 | 状态颜色、升级类型等提取为常量 |

---

## 三、优先级建议

| 优先级 | 优化项 | 预估工作量 |
|-------|--------|-----------|
| P0（高） | 自动生成升级单号、系统/负责人下拉选择、时间冲突检测 | 1-2天 |
| P1（中） | 列表排序、图表可视化、批量操作、自动刷新 | 2-3天 |
| P2（低） | 筛选记忆、快捷筛选、通知提醒、导出报表 | 3-5天 |

## 四、参考实现

### 4.1 自动生成单号示例
```javascript
// 格式：UPG-20250328-001
generateUpgradeNo = () => {
  const date = moment().format('YYYYMMDD');
  const count = this.records.filter(r => r.upgrade_no?.startsWith(`UPG-${date}`)).length;
  return `UPG-${date}-${String(count + 1).padStart(3, '0')}`;
}
```

### 4.2 时间冲突检测示例
```javascript
checkTimeConflict = (system, planTime, excludeId = null) => {
  const conflicts = this.records.filter(r => 
    r.system === system && 
    r.id !== excludeId &&
    moment(r.plan_time).isSame(planTime, 'day')
  );
  return conflicts.length > 0 ? conflicts : null;
}
```

## 五、注意事项

1. **兼容性**：优化需保持现有数据格式兼容
2. **权限控制**：新增功能需继承现有权限体系
3. **性能考虑**：自动刷新需控制频率，避免频繁请求
4. **用户体验**：保持界面简洁，避免功能堆砌
