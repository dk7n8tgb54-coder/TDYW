# 响应式改造实施计划

## Context

用户需要一个同时支持电脑和手机访问的"空管综合运维管理平台"。当前系统只有电脑版网页，用户希望扩展到移动端，要求：
- 全部页面都做响应式改造
- 手机版为精简版（隐藏次要功能）
- 先做核心页面

## 技术方案

**方式：响应式网页（方式A）** - 通过 CSS 媒体查询 + 条件渲染，让同一页面自适应不同屏幕尺寸。

**技术基础：**
- 已有 `isMobile` 检测（通过 UserAgent）
- 使用 less + CSS Modules 样式方案
- 使用 Ant Design 4.x 组件库

---

## 分步实施计划

### 阶段一：响应式基础设施（第 1-2 天）

#### 步骤 1：定义全局响应式变量和工具类

**修改文件：** `src/index.less`

- 添加响应式断点变量（xs: 480px, sm: 576px, md: 768px, lg: 992px）
- 添加响应式工具类（.hide-md, .mobile-only, .pc-only 等）

#### 步骤 2：创建响应式 Hook 和条件渲染组件

**新建文件：** `src/components/Responsive.js`

- `useResponsive()` Hook - 返回 isMobile/isTablet/isDesktop
- `PCOnly` 组件 - 仅 PC 端渲染
- `MobileOnly` 组件 - 仅移动端渲染
- `Responsive` 组件 - 根据屏幕宽度切换渲染

---

### 阶段二：布局组件改造（第 2-3 天）

#### 步骤 3：布局组件整体改造

**修改文件：** `src/layout/index.js`

- 移动端默认隐藏侧边栏（collapsed = true）
- 移动端使用 Drawer 抽屉组件替代侧边栏
- 提供移动端专属的顶部导航栏（带汉堡菜单按钮）

#### 步骤 4：移动端侧边栏组件

**新建文件：** `src/layout/MobileSider.js`

- 使用 Ant Design Drawer 实现侧边菜单
- 复用现有菜单逻辑（从 Sider.js 抽取）

#### 步骤 5：布局样式响应式改造

**修改文件：** `src/layout/layout.module.less`

- 移动端隐藏传统 Sider，使用 Drawer 代替
- 调整 Header 和 Content 的 padding

---

### 阶段三：核心页面改造（第 3-5 天）

#### 步骤 6：登录页响应式改造

**修改文件：** `src/pages/login/index.js` + `login.module.css`

- 移动端使用渐变背景替代图片背景
- 表单容器宽度自适应
- 缩小移动端标题字号

#### 步骤 7：工作台响应式改造

**修改文件：** `src/pages/home/index.js`

- PC 端：4 列卡片布局（span={6} × 4）
- 移动端：单列卡片堆叠（span={24}）
- 使用 `useResponsive()` Hook 动态计算列数和间距

#### 步骤 8：FilterBar 组件响应式改造

**修改文件：** `src/components/FilterBar.js`

- PC 端：多列筛选项一行展示
- 移动端：筛选项垂直堆叠，可折叠/展开
- 移动端默认折叠，仅显示"筛选"按钮

#### 步骤 9：TableCard 组件响应式改造

**修改文件：** `src/components/TableCard.js`

- 移动端隐藏次要列（通过 `hideOnMobile` 配置）
- 保持操作列固定
- 启用横向滚动并优化分页

#### 步骤 10：设备管理页面改造

**修改文件：** `src/pages/device/index.js`

- 移动端精简筛选项（只保留设备编号/名称）
- 移动端隐藏表格次要列（设备型号、使用单位）

#### 步骤 11：干扰管理页面改造

**修改文件：** `src/pages/interference/index.js`

- 移动端精简筛选项（频率、日期时间）
- 隐藏次要列（坐标、现象、机型）

#### 步骤 12：值班日志页面改造

**修改文件：** `src/pages/duty/index.js`

- 移动端只保留关键筛选（值班人员、日期范围）
- 隐藏科室筛选

#### 步骤 13：故障管理页面改造

**修改文件：** `src/pages/exec/fault/record/index.js`

- 移动端只保留系统名称、故障评级筛选
- 隐藏日期、处置人员筛选

### 阶段四：细节优化与测试（第 5-7 天）

- SearchForm、TableCard、Breadcrumb 等组件的移动端样式优化

#### 步骤 15：移动端操作按钮适配

- 表格操作列按钮改为图标或下拉菜单

#### 步骤 16：横屏模式提示优化

## 移动端隐藏优先级

**隐藏（从高到低）：**
1. 导出按钮
2. 次要筛选字段
3. 详情列（坐标、备注）
4. 部分操作按钮
5. 统计概览中的次要指标

**保留（从高到低）：**
1. 新建/编辑按钮
2. 关键筛选条件
3. 操作列的基本操作
4. 核心数据列

---

## 验证方式

1. **浏览器模拟**：使用 Chrome DevTools 模拟移动设备（iPhone、Android）
2. **渐进验证**：每完成一个阶段，在浏览器中测试该阶段的改动
3. **真机测试**：在手机上访问内网地址，验证实际效果
