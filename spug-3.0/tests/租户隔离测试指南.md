# 文档管理模块租户隔离测试指南

## 测试目标
验证租户隔离修复是否有效，确保不同租户间数据完全隔离。

## 测试环境准备
1. 准备两个不同租户的账号：
   - 租户A账号：tenant_a (tenant_id = 'tenant_a')
   - 租户B账号：tenant_b (tenant_id = 'tenant_b')
2. 准备一个超级管理员账号：admin (is_supper = True)

---

## 测试用例

### 🔴 测试1：横向越权测试（文件下载）

**测试步骤：**
1. 使用 `tenant_a` 登录，上传一个私有文件，记录文件 ID（假设为 1001）
2. 使用 `tenant_b` 登录，直接调用下载接口：
   ```
   GET /api/document/download/?id=1001&is_public=false
   ```

**预期结果：**
- ✅ 返回"文件不存在"错误
- ❌ **如果成功下载文件** → 严重安全漏洞

---

### 🔴 测试2：横向越权测试（文件删除）

**测试步骤：**
1. 使用 `tenant_a` 登录，创建一个私有文件夹，记录 ID（假设为 201）
2. 使用 `tenant_b` 登录，直接调用删除接口：
   ```
   DELETE /api/document/folder/?id=201&is_public=false
   ```

**预期结果：**
- ✅ 返回"文件夹不存在"错误
- ❌ **如果删除成功** → 严重安全漏洞

---

### 🔴 测试3：横向越权测试（文件复制/移动）

**测试步骤：**
1. 使用 `tenant_a` 登录，创建文件 ID=3001
2. 使用 `tenant_b` 登录，调用复制接口：
   ```json
   POST /api/document/file/copy/
   {
     "id": 3001,
     "folder_id": null,
     "is_public": false
   }
   ```

**预期结果：**
- ✅ 返回"文件不存在"错误
- ❌ **如果复制成功** → 严重安全漏洞

---

### 🟡 测试4：公共空间权限测试

**测试步骤：**
1. 使用 `tenant_a` 登录，在公共空间（is_public=true）上传文件 ID=5001
2. 使用 `tenant_b` 登录（非管理员），尝试删除：
   ```
   DELETE /api/document/file/?id=5001&is_public=true
   ```

**预期结果：**
- ✅ 返回"无权限删除他人的公共文件"错误
- ❌ **如果删除成功** → 权限校验漏洞

---

### 🟡 测试5：文件夹树隔离测试

**测试步骤：**
1. 使用 `tenant_a` 登录，创建文件夹 `/A/B/C`
2. 使用 `tenant_b` 登录，调用接口：
   ```
   GET /api/document/folder/?id=201&is_public=false
   ```

**预期结果：**
- ✅ 返回"文件夹不存在"错误
- ✅ 左侧文件夹树不显示租户A的任何文件夹

---

### 🟢 测试6：递归操作安全测试

**测试步骤：**
1. 使用 `tenant_a` 登录，创建嵌套文件夹 `/A/B/C`，并在 C 中上传文件
2. 使用 `tenant_b` 登录，尝试下载整个文件夹 A：
   ```
   GET /api/document/folder/download/?id=101&is_public=false
   ```

**预期结果：**
- ✅ 返回"文件夹不存在"错误
- ❌ **如果成功下载 ZIP** → 递归过滤漏洞

---

### 🟢 测试7：分片上传安全测试

**测试步骤：**
1. 使用 `tenant_a` 登录，获取文件夹 ID=301
2. 使用 `tenant_b` 登录，上传文件：
   ```
   POST /api/document/upload_chunk/
   folder_id=301&is_public=false&file=test.txt
   ```

**预期结果：**
- ✅ 返回"文件夹不存在"错误
- ❌ **如果上传成功** → 上传接口漏洞

---

### 🟢 测试8：秒传安全测试

**测试步骤：**
1. 使用 `tenant_a` 登录，上传文件，记录 MD5 和文件大小
2. 使用 `tenant_b` 登录，调用秒传检查：
   ```json
   POST /api/document/check_file/
   {
     "file_hash": "abc123...",
     "file_size": 1024,
     "is_public": false
   }
   ```

**预期结果：**
- ✅ 返回 `exists: false`（tenant_b 看不到 tenant_a 的文件）
- ❌ **如果返回 exists: true** → 秒传接口漏洞

## 测试工具

### curl 命令示例

```bash
# 获取 X-Token
X_TOKEN=$(curl -s -X POST http://localhost:8000/api/account/login/ \
  -H "Content-Type: application/json" \
  -d '{"username":"tenant_a","password":"123456"}' \
  | jq -r '.token')

# 测试文件下载
curl -v -X GET "http://localhost:8000/api/document/download/?id=1001&is_public=false" \
  -H "x-token: $X_TOKEN"

# 测试文件夹删除
curl -v -X DELETE "http://localhost:8000/api/document/folder/?id=201&is_public=false" \
  -H "x-token: $X_TOKEN"

# 测试文件复制
curl -v -X POST http://localhost:8000/api/document/file/copy/ \
  -H "x-token: $X_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"id":3001,"folder_id":null,"is_public":false}'
```

### Python 测试脚本

```python
import requests
import json

BASE_URL = "http://localhost:8000"

def login(username, password):
    """登录并返回 token"""
    resp = requests.post(f"{BASE_URL}/api/account/login/", json={
        "username": username,
        "password": password
    })
    return resp.json()['token']

def test_cross_tenant_access(file_id, attacker_token):
    """测试跨租户访问"""
    resp = requests.get(
        f"{BASE_URL}/api/document/download/",
        params={"id": file_id, "is_public": False},
        headers={"x-token": attacker_token}
    )
    print(f"Status: {resp.status_code}")
    print(f"Response: {resp.text}")
    return resp.status_code == 200

# 测试
tenant_a_token = login("tenant_a", "123456")
tenant_b_token = login("tenant_b", "123456")

# 假设文件 ID 1001 属于租户 A
is_vulnerable = test_cross_tenant_access(1001, tenant_b_token)
print(f"\n{'🔴 漏洞存在！' if is_vulnerable else '✅ 租户隔离正常'}")
```

## 问题排查

### 如果测试1失败（跨租户能下载文件）

1. 检查 `apply_tenant_filter` 函数实现
2. 检查 `DocumentFilePrivate` 模型是否有 `tenant_id` 字段
3. 检查数据库中该文件的 `tenant_id` 值
4. 检查是否正确调用 `apply_tenant_filter`

```sql
-- 检查文件的租户ID
SELECT id, name, tenant_id, created_by_id
FROM spug_document_file_private
WHERE id = 1001;
```

### 如果性能测试失败（查询慢）

1. 检查是否创建了索引：
```sql
-- 检查索引
SHOW INDEX FROM spug_document_file_private;

-- 如果没有索引，执行索引创建脚本
SOURCE scripts/add_document_tenant_indexes.sql;
```

2. 使用 EXPLAIN 分析查询计划：
```sql
EXPLAIN SELECT * FROM spug_document_file_private
WHERE tenant_id = 'tenant_a' AND folder_id = 101;
```
