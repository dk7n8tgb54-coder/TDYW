## ⚠️ 已知问题

### 1. 恢复传输列表逻辑待完善

**问题描述**:
- `restoreTransfers()` 方法已实现 API 调用
- 但将传输记录恢复到队列的逻辑需要根据实际业务需求实现

**影响范围**:
- 页面刷新后，传输列表可以从后端获取
- 但传输任务无法恢复到上传队列

**建议方案**:
- 仅恢复"已暂停"状态的传输任务
- 要求用户重新选择文件进行断点续传
- 或者只显示历史记录，不支持恢复

**优先级**: 低（不影响核心功能）
