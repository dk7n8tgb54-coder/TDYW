## 一、问题描述

### 核心问题（严格基于控制台日志）

#### 🔴 问题1：状态机问题 - 无效的状态转换
**报错1**: `更新传输状态失败: 24 无效的状态转换：CANCELED -> PAUSED`
**报错2**: `取消传输记录失败: 24 只能取消未完成的传输`

**根因分析**:
- 前端在操作时，没有先检查当前后端的真实状态，就直接调用接口
- 导致无效的状态转换（如 CANCELED -> PAUSED）
- 前端本地状态与后端真实状态严重不同步

**异常行为**:
- 用户多次操作（暂停→取消→恢复→暂停→取消→恢复）
- 中间有很多无效的状态转换请求
- 前端本地状态没有及时从后端同步

---

#### 🟡 问题2：合并逻辑问题 - 重复提交合并请求
**报错**: `文件上传失败: 21-【徒手】第4周，周三，全身肌肉强化.mp4 错误: 文件正在合并中，请勿重复提交`

**根因分析**:
- 续传时，前端没有先检查后端的合并状态
- 直接重新提交合并请求，导致重复提交
- 后端已存在合并锁，拒绝重复合并请求

**异常行为**:
- 续传时触发新的合并请求
- 后端返回"文件正在合并中，请勿重复提交"
- 上传流程失败，用户体验差

---

#### 🟡 问题3：前端本地状态与后端真实状态不同步
**根因分析**:
- 前端更新本地状态后，才调用后端接口
- 后端接口返回失败时，前端状态已更新，导致不一致
- 没有定期从后端同步状态的机制

**异常行为**:
- 用户操作后，前端状态与后端状态不一致
- 导致后续操作无效或失败

---

## 二、根因分析

### 根因1（P0）：前端状态检查逻辑不完善 【概率 95%】

**位置**: `spug_web/src/pages/document/stores/UploadCoreStore.js:1720-1778`

**问题**:
- `pauseItem` 方法只检查前端本地状态，未检查后端真实状态
- `cancelItem` 方法只检查前端本地状态，未检查后端真实状态
- 状态转换失败后，前端状态已经更新，导致不一致

**影响**:
- 无效的状态转换请求（如 CANCELED -> PAUSED）
- 前端显示状态与后端真实状态不一致

---

### 根因2（P0）：续传时未检查合并状态 【概率 90%】

**位置**: `spug_web/src/pages/document/stores/UploadCoreStore.js:676-716`

**问题**:
- 续传时只检查已上传分片，未检查合并状态
- 即使检查了合并状态，也只处理了 `merging` 状态，未处理 `completed` 状态

**影响**:
- 重复提交合并请求
- 导致"文件正在合并中，请勿重复提交"错误

### 根因3（P0）：后端状态机缺少 MERGING 状态支持 【概率 85%】

**位置**: `data/backend/apps/document/views.py:2980-2996`

- 状态转换规则中缺少 `MERGING` 状态
- `TransferCompleteView` 未验证状态转换合法性
- `TransferCancelView` 未处理 `MERGING` 状态的取消

**影响**:
- 合并中的任务无法正确转换到 COMPLETED 状态
- 状态转换失败，导致传输记录状态不一致

### 根因4（P1）：错误处理不完善 【概率 70%】

**位置**: `spug_web/src/pages/document/stores/UploadCoreStore.js:2063-2074`

**问题**:
- `updateTransferStatus` 静默处理错误，不抛出异常
- 调用方无法判断状态转换是否成功
- 错误信息未正确传递给用户

**影响**:
- 状态转换失败后，用户不知道原因
- 前端状态可能不一致

```javascript
async pauseItem(itemId) {
  console.log('[传输] 暂停单个任务:', itemId);
  const { item } = this.findUploadItem(itemId);
  if (!item) {
    console.warn('[传输] 未找到任务:', itemId);
    return;
  }

  // 检查前端本地状态是否允许暂停

      const currentTransfer = transferData?.find(t => t.id === item.transferId);

          message.warning(`"${item.name}" 后端状态为 ${backendStatus}，无法暂停`);
          return;
        }
      }
    } catch (error) {
      console.warn('[传输] 检查后端状态失败，继续执行:', error);
    }
  }

  // 执行暂停操作
  item.abortToken.cancel('用户暂停');
  console.log('[传输] 任务已暂停:', item.name);
  runInAction(() => {
    item.status = 'paused';
    item.error = '已暂停';
    item.canAbort = false;
    item.abortToken = null;
  });

  // 更新后端传输记录状态
  if (item.transferId) {
    await this.updateTransferStatus(item.transferId, 'PAUSED');
  }
}

@action.bound
async pauseItem(itemId) {
  console.log('[传输] 暂停单个任务:', itemId);
  const { item } = this.findUploadItem(itemId);
  if (!item) {
    console.warn('[传输] 未找到任务:', itemId);
    return;
  }

  // 检查前端本地状态是否允许暂停（支持 'calculating' 状态）
  if (item.status !== 'uploading' && item.status !== 'calculating') {
    console.warn('[传输] 任务状态不允许暂停:', item.name, 'status:', item.status);
    if (item.status === 'error' || item.status === 'completed') {
      message.warning(`"${item.name}" 已${item.status === 'completed' ? '完成' : '取消/失败'}，无法暂停`);
    } else if (item.status === 'paused') {
      message.info(`"${item.name}" 已暂停，无需重复操作`);
    }
    return;
  }

  // 如果有传输记录，先检查后端状态
  if (item.transferId) {
    try {
      const { http } = await import('libs');
      const transferData = await http.get(`/api/document/transfers/`);
      const currentTransfer = transferData?.find(t => t.id === item.transferId);
      if (currentTransfer) {
        const backendStatus = currentTransfer.status;
        console.log('[传输] 后端传输状态:', backendStatus);
        // 检查后端状态是否允许暂停
        if (backendStatus === 'COMPLETED' || backendStatus === 'FAILED' || backendStatus === 'CANCELED') {
          console.warn('[传输] 后端状态不允许暂停:', backendStatus);
          message.warning(`"${item.name}" 后端状态为 ${backendStatus}，无法暂停`);
          // 同步后端状态到前端
          runInAction(() => {
            item.status = backendStatus.toLowerCase();
            item.error = backendStatus === 'COMPLETED' ? null : (backendStatus === 'CANCELED' ? '已取消' : '失败');
            item.canAbort = false;
          });
          return;
        } else if (backendStatus === 'PAUSED') {
          console.log('[传输] 后端已暂停，同步状态');
          runInAction(() => {
            item.status = 'paused';
            item.error = '已暂停';
            item.canAbort = false;
          });
          return;
        }
      }
    } catch (error) {
      console.warn('[传输] 检查后端状态失败，继续执行:', error);
    }
  }

  // 检查是否有中止令牌
  if (!item.canAbort || !item.abortToken) {
    console.warn('[传输] 任务无法中止:', item.name, 'canAbort:', item.canAbort);
    // 如果传输记录已后端暂停，则同步本地状态
    if (item.transferId) {
      runInAction(() => {
        item.status = 'paused';
        item.error = '已暂停';
        item.canAbort = false;
        item.abortToken = null;
      });
    }
    return;
  }

  // 执行暂停操作
  try {
    item.abortToken.cancel('用户暂停');
    console.log('[传输] 任务已暂停:', item.name);
    runInAction(() => {
      item.status = 'paused';
      item.error = '已暂停';
      item.canAbort = false;
      item.abortToken = null;
    });

    // 更新后端传输记录状态（在状态更新后调用）
    if (item.transferId) {
      try {
        await this.updateTransferStatus(item.transferId, 'PAUSED');
      } catch (error) {
        console.error('[传输] 更新后端暂停状态失败:', item.name, error);
        // 如果状态转换失败，显示错误提示
        if (error?.message) {
          message.error(error.message);
        }
        // 不恢复前端状态，因为上传已被实际暂停
      }
    }
  } catch (error) {
    console.error('[传输] 暂停任务失败:', item.name, error);
    message.error(`暂停失败: ${error.message || '未知错误'}`);
  }
}
```

**修复点**:
1. 支持暂停 `calculating` 状态的任务
2. 增强后端状态检查，同步后端状态到前端
3. 增加 `PAUSED` 状态的幂等性处理
4. 完善错误处理，显示用户友好的错误提示
5. 状态转换失败时，不恢复前端状态（因为上传已被实际暂停）

```javascript
async cancelItem(itemId) {
  console.log('[传输] 取消单个任务:', itemId);
  const { item } = this.findUploadItem(itemId);
  if (!item) {
    console.warn('[传输] 未找到任务:', itemId);
    return;
  }

  // 检查前端本地状态是否允许取消
  if (item.status === 'completed' || item.status === 'error') {

    return;
  }

  // 如果有传输记录，先检查后端状态

    try {
      const { http } = await import('libs');
      const transferData = await http.get(`/api/document/transfers/`);
      const currentTransfer = transferData?.find(t => t.id === item.transferId);
      if (currentTransfer) {
        const backendStatus = currentTransfer.status;
        console.log('[传输] 后端传输状态:', backendStatus);
        // 检查后端状态是否允许取消

          console.warn('[传输] 后端状态不允许取消:', backendStatus);
          message.warning(`"${item.name}" 后端状态为 ${backendStatus}，无需取消`);
          runInAction(() => {
            item.status = backendStatus.toLowerCase();
            if (backendStatus === 'CANCELED') {
              item.error = '已取消';
            }
          });
          return;
        }
      }
    } catch (error) {
      console.warn('[传输] 检查后端状态失败，继续执行:', error);
    }
  }

  // 清理 MD5 Worker
  if (item.md5Worker) {
    item.md5Worker.terminate();
    item.md5Worker = null;
    console.log('[传输] 取消时清理 MD5 Worker:', item.name);
  }

  // 取消上传请求
  if (item.canAbort && item.abortToken) {
    item.abortToken.cancel('用户取消');
  }

  runInAction(() => {
    item.status = 'error';
    item.error = '已取消';
    item.canAbort = false;
    item.abortToken = null;
    console.log('[传输] 任务已取消:', item.name);
  });

  // 取消传输记录
  if (item.transferId) {
    await this.cancelTransfer(item.transferId);
  }

  // 清理 uniqueKey，允许重新上传
  if (item.uniqueKey) {
    this.uploadingUniqueKeys.delete(item.uniqueKey);
    console.log('[传输] 取消时清理 uniqueKey:', item.name);
  }
}
```

## 四、修复后的状态机转换规则

### 合法的状态转换

```
PENDING ──────────────┐
    │                │
    ├─→ UPLOADING    ├─→ CANCELED
    │                │
    ├─→ PAUSED       │
    │
    └─→ CANCELED

UPLOADING ────────────┐
    │                │
    ├─→ PAUSED       ├─→ FAILED
    │                │
    ├─→ MERGING      │
    │                │
    ├─→ COMPLETED    │
    │                │
    └─→ CANCELED     │

PAUSED ───────────────┤
    │                │
    ├─→ UPLOADING    │
    │                │
    └─→ CANCELED     │

MERGING ─────────────┤
    │                │
    ├─→ COMPLETED    │
    │                │
    └─→ FAILED       │

FAILED ──────────────┤
    │                │
    ├─→ UPLOADING    │
    │                │
    └─→ CANCELED     │

COMPLETED ───────────┘
(终端状态，不能转换)

CANCELED ────────────┘
(终端状态，不能转换)
```

### 状态说明

| 状态 | 说明 | 可转换到的状态 |
|------|------|---------------|
| `PENDING` | 等待中 | `UPLOADING`, `PAUSED`, `CANCELED` |
| `UPLOADING` | 上传中 | `PAUSED`, `FAILED`, `COMPLETED`, `CANCELED`, `MERGING` |
| `PAUSED` | 已暂停 | `UPLOADING`, `CANCELED` |
| `MERGING` | 合并中 | `COMPLETED`, `FAILED` |
| `FAILED` | 失败 | `UPLOADING`, `CANCELED` |
| `COMPLETED` | 已完成 | (终端状态) |
| `CANCELED` | 已取消 | (终端状态) |
