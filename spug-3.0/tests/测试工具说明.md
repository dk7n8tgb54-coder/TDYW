### CI/CD 集成

```yaml
# .github/workflows/test.yml
name: Test Multi-file Upload
on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2

      - name: Start Spug
        run: docker-compose up -d

      - name: Wait for service
        run: sleep 30

      - name: Run basic tests
        run: |
          cd tests
          npm install puppeteer
          node test_multi_file_upload_node.js --files 3 --size 1
```

**注意：** CI/CD 只能进行基本验证，完整测试需要人工验证。

## ⚠️ 重要提示

### 1. Node.js 脚本的限制

**为什么功能不完整？**
- React 生产代码经过压缩和混淆
- MobX store 实例无法通过 window 对象访问
- Puppeteer 无法直接访问 React 内部状态

**解决方案：**
- 使用浏览器控制台进行完整测试
- 或者在开发环境（未混淆代码）使用 Puppeteer

### 2. 测试数据隔离

**重要：** 所有测试都会生成临时文件！

建议：
- 使用独立的测试目录
- 定期清理测试文件
- 不要在生产环境运行完整测试

### 3. 测试环境要求

**必需：**
- Spug 服务已启动
- 浏览器支持（Chrome/Firefox/Edge）
- 对于 Node.js：需要安装 Puppeteer

**可选：**
- 开发工具（F12）
- 文本编辑器（查看测试报告）
