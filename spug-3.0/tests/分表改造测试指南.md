# 文档管理分表改造全量测试指南

## 概述

本文档提供文档管理分表改造的完整测试方案，包括自动化测试、手动测试和性能测试。

## 测试环境准备

### 1. 数据库准备
```bash
# 确保数据库已分表改造完成
python manage.py migrate

# 创建测试数据
python manage.py shell
>>> from tests.test_document_split_tables import *
>>> # 自动创建测试用户
```

### 2. 测试账号
创建3个测试账号：
- **admin**: 管理员账号（is_supper=True）
- **user1**: 普通用户1
- **user2**: 普通用户2

### 3. 获取Token
```bash
# 登录获取token
curl -X POST http://localhost:8000/api/account/login/ \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"password123"}'

# 返回的token用于后续测试
```

## 测试类型

### 一、自动化测试

#### 1.1 Django单元测试
```bash
# 运行所有测试
python manage.py test tests.test_document_split_tables

# 运行特定测试类
python manage.py test tests.test_document_split_tables.DocumentSplitTablesTest

# 运行单个测试方法
python manage.py test tests.test_document_split_tables.DocumentSplitTablesTest.test_folder_view_private_space

# 显示详细输出
python manage.py test tests.test_document_split_tables --verbosity=2
```

#### 1.2 手动测试脚本
```bash
# 安装依赖
pip install requests

# 修改配置
编辑 tests/manual_test_split_tables.py，设置以下变量：
- BASE_URL: API地址
- ADMIN_TOKEN: 管理员token
- USER1_TOKEN: user1的token
- USER2_TOKEN: user2的token

# 运行测试
python tests/manual_test_split_tables.py
```

### 二、Postman/ApiPost测试

#### 2.1 导入测试集合
1. 打开Postman
2. 点击 `Import` 按钮
3. 选择 `tests/postman_collection.json`
4. 修改环境变量：
   - `baseUrl`: http://localhost:8000/api
   - `adminToken`: 管理员token
   - `user1Token`: user1的token
   - `user2Token`: user2的token

#### 2.2 执行测试
- 点击 `Runner` 按钮
- 选择测试集合
- 点击 `Run Document Tests` 按钮执行

### 三、手动curl测试

#### 3.1 私有空间测试
```bash
# 创建私有文件夹
curl -X POST http://localhost:8000/api/document/folder/ \
  -H "X-Token: USER1_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"私有文件夹","parent_id":null,"is_public":false}'

# 获取私有文件夹列表
curl -X GET "http://localhost:8000/api/document/folder/?is_public=false" \
  -H "X-Token: USER1_TOKEN"

# 上传文件到私有空间
curl -X POST http://localhost:8000/api/document/upload/ \
  -H "X-Token: USER1_TOKEN" \
  -F "file=@/path/to/file.txt" \
  -F "folder_id=" \
  -F "is_public=false"
```

#### 3.2 公共空间测试
```bash
# 创建公共文件夹
curl -X POST http://localhost:8000/api/document/folder/ \
  -H "X-Token: USER1_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"公共文件夹","parent_id":null,"is_public":true}'

# 获取公共文件夹列表
curl -X GET "http://localhost:8000/api/document/folder/?is_public=true" \
  -H "X-Token: USER1_TOKEN"

# 上传文件到公共空间
curl -X POST http://localhost:8000/api/document/upload/ \
  -H "X-Token: USER1_TOKEN" \
  -F "file=@/path/to/file.txt" \
  -F "folder_id=" \
  -F "is_public=true"
```

#### 3.3 权限测试
```bash
# user2尝试删除user1的公共文件夹（应该失败）
curl -X DELETE "http://localhost:8000/api/document/folder/?id=FOLDER_ID&is_public=true" \
  -H "X-Token: USER2_TOKEN"

# 管理员删除公共文件夹（应该成功）
curl -X DELETE "http://localhost:8000/api/document/folder/?id=FOLDER_ID&is_public=true" \
  -H "X-Token: ADMIN_TOKEN"
```

#### 3.4 安全测试
```bash
# 路径遍历攻击（应该失败）
curl -X POST http://localhost:8000/api/document/folder/ \
  -H "X-Token: USER1_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"../../../etc/passwd","parent_id":null,"is_public":false}'

# XSS攻击（应该失败）
curl -X POST http://localhost:8000/api/document/folder/ \
  -H "X-Token: USER1_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"test<script>alert(1)</script>","parent_id":null,"is_public":false}'
```

## 常见问题

### Q1: 测试失败如何处理？
A:
1. 查看错误日志：`tail -f logs/spug.log`
2. 检查数据库连接：`python manage.py dbshell`
3. 验证模型定义：检查models.py
4. 重启服务：`python manage.py runserver`

### Q2: 如何验证分表是否正确？
A:
```sql
-- 查看私有表
SELECT COUNT(*) FROM document_folder_private;
SELECT COUNT(*) FROM document_file_private;

-- 查看公共表
SELECT COUNT(*) FROM document_folder_public;
SELECT COUNT(*) FROM document_file_public;
```

### Q3: 如何清理测试数据？
```bash
# 使用Django shell
python manage.py shell

# 清空测试数据
>>> from apps.document.models import *
>>> DocumentFolderPrivate.objects.all().delete()
>>> DocumentFilePrivate.objects.all().delete()
>>> DocumentFolderPublic.objects.all().delete()
>>> DocumentFilePublic.objects.all().delete()
```
