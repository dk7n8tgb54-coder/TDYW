# 资料库模块前端权限控制说明

## 概述

前端权限控制（UI层面的权限展示）是指在前端界面中，根据用户的权限和资源归属来控制按钮、菜单、操作选项的显示和隐藏，确保用户只能看到和操作自己有权限的功能。

---

## 权限控制实现

### 1. 权限判断方法

#### 1.1 判断当前用户是否是管理员

```javascript
// Explorer.js (line 82-84)
get isAdmin() {
  return localStorage.getItem('is_supper') === 'true';
}
```

**说明**:
- 从 localStorage 读取 `is_supper` 标识
- `is_supper === 'true'` 表示超级管理员
- 管理员拥有所有操作权限

#### 1.2 获取当前用户ID

```javascript
// Explorer.js (line 96-98)
get currentUserId() {
  return parseInt(localStorage.getItem('id') || '0');
}
```

**说明**:
- 从 localStorage 读取用户ID
- 用于判断资源归属

#### 1.3 判断是否可以编辑当前项

```javascript
// Explorer.js (line 255-264)
canEditItem = (item) => {
  // 私有空间：始终可以编辑
  if (!this.isPublic) return true;

  // 公共空间：管理员或创建者可以编辑
  if (this.isAdmin) return true;

  // 处理 created_by_id 为 null 的情况
  if (!item.created_by_id) return false;

  return item.created_by_id === this.currentUserId;
};
```

**权限规则**:
1. **私有空间**: 当前用户始终可以编辑自己空间内的所有资源
2. **公共空间**:
   - 超级管理员：可以编辑所有公共资源
   - 普通用户：只能编辑自己创建的公共资源
   - 非创建者：无法编辑其他用户的公共资源

### 2. UI层面的权限展示

#### 2.1 右键菜单权限控制

```javascript
// Explorer.js (line 1225-1271)
const handleContextMenu = (e, item) => {
  e.preventDefault();

  // 多选状态：只显示批量操作
  const isMultiSelect = currentSelection.length > 1;
  let menuItems;

  if (isMultiSelect) {
    // 公共空间检查是否有编辑权限
    const canEdit = this.isPublic ? this.canEditItem(item) : true;

    menuItems = [
      { key: 'download', label: `批量下载 (${selectedCount}项)` }
    ];

    // 只有有编辑权限的用户才能看到复制、移动、删除选项
    if (canEdit) {
      menuItems.push(
        { key: 'copy', label: `批量复制 (${selectedCount}项)` },
        { key: 'cut', label: `批量移动 (${selectedCount}项)` },
        { key: 'delete', label: `批量删除 (${selectedCount}项)` }
      );
    }
  } else {
    // 单选状态：显示完整菜单
    const canEdit = this.canEditItem(item);

    menuItems = item.isFolder ? [
      { key: 'open', label: '打开' },
      { key: 'download', label: '下载' }
    ] : [
      { key: 'open', label: '打开' },
      { key: 'download', label: '下载' }
    ];

    // 只有有编辑权限的用户才能看到编辑选项
    if (canEdit) {
      menuItems.push(
        { key: 'copy', label: '复制' },
        { key: 'cut', label: '移动' },
        { key: 'rename', label: '重命名' },
        { key: 'delete', label: '删除' }
      );
    }
  }

  this._showContextMenu(e, menuItems);
};
```

**权限展示效果**:
- **无编辑权限的用户**:
  - 右键菜单只显示：打开、下载
  - 复制、移动、重命名、删除选项被隐藏

- **有编辑权限的用户**:
  - 右键菜单显示完整选项：打开、下载、复制、移动、重命名、删除

### 4. 删除操作的权限验证

```javascript
// Explorer.js (line 429-467)
handleDelete = (record) => {
  let content;

  if (record.isFolder) {
    // 文件夹删除权限检查
    if (this.isPublic && !this.isAdmin && record.created_by_id !== this.currentUserId) {
      message.warning('您没有权限删除此文件夹');
      return;
    }

    content = this.isPublic
      ? `确定要删除公共文件夹 "${record.name}" 及其所有内容吗？删除后所有用户均无法访问此文件夹，此操作不可恢复。`
      : `确定要删除文件夹 "${record.name}" 及其所有内容吗？此操作不可恢复。`;
  } else {
    // 文件删除权限检查
    if (this.isPublic && !this.isAdmin && record.created_by_id !== this.currentUserId) {
      message.warning('您没有权限删除此文件');
      return;
    }

    content = this.isPublic
      ? `确定要删除公共文件 "${record.name}" 吗？删除后所有用户均无法访问此文件，此操作不可恢复。`
      : `确定要删除文件 "${record.name}" 吗？`;
  }

  // 显示删除确认对话框
  Modal.confirm({
    title: '删除确认',
    content,
    onOk: async () => {
      // 执行删除操作
      await http.delete(url, { params: { id: record.id, is_public: this.isPublic } });
      message.success('删除成功');
    }
  });
};
```

**权限检查**:
1. 删除前先检查权限
2. 公共空间非管理员且非创建者 → 提示 "您没有权限删除此文件/文件夹"
3. 私有空间 → 当前用户始终可以删除
4. 通过权限检查后 → 显示删除确认对话框

## 前端权限控制的优势

### 1. 提升用户体验
- **即时反馈**: 用户无需点击后才知道没有权限
- **清晰的UI**: 有权限的操作显示，无权限的操作隐藏
- **减少困惑**: 用户不会被允许执行但最终失败的操作

### 2. 减少服务器压力
- **前端拦截**: 无权限的操作在前端就被拦截，不会发送到后端
- **减少无效请求**: 减少后端权限验证的压力

### 3. 提升安全性
- **多层防护**: 前端UI控制 + 后端权限验证
- **攻击面减小**: 防止用户绕过前端直接调用API（需配合后端）

---

## 前端权限控制的局限性

### 1. 不是安全措施
- **可绕过**: 熟悉技术的用户可以通过浏览器开发者工具绕过前端限制
- **仅UI层面**: 只是为了提升用户体验，不是真正的安全防护

### 2. 依赖后端验证
- **必须配合**: 必须在后端也实现严格的权限验证
- **最终防线**: 后端权限验证是最终的安全防线

### 3. 数据一致性
- **需同步**: 前端和后端的权限规则必须保持一致
- **否则矛盾**: 前端允许的操作，后端可能拒绝
