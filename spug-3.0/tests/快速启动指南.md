# 多文件上传测试快速启动指南

## ⚠️ 重要提示

**Node.js 版本测试脚本存在以下限制：**

1. ❌ **无法直接访问 store 实例** - React 构建后的代码经过压缩和混淆，无法直接访问 MobX store
2. ⚠️ **功能不完整** - 只能进行基本的页面交互测试，无法验证并发控制等核心功能
3. 🎯 **推荐使用浏览器控制台** - 这是最完整、最可靠的测试方式

**强烈推荐使用【浏览器控制台】方式运行测试！**


## 常见问题快速解决

### ❌ 问题1：连接失败 (ERR_CONNECTION_REFUSED)

**错误信息：**
```
❌ 错误：无法连接到 http://localhost:3000/#/document
```

**解决方案：**

```bash
# 检查服务是否运行
docker ps | grep spug

# 如果没有运行，启动服务
docker-compose up -d

# 等待服务启动（约 10 秒）
sleep 10

# 再次运行测试
node test_multi_file_upload_node.js
```

**或者使用 Docker 环境的 URL：**
```bash
node test_multi_file_upload_node.js --url http://localhost/#/document
```

---

### ❌ 问题2：找不到 documentStore

**错误信息：**
```
❌ 错误：找不到 documentStore
```

**解决方案：**

1. **检查 URL 路径是否正确**
   - 正确: `http://localhost/#/document`
   - 错误: `http://localhost/` 或 `http://localhost/home`

2. **等待页面完全加载**
   ```javascript
   // 在浏览器控制台检查
   console.log(window.documentStore); // 应该有输出
   ```

3. **使用正确的 URL**
   ```bash
   node test_multi_file_upload_node.js --url http://localhost/#/document
   ```

---

### ❌ 问题3：Puppeteer 安装失败

**错误信息：**
```
Error: Cannot find module 'puppeteer'
```

**解决方案：**

```bash
# 安装 Puppeteer
cd tests
npm install puppeteer

# 如果安装失败，尝试使用淘宝镜像
npm install puppeteer --registry=https://registry.npmmirror.com

# 或者安装轻量版本
npm install puppeteer-core
```

---

### ❌ 问题4：测试超时

**错误信息：**
```
❌ 条件等待超时 (超时: 30000ms)
```

**解决方案：**

**方法1：减少文件数量和大小**
```bash
node test_multi_file_upload_node.js --files 3 --size 1
```

**方法2：增加超时时间**
```bash
node test_multi_file_upload_node.js --files 3 --size 1
```

**方法3：检查服务器性能**
```bash
# 查看服务器日志
docker-compose logs -f spug

# 检查磁盘空间
df -h

# 检查数据库连接
docker exec -it spug-db mysql -uspug -pspug.cc spug -e "SHOW PROCESSLIST;"
```

---

### ❌ 问题5：浏览器启动失败

**错误信息：**
```
Error: Failed to launch the browser process
```

**解决方案：**

**方法1：添加浏览器参数**
```bash
# 修改 test_multi_file_upload_node.js 中的 browser 启动参数
browser = await puppeteer.launch({
  headless: false,
  args: [
    '--no-sandbox',
    '--disable-setuid-sandbox',
    '--disable-dev-shm-usage'
  ]
});
```

**方法2：使用 headless 模式**
```bash
# 修改配置
headless: 'new'  // 或者 true
```

**方法3：检查系统要求**
```bash
# 检查是否安装了依赖库（Linux）
sudo apt-get update
sudo apt-get install -y \
  libnss3 \
  libatk-bridge2.0-0 \
  libdrm2 \
  libxcomposite1 \
  libxdamage1 \
  libxrandr2 \
  libgbm1 \
  libasound2
```

## 测试参数速查表

| 参数 | 说明 | 默认值 | 快速测试值 |
|------|------|--------|------------|
| `--url` | 测试页面 URL | http://localhost/#/document | http://localhost:3000/#/document |

```bash
node test_multi_file_upload_node.js --files 3 --size 1 --no-logs --no-screenshots

```

---

### 常见失败原因

| 失败项 | 可能原因 | 解决方案 |
|--------|----------|----------|
| **并发控制** | 配置错误、竞态条件 | 检查 `MAX_CONCURRENT_UPLOADS` 常量 |
| **等待队列** | 文件数量太少 | 增加测试文件数量（≥5） |
| **进度节流** | 文件太小、网络太快 | 增大文件大小（≥5MB） |
| **暂停/继续** | 未实现 resumeAll | 检查是否有 pauseAll/resumeAll 方法 |
| **资源清理** | 清理逻辑缺失 | 检查 cancelAll 和 removeItem 方法 |
