
### 用户类型说明

#### PrivateSpaceUser（私有空间用户）
- 测试私有空间的功能
- 操作包括：创建文件夹、查询文件夹、上传文件、删除文件、重命名文件、搜索、回收站、传输列表
- 权重较高的操作（高频率）：查询文件夹、上传文件
- 权重较低的操作（低频率）：重命名文件、回收站统计

#### PublicSpaceUser（公共空间用户）
- 测试公共空间的功能
- 操作与私有空间相同，但 `is_public=True`
- 可以验证公共空间的租户隔离和权限控制

#### AdminUser（管理员用户）
- 监控私有和公共空间的传输列表
- 检查私有和公共空间的磁盘使用情况
- 适合用于系统监控和性能指标收集

## 测试结果分析

### 关键指标

1. **失败率**: 应低于 1%
2. **平均响应时间**: 
   - 查询操作应 < 100ms
   - 上传操作（小文件）应 < 500ms
   - 上传操作（大文件）应 < 2000ms
3. **95/99 百分位响应时间**: 用于识别性能瓶颈
4. **RPS (每秒请求数)**: 用于评估系统吞吐量

### 常见问题

#### 1. 登录失败
- 检查用户名和密码是否正确
- 检查用户是否被禁用（登录失败 3 次会被禁用）
- 使用以下命令清除登录失败缓存：
  ```python
  # 需要先登录获取 token
  import requests
  response = requests.patch(
      'http://localhost/api/account/login/clear/',
      headers={'x-token': 'your_token_here'}
  )
  ```

#### 2. 401 Unauthorized 错误
- Token 可能已过期，Locust 会在测试开始时登录一次，然后重复使用该 token
- 如果测试时间过长，可能需要刷新 token
- 这种错误在高并发长测试中是正常的

#### 3. 分页显示空白
- 已修复后端分页逻辑（`views/folder/views.py`）
- 需要重启 Django 服务使修改生效

### 测试结果解读

#### 基础分片上传测试
- 验证后端是否能正确接收和存储分片
- 验证合并接口是否能正确重组文件
- 所有分片上传后合并应该100%成功

#### 断点续传测试
- 第一轮上传应该只成功部分分片
- 续传后应该能补齐所有分片
- 最终合并应该成功
- 检查传输列表是否正确显示进度

#### 并发上传测试
- 所有分片应该全部上传成功
- 合并应该成功
- 验证后端没有死锁或竞争条件
- 响应时间可能较长，但不应该失败

#### 分片顺序校验测试
- 乱序上传的所有分片都应该成功
- 合并应该成功
- 验证文件完整性（MD5校验）

#### 分片丢失处理测试
- 第一轮应该上传部分分片成功
- 重传丢失的分片应该成功
- 合并应该成功
- 验证后端在合并前检查完整性

### 常见问题

#### 1. 登录失败
- 检查用户名和密码是否正确
- 检查用户是否被禁用（登录失败 3 次会被禁用）
- 使用以下命令清除登录失败缓存：
  ```python
  # 需要先登录获取 token
  import requests
  response = requests.patch(
      'http://localhost/api/account/login/clear/',
      headers={'x-token': 'your_token_here'}
  )
  ```

#### 2. 401 Unauthorized 错误
- Token 可能已过期，Locust 会在测试开始时登录一次，然后重复使用该 token
- 如果测试时间过长，可能需要刷新 token
- 这种错误在高并发长测试中是正常的

#### 3. 分片上传失败
- 检查后端 `/api/document/upload_chunk/` 接口是否正常运行
- 检查磁盘空间是否充足
- 检查临时文件存储目录权限
- 查看后端日志获取详细错误信息

#### 4. 合并失败
- 检查是否所有分片都已上传成功
- 检查分片索引是否正确（0、1、2...）
- 检查MD5哈希是否匹配
- 检查文件存储路径是否正确

#### 5. 并发测试高失败率
- 检查数据库连接池配置
- 检查文件系统锁机制
- 检查后端是否有并发限制
- 可以适当降低并发用户数
