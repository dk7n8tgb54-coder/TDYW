# Spug 数据库配置说明

## 当前配置

**默认数据库：MySQL**

项目已将MySQL作为默认数据库配置，与Docker部署环境保持一致。

## 配置方式

### 方式1：环境变量（推荐，Docker部署使用）

通过环境变量配置数据库连接：

```bash
MYSQL_DATABASE=spug
MYSQL_USER=spug
MYSQL_PASSWORD=spug.cc
MYSQL_HOST=db              # Docker容器名或IP
MYSQL_PORT=3306
```

### 方式2：直接修改settings.py

如果需要使用不同的数据库，可直接修改 `spug/settings.py` 中的 `DATABASES` 配置。

### 方式3：创建overrides.py（不推荐）

如需在运行时覆盖配置，在 `spug/` 目录创建 `overrides.py`：

```python
# spug/overrides.py
DATABASES = {
    'default': {
        'ATOMIC_REQUESTS': True,
        'ENGINE': 'django.db.backends.sqlite3',
        'NAME': '/path/to/db.sqlite3',
    }
}
```

⚠️ **注意**：使用overrides会覆盖所有默认配置，包括已设置的MySQL配置。

## 常见问题

**Q: 为什么默认是MySQL而不是SQLite？**
A: 为了与Docker部署环境保持一致，避免配置混淆。

**Q: 如何切换到SQLite？**
A: 修改settings.py中的ENGINE和NAME配置，或创建overrides.py。

**Q: 数据库连接失败怎么办？**
A: 检查：
1. MySQL服务是否运行
2. 环境变量是否正确设置
3. 网络连接是否正常（Docker中注意容器名称）
4. 数据库用户权限是否足够
