# 资料管理模块使用说明

## 功能特性

资料管理模块是一个完整的文件资源管理器，提供以下功能：

- **文件夹管理**: 支持多级文件夹结构，可以创建、删除文件夹
- **文件上传**: 支持单个文件和批量上传，显示上传进度
- **文件下载**: 支持文件下载功能
- **文件删除**: 支持单个删除和批量删除
- **文件复制**: 可以在文件夹内复制文件
- **在线预览**: 支持图片类型的在线预览
- **权限控制**: 集成Spug的权限系统，支持细粒度的权限控制

## 安装步骤

### 1. 数据库初始化

执行以下SQL脚本创建必要的数据库表：

```bash
# 连接到Spug数据库
mysql -u your_username -p spug

# 执行初始化脚本
source spug_api/apps/document/init.sql
```

或者使用Django的migrate命令（需要创建migration文件）：

```bash
cd spug_api
python manage.py makemigrations document
python manage.py migrate
```

### 2. 创建存储目录

确保存储目录存在且有正确的权限：

```bash
mkdir -p spug_api/storage/documents
chmod 755 spug_api/storage/documents
```

### 3. 重启服务

```bash
# 重启API服务
cd spug_api
python manage.py runserver

# 重启Web服务
cd spug_web
npm start
```

### 4. 权限配置

在系统管理 -> 角色管理中，为相应角色配置资料管理的权限：

- 资料查看：允许查看文件和文件夹
- 文件夹管理：允许创建、删除、移动文件夹
- 文件管理：允许上传、下载、删除、复制文件

## 使用说明

### 创建文件夹

1. 点击左侧文件夹树顶部的 "+" 按钮
2. 输入文件夹名称
3. 点击确定
4. 文件夹会在选中的父文件夹下创建

### 上传文件

1. 选择目标文件夹
2. 点击顶部的"上传文件"按钮
3. 拖拽文件到上传区域或点击选择文件
4. 支持同时上传多个文件
5. 显示实时上传进度

### 下载文件

1. 在文件列表中找到目标文件
2. 点击"下载"图标

### 在线预览

1. 在文件列表中找到目标文件
2. 点击"预览"图标（眼睛图标）
3. 目前支持图片类型的在线预览

### 复制文件

1. 在文件列表中找到目标文件
2. 点击"复制"图标
3. 确认复制操作
4. 文件会以"副本_原文件名"的形式复制到当前文件夹

### 删除文件

单个删除：
1. 在文件列表中找到目标文件
2. 点击"删除"图标
3. 确认删除操作

批量删除：
1. 在文件列表中勾选多个文件
2. 执行批量删除操作

### 删除文件夹

1. 在左侧文件夹树中选中要删除的文件夹
2. 点击顶部的"删除"图标
3. 确认删除操作
4. 注意：删除文件夹会同时删除该文件夹下的所有文件和子文件夹

## API接口说明

### 文件夹相关

- `GET /api/document/folder/?id=<folder_id>` - 获取文件夹内容（id为空时获取所有文件夹）
- `POST /api/document/folder/` - 创建文件夹
- `DELETE /api/document/folder/?id=<folder_id>` - 删除文件夹

### 文件相关

- `POST /api/document/upload/` - 上传文件
- `GET /api/document/download/?id=<file_id>` - 下载文件
- `DELETE /api/document/file/?id=<file_id>` - 删除文件
- `GET /api/document/preview/?id=<file_id>` - 预览文件
- `POST /api/document/copy/` - 复制文件

## 技术栈

- 后端：Django + Django REST Framework
- 前端：React + Ant Design + MobX
- 存储：本地文件系统
- 数据库：MySQL

## 注意事项

1. **文件大小限制**: 建议单个文件不超过500MB
2. **权限管理**: 请根据实际需求配置合适的权限
3. **存储空间**: 定期检查存储目录的磁盘空间
4. **备份**: 建议定期备份存储的文件和数据库
5. **路径安全**: 文件上传后会自动重命名，避免路径遍历攻击
