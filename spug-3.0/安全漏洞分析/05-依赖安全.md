## 漏洞 #11：Django版本过旧（2.2.28）存在已知CVE（P2）

### 风险描述
Django 2.2.x 已于2022年4月停止安全支持。当前使用的2.2.28是该分支最后一个版本，之后发现的漏洞将不再修复。

### 涉及文件

**文件：`spug_api/requirements.txt`**
```
Django==2.2.28
```

### 已知CVE（Django 2.2.28之后发现）

| CVE | 严重程度 | 描述 |
|-----|----------|------|
| CVE-2023-36053 | 高 | EmailValidator/URLValidator ReDoS |
| CVE-2023-41164 | 中 | django.utils.encoding.uri_to_iri() DoS |
| CVE-2023-43665 | 中 | Truncator DoS |
| CVE-2024-24680 | 中 | intcomma模板过滤器DoS |
| CVE-2024-27351 | 高 | django.utils.text.Truncator ReDoS |
| CVE-2024-38875 | 中 | urlize/urlizetrunc DoS |
| CVE-2024-39329 | 低 | 用户枚举（HashedPassword） |
| CVE-2024-39330 | 中 | Storage.save() 路径遍历 |
| CVE-2024-41989 | 中 | floatformat DoS |
| CVE-2024-41990 | 中 | urlize DoS |
| CVE-2024-41991 | 中 | urlize/urlizetrunc DoS |
| CVE-2024-45230 | 中 | urlize DoS |
| CVE-2024-45231 | 低 | 密码重置用户枚举 |

### 影响范围
- ReDoS漏洞可导致服务拒绝
- 路径遍历可能导致文件读取
- 用户枚举可辅助暴力破解

## 漏洞 #22：paramiko版本过旧（2.11.0）存在Terrapin攻击（P3）

### 风险描述
paramiko 2.11.0 受 CVE-2023-48795（Terrapin攻击）影响，攻击者可在SSH握手阶段进行前缀截断攻击。

### 涉及文件

**文件：`spug_api/requirements.txt`**
```
paramiko==2.11.0
```

### CVE-2023-48795 详情
- **类型**：SSH协议层面的中间人攻击
- **影响**：攻击者可截断SSH握手中的扩展协商消息
- **修复版本**：paramiko >= 3.4.0
