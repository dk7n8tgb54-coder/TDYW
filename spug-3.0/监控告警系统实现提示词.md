# 实现系统监控告警功能

## 背景

Django 4.2 + Celery + React + antd 4.21.5 + mobx 项目，内网部署无外网，8核8G单机Docker。需要实现监控告警：SMTP邮件 + 站内展示（Header铃铛 + 首页卡片 + 系统管理列表页）。

## 要做什么

### 后端

1. **Alert 模型**（`apps/home/models.py`）：title/message/level(error|warning|info)/status(unread|read|resolved)/source/alert_key/created_at/resolved_at/resolved_by，db_table='home_alert'。makemigrations 必须指定 `home`。

2. **告警入口**（`libs/alert.py`）：`send_alert(title, message, level, source, alert_key)` 函数。alert_key 相同则限流去重（Redis），限流时长按来源分级：celery/middleware 5分钟（瞬态事件），disk/db 30分钟（持续状态，避免告警风暴），默认5分钟。三路输出：写DB Alert表 + 写Redis List(`alerts:recent`保留50条) + 发SMTP邮件 + 写日志。邮件用 `smtplib`，SMTP配置从 `settings.ALERT_SMTP` 读取。所有外部调用 try/except 不影响主流程。

3. **Celery 信号**（`spug/celery.py` 末尾）：`@task_failure.connect` 调 `send_alert(title=f'Celery任务失败: {task_name}', level='error', source='celery', alert_key=f'celery:{task_name}')`。

4. **异常中间件**（`libs/middleware.py` 的 `HandleExceptionMiddleware.process_exception`）：现有 `logger.error` 之后加 `send_alert(title=f'API异常: {request.method} {request.path}', level='error', source='middleware', alert_key=f'500:{request.path}')`，try/except 包裹不影响原逻辑。

5. **监控 Beat 任务**（`apps/home/tasks/monitoring.py`）：
   - `check_disk_space`：每10分钟，检查 documents/chunks/media 三个目录，>90%告警。
   - `collect_db_metrics`：每5分钟，查 Threads_connected/max_connections/Innodb_buffer_pool命中率/Slow_queries，连接率>80%或命中率<95%告警。
   - 在 `apps/home/celery_beat_schedule.py` 的 HOME_BEAT_SCHEDULE 中注册，queue='home.monitoring'。

6. **告警 API**（`apps/home/views.py`）+ 路由（`apps/home/urls.py`）：
   - `GET /api/home/alert/` - 列表（支持 level/status 筛选，返回 data + unread_count/error_count/warning_count/info_count）
   - `GET /api/home/alert/unread-count/` - 铃铛轮询用（轻量，只返回 count + error_count）
   - `POST /api/home/alert/mark-read/` - 标记已读（支持 ids 列表或 all=true）
   - `POST /api/home/alert/<pk>/resolve/` - 标记已处理
   - 权限用 `@auth('dashboard.dashboard.view')`

7. **settings.py** 末尾加 `ALERT_SMTP` 配置（从环境变量读 SMTP_HOST/PORT/USER/PASSWORD/FROM/TO）。

### 前端

8. **AlertStore**（`src/layout/AlertStore.js`）：仿 `src/layout/RadioLicenseBadgeStore.js` 模式（mobx @observable + setInterval）。30秒轮询 unread-count，点击铃铛时拉 alert 列表。

9. **Header.js**：用户头像左侧加铃铛（BellOutlined + Badge + Popover）。Popover 内容：最近告警列表（Tag标级别+标题+时间）+ "全部已读"按钮 + "查看全部"链接到 `/system/alert`。

10. **layout/index.js**：useEffect 中启动/停止 alertStore（与已有 radioLicenseBadge 并列）。

11. **layout.module.less**：`.right` 内加 `.bell` 样式（cursor:pointer; padding:0 12px; height:48px; display:flex; align-items:center）。

12. **首页卡片**（`src/pages/home/AlertOverview.js`）：Card + 3列Statistic（严重/警告/提示未读数），60秒刷新，引入到首页 index.js。

13. **告警列表页**（`src/pages/system/alert/index.js`）：Table 展示全部告警，支持级别/状态筛选，每行"标记已处理"按钮。路由加到 `src/routes.js` 系统管理子菜单下 `/system/alert`。

## 约束

- antd 4.21.5：用 `visible` 不是 `open`
- mobx legacy decorators：用 `@observable`，不是 `makeAutoObservable`
- http 请求用 `libs/http`，返回值兼容 `res.data || res`
- makemigrations 指定 app：`python manage.py makemigrations home`
- 验证：`docker exec -e PYTHONIOENCODING=utf-8 tdyw python -m py_compile <path>`
