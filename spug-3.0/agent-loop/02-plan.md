# 02 任务拆解：无线电台执照有效期管理

## 总体任务树

```text
无线电台执照有效期管理
  - 后端模块
    - 数据模型
    - CRUD 接口
    - 附件接口
    - 提醒接口
    - 定时扫描任务
    - 权限接入
  - 前端模块
    - 列表页
    - 新增/编辑表单
    - 详情页
    - 附件管理
    - 提醒展示
  - 数据库
    - 执照主表
    - 频率明细表
    - 附件表
    - 提醒记录表
  - 验证
    - 日期边界
    - 多频率
    - 附件权限
    - 提醒去重
    - 多租户隔离
```

## 阶段拆解

### 阶段一：基础模型与执照 CRUD

目标：

- 建立执照主表。
- 建立频率明细表。
- 实现执照新增、编辑、删除、查询。
- 前端能录入台站、频率、起始日期、截止日期、用途。

任务：

| 编号 | 任务 | 产物 | 优先级 |
| --- | --- | --- | --- |
| BE-01 | 新建 `radio_license` 后端模块 | Django app 目录 | P0 |
| BE-02 | 新增执照主表模型 | `RadioLicense` | P0 |
| BE-03 | 新增频率明细模型 | `RadioLicenseFrequency` | P0 |
| BE-04 | 编写数据库迁移 | migration 文件 | P0 |
| BE-05 | 实现列表接口 | `GET /api/radio-license/` | P0 |
| BE-06 | 实现新增/编辑接口 | `POST /api/radio-license/` | P0 |
| BE-07 | 实现删除接口 | `DELETE /api/radio-license/` | P0 |
| FE-01 | 新建前端页面目录 | `src/pages/radioLicense` | P0 |
| FE-02 | 实现列表页 | `index.js`、`Table.js` | P0 |
| FE-03 | 实现新增/编辑表单 | `Form.js` | P0 |
| FE-04 | 实现前端 store | `store.js` | P0 |

退出标准：

- 能新增一条执照记录。
- 能录入多个频率。
- 能在列表看到状态和剩余天数。
- 能编辑和删除执照。

### 阶段二：附件管理

目标：

- 支持上传执照、许可证、许可批复等附件。
- 支持附件查看、下载、删除。
- 下载必须鉴权。

任务：

| 编号 | 任务 | 产物 | 优先级 |
| --- | --- | --- | --- |
| BE-08 | 新增附件模型 | `RadioLicenseAttachment` | P0 |
| BE-09 | 实现附件上传接口 | `POST /api/radio-license/<id>/attachments/` | P0 |
| BE-10 | 实现附件下载接口 | 鉴权下载接口 | P0 |
| BE-11 | 实现附件删除接口 | `DELETE /api/radio-license/attachments/` | P0 |
| FE-05 | 实现附件上传组件 | `AttachmentList.js` | P0 |
| FE-06 | 附件类型选择 | 执照/许可证/许可批复/其他 | P0 |
| FE-07 | 附件列表展示 | 文件名、类型、大小、上传人 | P1 |

退出标准：

- 能给执照上传多个附件。
- 能区分附件类型。
- 有权限用户可以下载。
- 无权限用户不能绕过接口下载。

### 阶段三：到期提醒

目标：

- 到期前 30 天自动提醒。
- 已过期执照显示已过期状态。
- 同一周期不重复生成提醒。

任务：

| 编号 | 任务 | 产物 | 优先级 |
| --- | --- | --- | --- |
| BE-12 | 新增提醒记录模型 | `RadioLicenseReminder` | P0 |
| BE-13 | 编写状态计算函数 | `calculate_license_status` | P0 |
| BE-14 | 实现定时扫描任务 | `scan_radio_license_expiration` | P0 |
| BE-15 | 接入 Celery Beat | 每日 08:00 执行 | P0 |
| BE-16 | 实现提醒列表/处理接口 | 已读、已处理 | P1 |
| FE-08 | 列表顶部到期提醒条 | `Alert` | P0 |
| FE-09 | 详情页提醒记录 | `ReminderList.js` | P1 |

退出标准：

- 30 天内到期的执照自动生成提醒。
- 已过期执照状态正确。
- 同一个截止日期周期不会重复刷提醒。
- 用户可以处理提醒。

目标：

- 核心验收项通过。

5. 到期状态计算。
