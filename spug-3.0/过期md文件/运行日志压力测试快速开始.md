# 运行日志压力测试 - 快速开始

## 一键运行（推荐）

### Windows PowerShell
```powershell
# 1. 交互式模式（适合调试）
.\test-runlog-load.ps1 -Interactive

# 2. 命令行模式（50用户，5分钟）
.\test-runlog-load.ps1

# 3. 高压测试（100用户，10分钟）
.\test-runlog-load.ps1 -Users 100 -Duration 10m
```

### Linux/Mac
```bash
# 1. 交互式模式
chmod +x test-runlog-load.sh
./test-runlog-load.sh -i

# 2. 命令行模式
./test-runlog-load.sh

# 3. 高压测试
./test-runlog-load.sh -u 100 -d 10m
```

## 手动运行 Locust

### 步骤 1: 启动服务
确保 TDYW 服务正在运行：
```bash
docker ps | grep tdyw
```

### 步骤 2: 运行测试
```bash
# Windows (推荐方式)
python -m locust -f locustfile/locustfile_runlog.py -H http://localhost:80

# Linux/Mac (如果直接运行 locust 不行)
python -m locust -f locustfile/locustfile_runlog.py -H http://localhost:80
```

### 步骤 3: 访问 Web 界面
打开浏览器访问：`http://localhost:8089`

### 步骤 4: 配置测试参数
- **Number of users**: 50（并发用户数）
- **Spawn rate**: 10（每秒启动用户数）
- **Host**: `http://localhost:80`

点击 **Start swarming** 开始测试。

## 命令行模式（无图形界面）

```bash
# Windows (推荐方式)
python -m locust -f locustfile/locustfile_runlog.py \
    -H http://localhost:80 \
    --users 100 \
    --spawn-rate 20 \
    --run-time 5m \
    --headless \
    --csv runlog_test

# Linux/Mac
python -m locust -f locustfile/locustfile_runlog.py \
    -H http://localhost:80 \
    --users 100 \
    --spawn-rate 20 \
    --run-time 5m \
    --headless \
    --csv runlog_test
```

## 清理测试数据

测试完成后，清理测试数据：

```sql
DELETE FROM runlog_run_log_updates
WHERE created_at >= DATE_SUB(NOW(), INTERVAL 1 HOUR);

DELETE FROM runlog_run_logs
WHERE created_at >= DATE_SUB(NOW(), INTERVAL 1 HOUR);
```

## 常见问题

### Q: Locust 连不上服务？
**A**: 检查：
1. 服务是否运行：`docker ps | grep tdyw`
2. Host 地址是否正确：
   - Windows 本地：`http://localhost:80`
   - Docker：`http://host.docker.internal:80`
   - 远程：`http://IP:PORT`

### Q: 出现 403 错误？
**A**: 检查：
1. 测试账号是否有 `runlog.runlog.*` 权限
2. 是否正确登录获取了 Token

### Q: 响应时间很长？
**A**:
1. 检查数据库慢查询
2. 检查是否有死锁
3. 检查服务器资源占用

### Q: 测试数据越来越多？
**A**: 测试完成后清理数据（见上方 SQL）
