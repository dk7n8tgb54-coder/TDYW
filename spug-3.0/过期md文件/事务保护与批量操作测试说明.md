## 手动验证步骤

### 1. 验证事务保护

```python
# 在Django shell中测试
python manage.py shell

from apps.document.tasks.batch import batch_delete_transfers, batch_cancel_transfers
from apps.document.models import DocumentTransfer
from apps.account.models import User

# 获取测试用户
user = User.objects.first()
tenant_id = user.tenant_id

# 创建测试数据
transfers = []
for i in range(5):
    t = DocumentTransfer.objects.create(
        tenant_id=tenant_id,
        user=user,
        status='COMPLETED',
        file_name=f'test_{i}.pdf',
        file_size=1024000,
        file_path=f'/test/{i}.pdf',
        file_hash=f'hash_{i}',
        folder_id=1,
        is_public=False,
        total_chunks=10,
        uploaded_chunks=10,
        progress=100,
    )
    transfers.append(t)

# 执行批量删除（同步执行）
result = batch_delete_transfers.run(
    transfer_ids=[t.id for t in transfers],
    request_user_id=user.id,
    request_tenant_id=tenant_id
)

print(f"删除结果: {result}")
# 期望输出: {'deleted': 5, 'skipped': 0, 'total': 5, 'errors': []}
```

## 故障排查

### 问题1: "No module named 'apps'"

**解决方案**:
```bash
export PYTHONPATH=/data/spug/spug_api
export DJANGO_SETTINGS_MODULE=spug.settings
```

### 问题2: 数据库连接失败

**解决方案**:
检查 `spug_api/spug/settings.py` 中的数据库配置，确保:
- MySQL服务正在运行
- 数据库用户有正确权限
- 数据库名正确

### 问题3: Celery任务无法执行

**解决方案**:
Celery任务在测试中使用 `task.run()` 方法同步执行，无需启动Celery Worker。
