## 一、事务保护实现 (P1-B3)

### 修改文件
- `spug_api/apps/document/tasks/batch.py`

### 核心改进

#### 1. 添加事务导入
```python
from django.db import transaction
```

#### 2. 批量删除任务 (`batch_delete_transfers`)
```python
with transaction.atomic():
    # 【事务保护】使用 select_for_update 避免并发冲突
    transfer = DocumentTransfer.objects.select_for_update().get(id=transfer_id)
    
    # 权限检查...
    # 分片清理（事务外执行，避免IO阻塞）
    # 删除记录
```

#### 3. 批量取消任务 (`batch_cancel_transfers`)
```python
with transaction.atomic():
    transfer = DocumentTransfer.objects.select_for_update().get(id=transfer_id)
    transfer.status = 'CANCELED'
    transfer.save()
```

### 事务保护效果

| 特性 | 说明 |
|-----|------|
| **原子性** | 每条记录的操作都在独立事务中执行 |
| **并发控制** | `select_for_update()` 获取行级锁，防止并发冲突 |
| **错误隔离** | 单条记录失败不影响其他记录的处理 |
| **IO分离** | 分片文件清理在事务外执行，避免阻塞 |

## 二、批量操作前端实现 (P1-2)

### 修改文件
1. `spug_web/src/pages/document/stores/upload/core/transfer.js`
2. `spug_web/src/pages/document/stores/upload/core/index.js`

### 核心改进

#### 1. TransferStore 新增批量方法

**batchPauseTransfers(ids)**
```javascript
async batchPauseTransfers(ids) {
  const hideLoading = message.loading(`正在暂停 ${ids.length} 个传输任务...`, 0);
  try {
    const result = await http.post(API_ENDPOINTS.TRANSFERS_BATCH_PAUSE, { 
      transfer_ids: ids 
    });
    message.success(`已暂停 ${result.updated} 个传输任务`);
    return { success: true, ...result };
  } catch (error) {
    // 异常处理：区分403/500/网络错误
    return { success: false, error };
  } finally {
    hideLoading();  // 确保loading关闭
  }
}
```

**batchResumeTransfers(ids)**
```javascript
async batchResumeTransfers(ids) {
  // 类似实现，调用 TRANSFERS_BATCH_RESUME 端点
}
```

**batchCancelTransfers(ids)**
```javascript
async batchCancelTransfers(ids) {
  // 类似实现，调用 TRANSFERS_BATCH_CANCEL 端点
}
```

#### 2. 核心方法使用批量API

**pauseAll() 改进**
```javascript
// 改进前：循环逐个调用
for (const id of transferIds) {
  await this.transferStore.updateTransferStatus(id, 'PAUSED');
}

// 改进后：批量API
if (transferIds.length > 0) {
  await this.transferStore.batchPauseTransfers(transferIds);
}
```

**resumeAll() 改进**
```javascript
// 使用 batchResumeTransfers 替代循环调用
if (transferIds.length > 0) {
  await this.transferStore.batchResumeTransfers(transferIds);
}
```

**cancelAll() 改进**
```javascript
// 改为异步函数，使用 batchCancelTransfers
if (transferIds.length > 0) {
  await this.transferStore.batchCancelTransfers(transferIds);
}
```
