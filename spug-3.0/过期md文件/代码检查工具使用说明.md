## 脚本使用详解

### 1. lint-check.sh / lint-check.ps1

**用途**：统一运行 ESLint 和 Flake8 检查

**使用方法**：
```bash
# Linux/macOS
./scripts/lint-check.sh

# Windows PowerShell
.\scripts\lint-check.ps1
```

**功能**：
- 自动检测前端代码修改并运行 ESLint
- 自动检测后端代码修改并运行 Flake8
- 彩色输出检查结果
- 失败时返回非零退出码

---

### 2. code_quality_check.py

**用途**：检查代码质量指标（文件行数、函数行数、复杂度）

**使用方法**：
```bash
python scripts/code_quality_check.py
```

**检查规则**：
- 文件行数 ≤ 1000行
- 函数行数 ≤ 200行
- 复杂度 ≤ 15

**输出**：
- 错误列表（ERROR）：函数行数超标
- 警告列表（WARN）：复杂度过高

---

### 3. install-git-hooks.sh / install-git-hooks.ps1

**用途**：安装 Git 预提交钩子，在提交前自动检查代码

**使用方法**：
```bash
# Linux/macOS
./scripts/install-git-hooks.sh

# Windows PowerShell
.\scripts\install-git-hooks.ps1
```

**安装后效果**：
每次执行 `git commit` 时，会自动：
1. 检查修改的 JS 文件（ESLint）
2. 检查修改的 Python 文件（Flake8）
3. 检查失败时阻止提交

**跳过检查**：
```bash
git commit --no-verify -m "your message"
```

## 手动检查

### 前端检查（ESLint）

```bash
cd spug_web

# 检查代码
npm run lint

# 自动修复问题
npm run lint:fix

# 生成 HTML 报告
npm run lint:report

# 检查指定目录
npx eslint src/pages/document --ext .js,.jsx

# 检查单个文件
npx eslint src/pages/document/Explorer/index.js
```

### 后端检查（Flake8）

```bash
cd spug_api

# 检查所有代码
flake8 apps/ libs/ consumer/

# 显示统计信息
flake8 apps/ libs/ consumer/ --count --statistics

# 检查指定目录
flake8 apps/document/

# 检查单个文件
flake8 apps/document/views/file/upload.py

# 显示源码
flake8 apps/ --show-source
```

## Git 预提交钩子

### 安装钩子

```bash
# Linux/macOS
./scripts/install-git-hooks.sh

# Windows
.\scripts\install-git-hooks.ps1
```

### 钩子行为

安装后，`.git/hooks/pre-commit` 文件会被创建。每次 `git commit` 时：

1. 获取暂存区的文件列表
2. 如果有 JS/JSX 文件修改，运行 ESLint
3. 如果有 Python 文件修改，运行 Flake8
4. 任何检查失败都会阻止提交

### 临时跳过钩子

```bash
# 跳过所有钩子
git commit --no-verify -m "your message"

# 或
SKIP=pre-commit git commit -m "your message"
```

### 卸载钩子

```bash
rm .git/hooks/pre-commit
```

## 配置说明

### ESLint 配置（spug_web/.eslintrc.js）

| 规则 | 级别 | 配置值 | 说明 |
|-----|------|-------|------|
| `max-lines` | **error** | 1000 | 文件行数限制 |
| `max-lines-per-function` | **error** | 200 | 函数行数限制 |
| `complexity` | warn | 15 | 圈复杂度限制 |
| `max-depth` | warn | 4 | 最大嵌套深度 |
| `max-len` | warn | 120 | 行长度限制 |
| `no-unused-vars` | error | - | 禁止未使用变量 |

**忽略文件**：`.eslintignore`
- `node_modules/`
- `build/`
- `public/lib/`

### Flake8 配置（spug_api/.flake8 或 setup.cfg）

| 配置项 | 值 | 说明 |
|-------|-----|------|
| `max-line-length` | 120 | 行长度限制 |
| `max-complexity` | 15 | 圈复杂度限制 |
| `max-doc-length` | 1000 | 文档长度限制 |

**忽略目录**：
- `migrations/`
- `__pycache__/`
- `venv/`, `.venv/`
- `tests/`

## 常见问题

### Q1: ESLint 报告错误但无法自动修复

**A**: 手动修复或临时调整规则：
```javascript
// .eslintrc.js
rules: {
  'specific-rule': 'off'  // 临时关闭某规则
}
```

### Q2: Flake8 未安装

**A**:
```bash
pip install flake8
```

### Q3: 某些文件需要放宽限制

**A**: 在配置中添加例外：

**ESLint**（在 .eslintrc.js）：
```javascript
overrides: [
  {
    files: ['specific-file.js'],
    rules: {
      'max-lines': 'off'
    }
  }
]
```

**Flake8**（在 setup.cfg）：
```ini
per-file-ignores =
    specific_file.py:E501
```

### Q4: 代码检查脚本权限不足（Linux/macOS）

**A**:
```bash
chmod +x scripts/lint-check.sh
chmod +x scripts/install-git-hooks.sh
```

### Q5: Python 脚本报 UnicodeEncodeError

**A**: Windows 系统已修复，如仍有问题请使用：
```bash
chcp 65001
```

### Q6: 如何只检查修改的文件

**A**: 使用 Git 钩子或在 CI 中：
```bash
# 获取修改的文件
FILES=$(git diff --cached --name-only --diff-filter=ACM | grep '\.js$')
if [ -n "$FILES" ]; then
    npx eslint $FILES
fi
```

## CI/CD 集成

### GitHub Actions 示例

```yaml
# .github/workflows/lint.yml
name: Lint Check

on: [push, pull_request]

jobs:
  lint:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      
      - name: Setup Node
        uses: actions/setup-node@v2
        with:
          node-version: '16'
      
      - name: Setup Python
        uses: actions/setup-python@v2
        with:
          python-version: '3.9'
      
      - name: Install Flake8
        run: pip install flake8
      
      - name: Frontend Lint
        run: |
          cd spug_web
          npm ci
          npm run lint
      
      - name: Backend Lint
        run: |
          cd spug_api
          flake8 apps/ libs/ consumer/
      
      - name: Code Quality Check
        run: python scripts/code_quality_check.py
```
