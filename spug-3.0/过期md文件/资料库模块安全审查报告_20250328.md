### 🟠 P1级问题（中风险）

#### 问题1：传输记录查询租户过滤不完整
- **文件**: `views/transfer/list.py`
- **行号**: 36-54
- **问题描述**: `TransferListView.get()` 在查询传输记录时，虽然使用了 `request_user.tenant_id` 进行过滤，但没有统一使用 `apply_tenant_filter` 方法。当 `is_public` 参数未提供时，只通过 `user` 过滤，存在租户隔离不完整的风险。
- **风险**: 中
- **修复建议**: 统一使用 `apply_tenant_filter` 进行租户过滤

```python
# 当前代码
if hasattr(form, 'is_public') and form.is_public is not None:
    if form.is_public:
        queryset = DocumentTransfer.objects.filter(user=request_user, is_public=True)
    else:
        queryset = DocumentTransfer.objects.filter(user=request_user, is_public=False)
        if hasattr(request_user, 'tenant_id') and request_user.tenant_id:
            queryset = queryset.filter(tenant_id=request_user.tenant_id)

# 建议修复
queryset = DocumentTransfer.objects.filter(user=request_user)
queryset = apply_tenant_filter(queryset, request_user, is_public=form.is_public)
```

- **风险**: 中

def check_rate_limit(user_id, rate_limit_config):
    # TEMPORARILY DISABLED FOR LOAD TESTING

#### 问题4：Celery任务权限验证不一致

- **行号**: 402-466, 558-641

- **风险**: 低
- **修复建议**: 添加 `created_by_id` 空值检查

#### 问题7：文件路径拼接潜在风险
- **文件**: `libs/document_utils.py`
- **行号**: 121-144
- **问题描述**: `get_document_relative_path()` 使用 f-string 拼接路径，虽然 `folder_id` 经过类型转换，但没有完整的路径遍历防护。
- **风险**: 低
- **修复建议**: 使用 `os.path.join` 并验证路径安全

#### 问题8：MD5哈希验证不完整
- **文件**: 多个文件
- **问题描述**: 虽然对 `file_hash` 进行了长度验证（32位），但没有验证是否只包含十六进制字符。
- **风险**: 低

#### 问题9：文件夹名称长度未限制

- **问题描述**: 创建文件夹时只验证了文件名安全性，没有限制名称长度。

#### 问题11：软删除文件查询统计信息不准确
