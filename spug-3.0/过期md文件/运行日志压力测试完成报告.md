## 核心测试点

### 1. 租户隔离（P0）
- **验证点**: 不同租户的数据互不可见
- **测试方法**: 使用同一账号创建和查询，验证只返回当前租户数据
- **预期结果**: 无跨租户数据泄露

### 2. 序号计算正确性（P0）
- **验证点**: 同一天内的动态序号正确递增
- **测试方法**: 多个并发用户同时为同一事件添加动态
- **预期结果**: 序号不重复，正确递增

### 3. 编辑时间限制（P1）
- **验证点**: 24小时内的动态可编辑，超时不可编辑
- **测试方法**: 尝试编辑不同时间的动态
- **预期结果**: 符合时间限制规则

### 4. 状态流转（P1）
- **验证点**: 状态流转符合业务规则
- **测试方法**: 尝试各种状态变更
- **预期结果**: 状态流转符合规则，非法流转被拒绝

### 5. 级联删除（P2）
- **验证点**: 删除事件时级联删除动态
- **测试方法**: 删除事件后检查动态
- **预期结果**: 关联动态全部删除，统计信息更新

### 6. 并发冲突（P0）
- **验证点**: 高并发下数据一致性
- **测试方法**: 多用户同时操作同一资源
- **预期结果**: 无数据不一致，无死锁

## 快速开始

### Windows PowerShell
```powershell
# 交互式模式
.\test-runlog-load.ps1 -Interactive

# 命令行模式（50用户，5分钟）
.\test-runlog-load.ps1

# 高压测试（100用户，10分钟）
.\test-runlog-load.ps1 -Users 100 -Duration 10m
```

### Linux/Mac
```bash
# 交互式模式
chmod +x test-runlog-load.sh
./test-runlog-load.sh -i

# 命令行模式
./test-runlog-load.sh

# 高压测试
./test-runlog-load.sh -u 100 -d 10m
```

### 手动运行
```bash
locust -f locustfile_runlog.py -H http://localhost:80
```

## 常见问题

### Q1: Locust 连不上服务？
**A**: 检查服务是否运行，Host 地址是否正确：
- Windows 本地：`http://localhost:80`
- Docker：`http://host.docker.internal:80`
- 远程：`http://IP:PORT`

### Q2: 出现 403 错误？
**A**: 检查测试账号是否有 `runlog.runlog.*` 权限

### Q3: 响应时间很长？
**A**: 检查数据库慢查询、死锁、服务器资源占用

### Q4: 测试数据越来越多？
**A**: 测试完成后清理数据（见上方 SQL）
