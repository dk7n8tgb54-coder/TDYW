## 二、待执行的部署操作

### 2.1 数据库迁移

**需要在Docker容器中执行：**

```bash
# 进入容器
docker exec -it tdyw /bin/sh

# 执行迁移
cd /data/spug/spug_api
python manage.py makemigrations document --name add_pending_clean_fields
python manage.py migrate

# 退出
exit
```

**迁移将添加的字段：**
- `is_pending_clean` (BooleanField): 待清理标记
- `clean_retry_count` (IntegerField): 清理重试次数  
- `last_clean_attempt` (DateTimeField): 上次清理尝试时间

### 2.2 Celery服务重启

```bash
# 重启Beat和Worker
docker exec tdyw supervisorctl restart spug-beat spug-worker

# 检查状态
docker exec tdyw supervisorctl status spug-beat spug-worker
```

### 2.3 验证配置
