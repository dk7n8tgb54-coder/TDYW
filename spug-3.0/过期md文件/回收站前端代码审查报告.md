### 3.2 ⚠️ 改进建议

#### 3.2.1 性能优化建议

**问题1**: 文件夹树每次弹窗都重新加载
```javascript
// RestoreModal.js 第35-39行
React.useEffect(() => {
  if (store.restoreVisible && store.restoreMode === 'custom') {
    loadFolderTree();  // 每次都重新加载
  }
}, [store.restoreVisible, store.restoreMode]);
```

**建议**: 添加缓存机制
```javascript
const [folderTreeCache, setFolderTreeCache] = React.useState(null);

React.useEffect(() => {
  if (store.restoreVisible && store.restoreMode === 'custom' && !folderTreeCache) {
    loadFolderTree();
  }
}, [store.restoreVisible, store.restoreMode, folderTreeCache]);
```

**问题2**: 表格滚动性能
```javascript
// index.js 第366行
scroll={{ x: 1200 }}
```

**建议**: 考虑使用虚拟滚动处理大数据量
```javascript
// 对于大量数据，建议使用 react-window 或 antd 的虚拟滚动
import { Table } from 'antd';
// 设置 scroll.y 启用虚拟滚动
scroll={{ x: 1200, y: 500 }}
```

#### 3.2.2 代码结构建议

**问题3**: RestoreModal中的图标逻辑可优化
```javascript
// RestoreModal.js 第146-150行
{service.getFileIcon(file.file_type, file.name) === 'image' ? (
```

#### 3.2.3 错误处理建议

**问题4**: API错误处理可以更细化
```javascript
// service.js
export function restoreFiles(data) {
  return http.post('/api/document/recycle-bin/restore/', data);
}
```

**建议**: 添加统一的错误处理中间件
```javascript
export async function restoreFiles(data) {
  try {
    return await http.post('/api/document/recycle-bin/restore/', data);
  } catch (error) {
    if (error.response?.status === 429) {
      message.error('操作过于频繁，请稍后再试');
    } else if (error.response?.data?.code === 403001) {
      message.error('无操作权限');
    }
    throw error;
  }
}
```
