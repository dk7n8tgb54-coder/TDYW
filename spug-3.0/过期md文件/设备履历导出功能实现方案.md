# 设备履历导出功能实现方案

## 一、需求概述

为设备履历模块添加 Excel 导出功能，支持导出当前筛选条件下的设备列表数据。

## 二、实现步骤

### 2.1 安装依赖

```bash
cd spug_web
npm install xlsx
```

### 2.2 修改 Table.js

**文件路径**: `spug_web/src/pages/device/Table.js`

#### 1) 导入依赖
```javascript
import { ExportOutlined } from '@ant-design/icons';
import * as XLSX from 'xlsx';
import moment from 'moment';
```

#### 2) 添加导出方法
```javascript
handleExport = () => {
  const { records } = store;
  
  if (records.length === 0) {
    message.warning('没有可导出的数据');
    return;
  }

  try {
    // 准备导出数据
    const exportData = records.map(item => ({
      '设备编号': item.device_sn || '',
      '设备名称': item.device_name || '',
      '设备型号': item.device_model || '',
      '当前设备状况': this.getStatusText(item.current_status),
      '使用单位': item.use_unit || '',
      '负责人': item.responsible_user_name || '',
      '创建时间': item.created_at || ''
    }));

    // 创建工作簿和工作表
    const ws = XLSX.utils.json_to_sheet(exportData);
    const wb = XLSX.utils.book_new();
    XLSX.utils.book_append_sheet(wb, ws, '设备履历');

    // 生成文件名
    const now = moment().format('YYYYMMDD_HHmmss');
    const fileName = `设备履历_${now}.xlsx`;

    // 保存文件
    XLSX.writeFile(wb, fileName);

    message.success(`成功导出 ${records.length} 条记录`);
  } catch (error) {
    console.error('导出失败:', error);
    message.error('导出失败，请重试');
  }
};

// 状态码转文本
getStatusText = (status) => {
  const statusMap = {
    '1': '正常',
    '2': '故障',
    '3': '维修中',
    '4': '停用',
    '5': '报废'
  };
  return statusMap[status] || status || '-';
};
```

#### 3) 添加导出按钮
在 `render()` 方法的按钮区域添加导出按钮：

### 2.3 完整代码参考

```javascript
/**

 */
import React from 'react';
import { observer } from 'mobx-react';
import { Table, Tag, Modal, message } from 'antd';
import { PlusOutlined, ExportOutlined } from '@ant-design/icons';
import { AuthButton } from 'components';
import store from './store';
import { getDeviceStatusConfig } from './constants';
import * as XLSX from 'xlsx';
import moment from 'moment';

@observer
class ComTable extends React.Component {
  componentDidMount() {
    store.fetchRecords()
    store.fetchFilterOptions()
  }

  handleDelete = (id) => {
    Modal.confirm({
      title: '确认删除',
      content: '确定要删除该设备档案吗？删除后将无法恢复。',
      okText: '确定',
      cancelText: '取消',
      onOk: () => {
        store.handleDelete(id).then(() => message.success('删除成功'));
      }
    });
  }

  handleExport = () => {
    const { records } = store;
    
    if (records.length === 0) {
      message.warning('没有可导出的数据');
      return;
    }

    try {
      const exportData = records.map(item => ({
        '设备编号': item.device_sn || '',
        '设备名称': item.device_name || '',
        '设备型号': item.device_model || '',
        '当前设备状况': this.getStatusText(item.current_status),
        '使用单位': item.use_unit || '',
        '负责人': item.responsible_user_name || '',
        '创建时间': item.created_at || ''
      }));

      const ws = XLSX.utils.json_to_sheet(exportData);
      const wb = XLSX.utils.book_new();
      XLSX.utils.book_append_sheet(wb, ws, '设备履历');

      const now = moment().format('YYYYMMDD_HHmmss');
      const fileName = `设备履历_${now}.xlsx`;

      XLSX.writeFile(wb, fileName);

      message.success(`成功导出 ${records.length} 条记录`);
    } catch (error) {
      console.error('导出失败:', error);
      message.error('导出失败，请重试');
    }
  };

  getStatusText = (status) => {
    const statusMap = {
      '1': '正常',
      '2': '故障',
      '3': '维修中',
      '4': '停用',
      '5': '报废'
    };
    return statusMap[status] || status || '-';
  };

  render() {
    const columns = [
      { title: '设备编号', dataIndex: 'device_sn', width: 150 },
      { title: '设备名称', dataIndex: 'device_name', width: 120 },
      { title: '设备型号', dataIndex: 'device_model', width: 120 },
      {
        title: '当前设备状况',
        dataIndex: 'current_status',
        width: 120,
        render: (status) => {
          const config = getDeviceStatusConfig(status);
          return <Tag color={config.color}>{config.text}</Tag>;
        }
      },
      { title: '使用单位', dataIndex: 'use_unit', width: 150 },
      { title: '负责人', dataIndex: 'responsible_user_name', width: 100 },
      {
        title: '操作',
        width: 200,
        fixed: 'right',
        render: (text, record) => (
          <React.Fragment>
            <AuthButton auth="device.device_resume.view" type="link" onClick={() => store.showDetail(record)}>详情</AuthButton>
            <AuthButton auth="device.device_resume.edit" type="link" onClick={() => store.showForm(record)}>编辑</AuthButton>
            <AuthButton auth="device.device_resume.delete" type="link" danger onClick={() => this.handleDelete(record.id)}>删除</AuthButton>
          </React.Fragment>
        )
      }
    ];

    return (
      <React.Fragment>
        <div style={{ marginBottom: 16 }}>
          <AuthButton auth="device.device_resume.add" type="primary" icon={<PlusOutlined />} onClick={() => store.showForm({})}>
            新增设备履历
          </AuthButton>
          <AuthButton 
            auth="device.device_resume.view" 
            icon={<ExportOutlined />} 
            onClick={this.handleExport}
            style={{ marginLeft: 8 }}
          >
            导出
          </AuthButton>
        </div>
        <Table
          loading={store.isFetching}
          dataSource={store.records}
          rowKey="id"
          columns={columns}
          pagination={{
            current: store.page,
            pageSize: store.pageSize,
            total: store.total,
            showSizeChanger: true,
            showQuickJumper: true,
            showTotal: (total) => `共 ${total} 条`,
            onChange: (page, pageSize) => {
              store.page = page;
              store.pageSize = pageSize;
              store.fetchRecords();
            }
          }}
          scroll={{ x: 1200 }}
        />
      </React.Fragment>
    );
  }
}

export default ComTable
```

## 三、功能特性

| 特性 | 说明 |
|------|------|
| 数据范围 | 导出当前页筛选后的数据 |
| 文件格式 | Excel (.xlsx) |
| 文件名格式 | `设备履历_YYYYMMDD_HHmmss.xlsx` |
| 状态转换 | 自动将状态码转换为中文文本 |
| 权限控制 | 使用 `device.device_resume.view` 权限 |
| 空数据提示 | 无数据时提示"没有可导出的数据" |

## 四、注意事项

1. **依赖已存在**：`xlsx` 和 `moment` 已在系统升级管理模块中使用，无需重复安装
2. **权限继承**：导出按钮使用与查看详情相同的权限 `device.device_resume.view`
3. **数据一致性**：导出的是当前筛选条件下的数据，与列表显示一致
4. **性能考虑**：当前实现导出当前页数据，如需导出全部数据需调用不分页接口
