# 回收站审计日志脱敏与追溯方案

## 问题背景

修复日志脱敏后，如何在保证安全的同时，确保管理员能够追溯"谁删除了什么文件"？

## 核心原则

**分层处理原则**：
- **应用日志**（普通）：脱敏处理，防止信息泄露
- **审计日志**（安全）：完整记录，用于追溯
- **数据库记录**（持久）：操作历史永久保存

---

## 方案对比

| 方案 | 实现方式 | 优点 | 缺点 | 推荐度 |
|------|----------|------|------|--------|
| **方案1** | 扩展审计日志函数 | 简单直接，立即生效 | 日志文件可能变大 | ⭐⭐⭐⭐⭐ |
| **方案2** | 分离存储审计日志 | 安全性最高，支持审计查询 | 需要数据库迁移 | ⭐⭐⭐⭐ |
| **方案3** | 数据库软删除记录 | 数据永久保存，可恢复 | 占用存储空间 | ⭐⭐⭐⭐ |

**创建操作历史模型**：

```python
# models.py
class DocumentOperationLog(models.Model):
    """资料库操作日志（永久保存）"""
    
    ACTION_CHOICES = [
        ('UPLOAD', '上传'),
        ('DOWNLOAD', '下载'),
        ('DELETE', '删除'),
        ('RESTORE', '恢复'),
        ('PERMANENT_DELETE', '彻底删除'),
        ('COPY', '复制'),
        ('MOVE', '移动'),
        ('RENAME', '重命名'),
    ]
    
    action = models.CharField(max_length=20, choices=ACTION_CHOICES)
    user_id = models.IntegerField()
    username = models.CharField(max_length=100)
    tenant_id = models.CharField(max_length=50)
    
    # 资源信息
    resource_type = models.CharField(max_length=20)  # FILE/FOLDER
    resource_id = models.IntegerField()
    resource_name = models.CharField(max_length=255)  # 文件名/文件夹名
    
    # 详细信息（JSON格式）
    details = models.JSONField(default=dict)
    # 示例: {"file_size": 1024000, "file_path": "/data/...", "is_public": false}
    
    created_at = models.DateTimeField(auto_now_add=True)
    ip_address = models.CharField(max_length=50, null=True)
    user_agent = models.TextField(null=True)
    
    class Meta:
        db_table = 'document_operation_logs'
        ordering = ['-created_at']
        indexes = [
            models.Index(fields=['tenant_id', 'created_at']),
            models.Index(fields=['user_id', 'created_at']),
            models.Index(fields=['action', 'created_at']),
        ]
```

**修改 `log_operation` 函数**：

```python
def log_operation(action, user, resource_type, resource_id, **kwargs):
    """
    统一的审计日志函数 - 同时记录到日志文件和数据库
    """
    tenant_id = getattr(user, 'tenant_id', 'N/A')
    is_public = kwargs.get('is_public', False)
    
    # 1. 记录到应用日志（脱敏）
    safe_details = {k: v for k, v in kwargs.items() 
                   if k not in ['file_path', 'file_name']}
    details_str = ', '.join([f'{k}={v}' for k, v in safe_details.items()])
    
    logger.info(
        f'[TenantAudit] Action={action}, User={user.username}, '
        f'Tenant={tenant_id}, Type={resource_type}, ID={resource_id}, {details_str}'
    )
    
    # 2. 记录到数据库（完整信息，受保护）
    try:
        from ..models import DocumentOperationLog
        DocumentOperationLog.objects.create(
            action=action,
            user_id=user.id,
            username=user.username,
            tenant_id=tenant_id,
            resource_type=resource_type,
            resource_id=resource_id,
            resource_name=kwargs.get('file_name') or kwargs.get('folder_name', ''),
            details={
                'file_size': kwargs.get('file_size'),
                'file_path': kwargs.get('file_path'),
                'is_public': is_public,
                'restore_mode': kwargs.get('restore_mode'),
                # 其他详细信息...
            }
        )
    except Exception as e:
        logger.error(f'[Audit] 数据库审计日志记录失败: {e}')
```

**管理后台查询界面**：

```python
# views.py
class OperationLogView(View):
    """操作日志查询（仅管理员）"""
    
    @auth('document.audit.view')
    def get(self, request):
        """查询操作日志"""
        form, error = JsonParser(
            Argument('action', required=False),
            Argument('user_id', type=int, required=False),
            Argument('start_date', required=False),
            Argument('end_date', required=False),
            Argument('keyword', required=False),  # 搜索文件名
        ).parse(request.GET)
        
        if error:
            return json_response(error=error)
        
        qs = DocumentOperationLog.objects.all()
        
        # 非管理员只能看本租户
        if not request.user.is_supper:
            qs = qs.filter(tenant_id=request.user.tenant_id)
        
        # 筛选条件
        if form.action:
            qs = qs.filter(action=form.action)
        if form.user_id:
            qs = qs.filter(user_id=form.user_id)
        if form.start_date:
            qs = qs.filter(created_at__gte=form.start_date)
        if form.end_date:
            qs = qs.filter(created_at__lte=form.end_date)
        if form.keyword:
            qs = qs.filter(resource_name__icontains=form.keyword)
        
        # 分页
        total = qs.count()
        logs = qs[:500]  # 最多返回500条
        
        return json_response(data={
            'items': [log.to_dict() for log in logs],
            'total': total
        })
```

## 查询示例

### 查询用户 zhangyanzhou 的所有删除操作

```sql
SELECT * FROM document_operation_logs 
WHERE username = 'zhangyanzhou' 
  AND action = 'PERMANENT_DELETE'
  AND created_at >= '2024-01-01'
ORDER BY created_at DESC;
```

### 查询谁删除了文件 "机密合同.pdf"

```sql
SELECT username, action, created_at 
FROM document_operation_logs 
WHERE resource_name LIKE '%机密合同%'
ORDER BY created_at DESC;
```

### 统计某租户的文件操作情况

```sql
SELECT action, COUNT(*) as count 
FROM document_operation_logs 
WHERE tenant_id = 'tenant_001'
  AND created_at >= DATE_SUB(NOW(), INTERVAL 30 DAY)
GROUP BY action;
```

## 安全注意事项

1. **数据库访问控制**
   - 操作日志表只能由管理员角色访问
   - 应用日志文件设置严格权限（640）

2. **敏感信息处理**
   - 用户密码、Token等绝不记录
   - 文件内容不记录，只记录元数据

3. **合规性**
   - 符合《网络安全法》日志留存要求
   - 支持等保2.0审计要求
