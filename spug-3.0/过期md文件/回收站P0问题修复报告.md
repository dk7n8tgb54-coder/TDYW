**修复后**:
```python
def _permanent_delete_single(file_id, user_id):
    # 【P0修复】重新查询用户并验证状态
    try:
        user = User.objects.get(id=user_id)
        if not user.is_active:
            return {'id': file_id, 'status': 'failed', 'error': '用户已禁用'}
    except User.DoesNotExist:
        return {'id': file_id, 'status': 'failed', 'error': '用户不存在'}
    
    # 权限校验
    if not user.is_supper and file_obj.created_by != user:
        return {'id': file_id, 'status': 'failed', 'error': '无操作权限'}
```

**修复后**:
```python
if hard:
    # 【P0修复】先删除物理文件
    physical_deleted = True
    if os.path.exists(self.file_path):
        try:
            os.remove(self.file_path)
        except Exception as e:
            logger.error(f'删除物理文件失败: {e}')
            physical_deleted = False
    
    # 【P0修复】只有物理文件删除成功才删除数据库记录
    if physical_deleted:
        super().delete(*args, **kwargs)
    else:

        self.is_pending_clean = True
        self.clean_retry_count = (self.clean_retry_count or 0) + 1
        self.last_clean_attempt = timezone.now()
        self.save(update_fields=['is_pending_clean', 'clean_retry_count', 'last_clean_attempt'])
        raise Exception(f'物理文件删除失败，已标记为待清理: {self.file_path}')
```

```python
def retry_clean_pending_files():
    """重试清理标记为待清理的文件"""
```

### P0.7 硬删除时序问题

**位置**: `spug_api/apps/document/views/file.py`

**修复前**:
```python
def _hard_delete(self, file_obj, is_public=False):
    # 1. 先删除数据库记录
    file_obj.delete(hard=True)
    
    # 2. 再删除物理文件
    if os.path.exists(file_path):
        try:
            os.remove(file_path)
        except Exception as e:
            logger.warning(f'物理文件删除失败：{e}')
```

**修复后**:
```python
def _hard_delete(self, file_obj, is_public=False):
    # 【P0修复】先删除物理文件，再删除数据库记录
    physical_deleted = True
    if os.path.exists(file_path):
        try:
            os.remove(file_path)
        except Exception as e:
            physical_deleted = False
    
    # 只有物理文件删除成功才删除数据库记录
    if physical_deleted:
        file_obj.delete(hard=True)
    else:
        # 标记为待清理状态
        file_obj.is_pending_clean = True
        file_obj.clean_retry_count = (file_obj.clean_retry_count or 0) + 1
        file_obj.last_clean_attempt = timezone.now()
        file_obj.save(update_fields=['is_pending_clean', 'clean_retry_count', 'last_clean_attempt'])
        raise Exception(f'物理文件删除失败，已标记为待清理: {file_path}')
```

**验证方法**:
1. 创建测试文件
2. 调用硬删除接口
3. 验证物理文件和数据库记录都删除
4. 模拟物理文件删除失败，验证数据库记录保留

2. **性能影响**: 大偏移量分页查询性能可能下降，建议后续优化为游标分页
3. **定时任务依赖**: 待清理文件的最终删除依赖Celery定时任务，请确保任务正常运行
