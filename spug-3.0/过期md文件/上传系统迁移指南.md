# 上传系统迁移指南

## 概述

将旧的简单上传系统 (`UploadModal.js` + `UploadFolderModal.js`) 迁移到新的完整功能上传系统。

**迁移原因**:
- 旧系统不支持大文件分片上传 (>32MB会失败)
- 旧系统没有暂停/恢复/断点续传功能
- 旧系统串行上传效率低
- 新系统功能完整，统一维护

## 关键代码示例

### 完整的上传文件按钮处理

```javascript
// Explorer.js

import React from 'react';
import { Button } from 'antd';
import { UploadOutlined } from '@ant-design/icons';
import { uploadCoreStore, uploadUIStore } from './stores';

class Explorer extends React.Component {
  
  // 上传文件按钮点击
  handleUploadFile = () => {
    const input = document.createElement('input');
    input.type = 'file';
    input.multiple = true;
    input.onchange = (e) => {
      const files = Array.from(e.target.files);
      if (files.length > 0) {
        // 【新系统】调用handleFileSelect
        uploadCoreStore.handleFileSelect(files);
        // 【新系统】显示上传面板
        uploadUIStore.showUploadPanel();
      }
    };
    input.click();
  };

  // 上传文件夹按钮点击
  handleUploadFolder = () => {
    const input = document.createElement('input');
    input.type = 'file';
    input.webkitdirectory = true;
    input.directory = true;
    input.onchange = (e) => {
      const files = Array.from(e.target.files);
      if (files.length > 0) {
        // 【新系统】调用handleFolderSelect
        uploadCoreStore.handleFolderSelect(files);
        // 【新系统】显示上传面板
        uploadUIStore.showUploadPanel();
      }
    };
    input.click();
  };

  render() {
    return (
      <div>
        <Button 
          icon={<UploadOutlined />} 
          onClick={this.handleUploadFile}
        >
          上传文件
        </Button>
        <Button 
          onClick={this.handleUploadFolder}
        >
          上传文件夹
        </Button>
        {/* UploadPanel 自动显示上传进度 */}
      </div>
    );
  }
}
```

### 拖拽上传处理

```javascript
// 拖拽区域组件

handleDragOver = (e) => {
  e.preventDefault();
  e.dataTransfer.dropEffect = 'copy';
};

handleDrop = async (e) => {
  e.preventDefault();
  
  const items = e.dataTransfer.items;
  if (!items || items.length === 0) return;
  
  const allFiles = [];
  
  // 递归读取文件夹
  const traverseDirectory = (entry, path = '') => {
    return new Promise((resolve) => {
      if (entry.isFile) {
        entry.file((file) => {
          // 保留相对路径
          file.relativePath = path + file.name;
          allFiles.push(file);
          resolve();
        });
      } else if (entry.isDirectory) {
        const dirReader = entry.createReader();
        dirReader.readEntries(async (entries) => {
          for (const entry of entries) {
            await traverseDirectory(entry, path + entry.name + '/');
          }
          resolve();
        });
      }
    });
  };
  
  // 处理所有拖拽项
  for (let i = 0; i < items.length; i++) {
    const entry = items[i].webkitGetAsEntry();
    if (entry) {
      await traverseDirectory(entry);
    }
  }
  
  if (allFiles.length > 0) {
    // 【新系统】统一使用handleFileSelect
    uploadCoreStore.handleFileSelect(allFiles);
    uploadUIStore.showUploadPanel();
  }
};
```

## 注意事项

1. **浏览器兼容性**: `webkitdirectory` 属性在部分移动端浏览器不支持
2. **文件大小限制**: 新系统支持大文件，但仍受服务器配置限制
3. **并发数控制**: 新系统默认同时上传3个文件，可在 `UPLOAD_CONSTANTS` 中调整
4. **存储空间**: 分片上传会在服务器产生临时文件，确保有足够磁盘空间
5. **Store初始化方式**: 本指南假设使用MobX单例模式，通过 `import { uploadCoreStore } from './stores'` 直接导入使用。如果项目使用Provider注入模式，请确保Store已正确初始化

## 发布策略

**【重要】建议遵循以下发布策略：**

1. **发布时间**：选择业务低峰期发布（如夜间或周末）
2. **状态保持**：
   - 旧系统本身不支持断点续传，用户在旧版有未完成的上传，刷新页面后将无法续传
   - **提示文案**：发布公告告知用户"上传功能已升级，请在发布前完成正在进行的文件上传"
3. **灰度发布**（可选）：
   - 先在内网/测试环境验证1-2周
   - 再对10%用户开放新功能
   - 全量发布前确保无严重Bug
4. **监控指标**：
   - 上传成功率
   - 大文件（>32MB）上传成功率
   - 用户反馈数量
