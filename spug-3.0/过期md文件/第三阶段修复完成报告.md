## 2. P2-1 缓存策略优化

### 实现方案

创建缓存工具模块 `cache_utils.py`：

```python
# 缓存时间配置 (秒)
CACHE_TTL = {
    'staff_list': 300,      # 人员列表 5分钟
    'shift_list': 300,      # 班次列表 5分钟
    'schedule_calendar': 120,  # 排班日历 2分钟
    'swap_list': 60,        # 换班列表 1分钟
    'substitute_list': 60,  # 替班列表 1分钟
}
```

### 缓存Key格式
```
schedule:{model}:{tenant_id}:{suffix}

示例:
- schedule:staff:admin
- schedule:shift:admin
- schedule:schedule:admin:2026-3
```

### 缓存策略说明

**读取缓存** (GET请求):
```python
def get(self, request):
    cache_key = get_cache_key('staff', tenant_id)
    
    def fetch_data():
        # 数据库查询逻辑
        return [x.to_view() for x in staff_list]
    
    data = get_cached_list(cache_key, CACHE_TTL['staff_list'], fetch_data)
    return json_response(data)
```

**清除缓存** (数据变更):
```python
def post(self, request):
    # 创建/更新数据...
    
    # 清除缓存
    invalidate_model_cache('staff', tenant_id)
    return json_response()
```

### 缓存清除策略

| 操作 | 清除的缓存 |
|:---|:---|
| 人员CRUD | `schedule:staff:{tenant_id}*` |
| 班次CRUD | `schedule:shift:{tenant_id}*` |
| 排班CRUD | `schedule:schedule:{tenant_id}*` |
| 换班CRUD | `schedule:swap:{tenant_id}*`, `schedule:schedule:{tenant_id}*` |
| 替班CRUD | `schedule:substitute:{tenant_id}*`, `schedule:schedule:{tenant_id}*` |

## 7. 注意事项

1. **缓存一致性**: 数据变更时会自动清除相关缓存
2. **缓存过期**: 按业务场景设置不同过期时间（1-5分钟）
3. **多租户隔离**: 缓存Key包含租户ID，确保数据隔离
4. **Redis依赖**: 需要确保 Redis 服务正常运行
