```python
    'schedule': crontab(hour=4, minute=0),

        'retention_days': 30,
        'dry_run': False
```

## 五、后续操作

### 5.1 部署到生产环境

1. **合并Celery Beat配置**
   ```python
   # 在 spug/settings.py 中添加
   from celery.schedules import crontab
   from apps.document.celery_beat_schedule import DOCUMENT_BEAT_SCHEDULE
   CELERY_BEAT_SCHEDULE.update(DOCUMENT_BEAT_SCHEDULE)
   ```

2. **重启Celery Beat**
   ```bash
   supervisorctl restart spug-celery-beat
   ```

3. **验证定时任务**
   ```bash
   # 查看Beat日志
   tail -f /var/log/supervisor/spug-celery-beat.log
   ```

### 5.2 手动触发清理

```python
# 测试模式（不实际删除）
from apps.document.tasks import cleanup_soft_deleted_files
cleanup_soft_deleted_files.delay(retention_days=30, dry_run=True)
```
