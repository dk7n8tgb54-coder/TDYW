# 资料库传输列表 - 网盘风格组件

## 实现概述

本目录包含仿照阿里云盘、百度网盘设计的传输列表组件，提供更美观、更直观的文件传输体验。

## 文件结构

```
components/
├── FileTypeIcon.js      # 文件类型图标组件（彩色背景）
├── TransferItem.js      # 单个传输项组件（网盘风格）
├── TransferList.js      # 分组传输列表组件
└── README.md           # 本文档
```

## 主要改进

### 1. 视觉设计
- **彩色图标背景**：根据文件类型显示不同颜色（PDF红色、图片绿色、Word蓝色等）
- **双行信息展示**：文件名 + 状态详情（大小、速度、进度）
- **分组展示**：上传中、已暂停、失败、已完成分组显示

### 2. 状态图标
| 状态 | 图标 | 颜色 |
|------|------|------|
| 等待中 | ⏱️ | 灰色 |
| 计算中 | ⚙️ | 橙色 |
| 上传中 | 🔄 | 蓝色 |
| 已暂停 | ⏸️ | 黄色 |
| 已完成 | ✅ | 绿色 |
| 失败 | ❌ | 红色 |
| 合并中 | 🔄 | 紫色 |

### 3. 新增功能
- **实时速度显示**：上传中显示实时速度（如 2.5 MB/s）
- **已传输大小**：显示已传输 / 总大小（如 2.5 MB / 5 MB）
- **智能按钮**：只显示当前状态可用的操作按钮
- **错误重试**：失败任务显示错误原因和重试按钮

## 注意事项

1. **速度显示**：仅在普通文件上传和分片上传时显示，文件夹上传暂不显示
2. **响应式**：组件支持响应式，但建议最小宽度 480px
3. **兼容性**：依赖 Ant Design 4.x 和 MobX 6.x

## 回滚方法

如需回滚到旧版本，只需恢复 `UploadPanel.js` 文件即可：
```bash
git checkout -- src/pages/document/UploadPanel.js
```

其他新增文件删除即可，不会影响原有功能。
