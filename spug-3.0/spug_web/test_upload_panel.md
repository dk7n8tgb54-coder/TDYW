// 资料库传输列表功能测试说明

## 功能概述

资料库传输列表现在支持以下功能：

1. **全部暂停** - 暂停所有正在上传的任务
2. **全部开始** - 继续所有已暂停的任务
3. **全部取消** - 取消所有正在上传的任务
4. **清空列表** - 清空已完成、已暂停和失败的任务

## 测试步骤

### 1. 测试全部暂停功能

1. 在资料库页面，选择多个文件进行上传（建议选择大文件以便观察）
2. 在传输过程中，点击"全部暂停"按钮
3. **预期结果**：
   - 正在上传的任务应该被中止
   - 任务状态变为"已暂停"
   - 进度条变为黄色
   - 显示"已暂停"提示
   - 按钮变为"全部开始"

### 2. 测试全部开始功能

1. 如果有已暂停的任务，点击"全部开始"按钮
2. **预期结果**：
   - 已暂停的任务重新开始上传
   - 进度继续更新
   - 按钮变回"全部暂停"

### 3. 测试全部取消功能

1. 在有任务正在上传时，点击"全部取消"按钮
2. **预期结果**：
   - 正在上传的任务被中止
   - 任务状态变为"已取消"
   - 显示红色错误提示

### 4. 测试清空列表功能

1. 有已完成、已暂停或失败的任务时，点击"清空列表"按钮
2. **预期结果**：
   - 已完成、已暂停和失败的任务被移除
   - 正在上传的任务保留

## 技术实现

### 关键代码逻辑

1. **CancelToken**: 使用 axios 的 CancelToken 来取消请求
2. **状态管理**:
   - `uploading`: 正在上传
   - `paused`: 已暂停
   - `completed`: 已完成
   - `error`: 失败/已取消

3. **暂停/继续流程**:
   ```
   点击暂停 → isPaused=true → cancel() → 保存file到队列
   点击继续 → isPaused=false → 重新上传保存的file
   ```

### 潜在问题检查

如果功能不工作，请检查以下几点：

1. **axios 版本**: 确保使用的是支持 CancelToken 的版本
2. **错误捕获**: 检查 `axios.isCancel()` 是否正确检测取消
3. **状态更新**: 确认 MobX 的 @action 装饰器正确应用

## 浏览器控制台测试

在浏览器开发者工具控制台输入以下命令测试：

```javascript
// 访问 store
const store = window._store || require('src/pages/document/store');

// 检查当前状态
console.log('isPaused:', store.isPaused);
console.log('uploadQueue:', store.uploadQueue);

// 手动测试暂停
store.pauseAll();

// 手动测试继续
store.resumeAll();

// 手动测试取消
store.cancelAll();
```

## 注意事项

1. 暂停功能会取消当前的 HTTP 请求，继续时会重新上传
2. 取消后的任务状态为"error"，不能继续
3. 暂停的任务点击"清空列表"会被移除
