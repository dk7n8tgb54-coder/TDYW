# 账户体系重构方案：科室账号 → 个人账号

## 一、现状分析

### 当前模型
```python
# apps/account/models.py
class User(models.Model):
    username = models.CharField(max_length=100)      # 科室账号，如：通信科
    nickname = models.CharField(max_length=100)      # 显示名称
    tenant_id = models.CharField(max_length=50)      # 租户ID（科室级别）
    roles = models.ManyToManyField('Role')           # 角色
    is_supper = models.BooleanField(default=False)   # 超级管理员
```

### 问题
- 一个科室共享一个账号，无法追踪操作人到个人
- 权限粒度粗，无法细分到个人职能
- 安全性差，密码共享

---

## 二、目标架构

### 2.1 核心原则
1. **保留租户体系**：`tenant_id` 仍代表科室/部门
2. **个人账号**：每个人独立账号，归属某科室
3. **权限继承**：个人权限 = 角色权限 + 科室基础权限
4. **平滑迁移**：存量数据自动关联到新体系

    @property

        return self.is_supper or self.is_department_admin

## 三、权限体系设计

### 3.1 权限层级

```
超级管理员（is_supper）
    ↓
全局管理员（is_global_admin）
    ↓
科室管理员（is_department_admin）
    ↓
普通用户（角色权限）
```

### 3.2 权限规则

| 操作 | 超级管理员 | 全局管理员 | 科室管理员 | 普通用户 |
|------|-----------|-----------|-----------|---------|
| 查看所有科室数据 | ✅ | ✅ | ❌ | ❌ |
| 查看本科室数据 | ✅ | ✅ | ✅ | ✅ |
| 管理所有用户 | ✅ | ❌ | ❌ | ❌ |
| 管理本科室用户 | ✅ | ✅ | ✅ | ❌ |
| 管理系统配置 | ✅ | ❌ | ❌ | ❌ |
| 管理本科室配置 | ✅ | ✅ | ✅ | ❌ |
| 跨科室操作 | ✅ | 部分 | ❌ | ❌ |

### 3.3 租户过滤改造

```python
# libs/tenant_utils.py（改造）

def apply_tenant_filter(queryset, request_user, strict_mode=False):
    """
    应用租户过滤
    
    规则：
    1. 超级管理员：不过滤（查看所有）
    2. 全局管理员：非严格模式下不过滤
    3. 科室管理员/普通用户：只能查看本科室数据
    """
    if request_user.is_supper:
        return queryset
    
    if request_user.is_global_admin and not strict_mode:
        return queryset
    
    # 普通用户和科室管理员按 tenant_id 过滤
    return queryset.filter(tenant_id=request_user.tenant_id)


def check_user_permission(request_user, target_user=None, action='view'):
    """
    检查用户是否有权操作目标用户
    
    Args:
        request_user: 当前操作用户
        target_user: 目标用户（None表示新用户）
        action: 操作类型（view/edit/delete）
    """
    # 超级管理员拥有所有权限
    if request_user.is_supper:
        return True
    
    # 目标用户不存在（创建场景）
    if target_user is None:
        # 全局管理员和科室管理员可以创建用户
        return request_user.is_global_admin or request_user.is_department_admin
    
    # 同一科室内，科室管理员可以管理
    if request_user.tenant_id == target_user.tenant_id:
        if request_user.is_department_admin:
            return True
        # 用户只能查看/编辑自己
        if action in ('view', 'edit') and request_user.id == target_user.id:
            return True
    
    return False
```

# apps/account/views/auth.py

class LoginView(View):
    """登录（保持不变，返回增加科室信息）"""
    def post(self, request):
        form, error = JsonParser(
            Argument('username', required=True, help='请输入用户名'),
            Argument('password', required=True, help='请输入密码'),
        ).parse(request.body)
        if error:
            return json_response(error=error)
        
        user = User.objects.filter(username=form.username, is_active=True).first()
        if user and user.verify_password(form.password):
            # 更新登录信息
            user.access_token = uuid.uuid4().hex
            user.token_expired = time.time() + 8 * 60 * 60
            user.last_login = human_datetime()
            user.last_ip = request.get_host()
            user.save()
            
            return json_response({
                'access_token': user.access_token,
                'nickname': user.nickname,
                'username': user.username,
                'is_supper': user.is_supper,
                'is_global_admin': user.is_global_admin,
                'is_department_admin': user.is_department_admin,
                'department': {
                    'id': user.department_id,
                    'name': user.department.name if user.department else None,
                    'tenant_id': user.tenant_id,
                },
                'permissions': list(user.page_perms),
            })
        
        return json_response(error='用户名或密码错误')

### 5.2 数据迁移脚本

```python
# scripts/migrate_to_personal_account.py

"""
科室账号 → 个人账号 数据迁移脚本

执行步骤：
1. 为每个现有租户创建科室记录
2. 将现有用户标记为科室管理员
3. 创建默认个人账号模板
4. 历史数据关联调整
"""

import os
import django
os.environ.setdefault('DJANGO_SETTINGS_MODULE', 'spug.settings')
django.setup()

from apps.account.models import User, Role, Department
from libs import human_datetime

def migrate():
    print("=== 开始账户体系迁移 ===\n")
    
    # 1. 获取所有现有租户ID
    tenant_ids = User.objects.values_list('tenant_id', flat=True).distinct()
    print(f"发现 {len(tenant_ids)} 个租户\n")
    
    for tenant_id in tenant_ids:
        if not tenant_id:
            continue
            
        print(f"处理租户: {tenant_id}")
        
        # 2. 创建科室记录
        department, created = Department.objects.get_or_create(
            tenant_id=tenant_id,
            defaults={
                'name': f'{tenant_id}科',
                'code': tenant_id,
                'is_active': True,
                'created_at': human_datetime(),
            }
        )
        
        if created:
            print(f"  ✓ 创建科室: {department.name}")
        else:
            print(f"  → 科室已存在: {department.name}")
        
        # 3. 更新该租户下的所有用户
        users = User.objects.filter(tenant_id=tenant_id)
        for user in users:
            # 关联科室
            user.department = department
            
            # 如果是原科室账号（只有一个用户或is_supper），设为科室管理员
            if users.count() == 1 or user.is_supper:
                user.is_department_admin = True
                print(f"  ✓ 设置 {user.username} 为科室管理员")
            
            user.save()
        
        print(f"  ✓ 更新 {users.count()} 个用户\n")
    
    print("=== 迁移完成 ===")
    print("\n后续步骤：")
    print("1. 登录各科室管理员账号")
    print("2. 为科室成员创建个人账号")
    print("3. 分配角色和权限")

if __name__ == '__main__':
    migrate()
```
