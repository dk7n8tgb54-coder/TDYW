### ✅ 4. 递归改迭代

#### 修复位置 1: `list.py` 中的 `_get_folder_and_descendants`
**优化前**:
```python
def _get_folder_and_descendants(self, folder, FolderModel):
    folder_ids = [folder.id]
    children = FolderModel.all_objects.filter(parent=folder, is_deleted=True)
    for child in children:
        folder_ids.extend(self._get_folder_and_descendants(child, FolderModel))  # 递归
    return folder_ids
```

**优化后**:
```python
# 使用公共函数 get_folder_and_descendants_iter()
def get_folder_and_descendants_iter(folder, FolderModel):
    folder_ids = []
    queue = [folder]  # 队列代替递归栈
    
    while queue:
        current = queue.pop(0)
        folder_ids.append(current.id)
        children = FolderModel.all_objects.filter(parent=current, is_deleted=True)
        queue.extend(children)
    
    return folder_ids
```
