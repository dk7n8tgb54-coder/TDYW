### 2.2 P1级问题（已修复）

#### 问题1: UIStore 缺少 enterSubFolder 方法
**影响范围**: `RecycleBinUIStore.js`  
**问题描述**: `stores/index.js` 调用了 `uiStore.enterSubFolder()`，但 UI Store 中只有 `enterFolder` 方法

**修复方案**: 已在 `RecycleBinUIStore.js` 中添加 `enterSubFolder` 方法

```javascript
@action enterSubFolder = (folder) => {
  if (this.currentFolder) {
    const current = { id: this.currentFolder.id, name: this.currentFolder.name };
    this.currentFolder.parent_chain = [...(this.currentFolder.parent_chain || []), current];
  }
  this.enterFolder(folder);
};
```
