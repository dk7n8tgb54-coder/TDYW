### 2.2 代码拆分详情

#### RecycleBinUIStore.js (116行)
```
职责: 管理UI相关状态
- loading / statsLoading / operationLoading
- keyword / space / page / pageSize
- selectedRowKeys / selectedRows
- restoreVisible / deleteVisible / restoreMode / targetFolderId
- deleteProgressVisible / deleteTasks
- currentFolder / folderContentPage

方法:
- 状态设置器 (setLoading, setKeyword, setSpace, setPage...)
- UI操作 (showRestoreModal, hideRestoreModal, showDeleteModal...)
- 选择管理 (setSelectedRows, clearSelection)
- 进度管理 (showDeleteProgress, updateDeleteTask, hideDeleteProgress)
- 文件夹导航 (enterFolder, exitFolder, setFolderContentPage)
- reset() - 重置所有状态
```

#### RecycleBinBusinessStore.js (238行)
```
职责: 处理业务逻辑和数据交互
- items / total - 回收站列表数据
- stats - 统计数据
- folderContent / folderContentTotal - 文件夹内容

核心方法:
- fetchList(params) - 获取回收站列表（支持AbortController取消）
- fetchStats() - 获取统计数据
- refresh(params) - 刷新列表和统计
- doRestore(rows, mode, targetFolderId, idempotentKey) - 执行恢复
- doDelete(rows) - 执行删除（返回异步任务信息）
- pollDeleteProgress(tasks, onUpdate, onComplete) - 轮询删除进度
- fetchFolderContent(folderId, space, page, pageSize) - 获取文件夹内容
- cancelPendingRequests() - 取消进行中的请求
- reset() - 重置业务状态
```

#### stores/index.js (280行)
```
职责: 组合UI Store和Business Store，提供统一接口

委托模式:
- UI状态委托: loading, keyword, page, selectedRows, restoreVisible...
- 业务状态委托: items, total, stats, folderContent...
- 计算属性委托: hasSelected, selectedCount, selectedTotalSize

UI Actions委托:
- setLoading, setKeyword, setSpace, setPage...
- showRestoreModal, hideRestoreModal...
- enterFolder, exitFolder...

业务Actions封装:
- fetchList() - 包装loading状态
- fetchStats() - 包装statsLoading状态
- refresh() - 组合获取列表和统计
- doRestore() - 恢复操作+消息提示+刷新
- doPermanentDelete() - 删除操作+异步任务处理+刷新
- fetchFolderContent() - 获取文件夹内容
- enterSubFolder() - 进入子文件夹
- goToParentFolder() - 返回上级文件夹
- reset() - 重置所有状态
```

### 2.3 关键优化点

| 优化项 | 实现方式 | 效果 |
|-------|---------|------|
| 职责分离 | UI状态与业务逻辑分离 | 代码更清晰，易于维护 |
| 请求取消 | AbortController + _requestId | 避免竞态条件 |
| 状态委托 | Getter/方法委托模式 | 保持API兼容性 |
| 消息统一 | 业务操作内统一处理message | 避免重复代码 |
| 进度轮询 | 封装pollDeleteProgress | 复用性增强 |
