## 七、修复建议

### 7.1 建议修复（P1-1）

在 `RecycleBinUIStore.js` 中添加 `enterSubFolder` 方法：

```javascript
@action enterSubFolder = (folder) => {
  if (this.currentFolder) {
    // 保存当前文件夹到parent_chain
    const current = {
      id: this.currentFolder.id,
      name: this.currentFolder.name,
    };
    this.currentFolder.parent_chain = [...(this.currentFolder.parent_chain || []), current];
  }
  this.enterFolder(folder);
};
```

或在 `stores/index.js` 中修改 `enterSubFolder` 方法，直接使用 `enterFolder`：

```javascript
@action
enterSubFolder = (folder) => {
  this.enterFolder(folder);  // 简化调用
  this.fetchFolderContent();
};
```
