## 漏洞 #13：多租户隔离TenantQuerySet未完整实现

### 风险描述
`TenantQuerySet` 类的自动过滤逻辑为空实现（`pass`），意味着多租户数据隔离完全依赖各个View手动调用过滤函数。如果某个View遗漏了租户过滤，将导致跨租户数据泄露。

### 涉及文件

**文件：`spug_api/libs/tenant_middleware.py` 第67-85行**
```python
class TenantQuerySet:
    """
    自定义QuerySet,自动添加租户过滤条件
    """
    def __init__(self, model=None, query=None, using=None, hints=None):
        from django.db.models import QuerySet
        self.queryset = QuerySet(model=model, query=query, using=using, hints=hints)

    def __getattr__(self, name):
        attr = getattr(self.queryset, name)
        if callable(attr):
            def wrapper(*args, **kwargs):
                current_tenant = get_current_tenant()
                if current_tenant:
                    if name in ['filter', 'get', 'all', 'first', 'last', 'exclude']:
                        if 'tenant_id' not in kwargs and hasattr(args[0] if args else None, '__contains__'):
                            pass  # ← 空实现！没有实际添加过滤条件
                return attr(*args, **kwargs)
            return wrapper
        return attr
```

### 当前隔离机制分析

**TenantMiddleware（正常工作）：**
```python
class TenantMiddleware(MiddlewareMixin):
    def process_request(self, request):
        if hasattr(request, 'user') and request.user:
            if getattr(request.user, 'is_supper', False):
                set_current_tenant(None)  # 超管不限制
            else:
                tenant_id = getattr(request.user, 'tenant_id', 'admin')
                set_current_tenant(tenant_id)
```

**问题：** 中间件正确设置了tenant_id到线程本地变量，但TenantQuerySet没有利用这个值进行自动过滤。

### 风险场景
1. 开发者新增一个View，忘记调用 `apply_tenant_filter()`
2. 该View返回所有租户的数据
3. 普通用户可以看到其他租户的敏感数据

### 当前依赖的手动过滤方式
系统通过 `libs/tenant_utils.py` 中的 `apply_tenant_filter()` 函数在每个View中手动过滤：
```python
# 每个View都需要手动调用
file_query = apply_tenant_filter(file_query, request.user, strict_mode=True)
```

这种方式的问题：
- 容易遗漏
- 无法在代码审查中自动检测
- 新开发者可能不知道需要调用
