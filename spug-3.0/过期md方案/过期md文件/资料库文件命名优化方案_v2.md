## 一、现状分析

### 1.1 当前问题

当前文件命名方案将所有信息（原始文件名、用户ID、时间戳、随机串）都塞入物理文件名，导致：

```
84-【哑铃】第11周，周三，臀腿+核心，围度突破2023-06-02_15_1773480302_8d09d33e.mp4
└─────────────────────────────────────────────────────────────────────────┘
                    超长物理文件名（78字符）
```

**问题清单**:

| 问题 | 影响 | 严重程度 |
|-----|------|---------|
| 文件名过长 | 超出某些文件系统限制（如FAT32的255字节） | 高 |
| 可读性差 | 用户从文件名无法识别内容 | 中 |
| 信息冗余 | 用户ID、时间戳对物理存储无意义 | 中 |
| 路径过长 | Windows路径超过260字符时出错 | 高 |
| 编码问题 | 中文+特殊符号在某些系统兼容性差 | 中 |
| 高并发冲突 | 秒级时间戳+随机串在极端并发下可能冲突 | 高 |
| 非法字符 | 原始文件名中的 `/ \ : * ? " < > |` 会导致创建失败 | 高 |

### 1.2 当前三层命名现状

| 层级 | 当前实现 | 示例 | 问题 |
|-----|---------|------|------|
| **前端显示** (display_name) | 可为null，从物理名解析 | `84-【哑铃】..._15_1773480302_8d09d33e.mp4` | 解析逻辑复杂，容易出错 |
| **数据库name** | 物理文件名 | `84-【哑铃】..._15_1773480302_8d09d33e.mp4` | 无可读性 |
| **物理文件** (file_path) | 带hash的随机名 | `storage/.../84-【哑铃】..._15_1773480302_8d09d33e.mp4` | 过长，兼容性差 |

**核心问题**: 三层都使用物理文件名，没有分离逻辑。

### 3.1 新命名规范与核心函数

#### 3.1.1 非法字符清理（必加）

```python
import re

def clean_illegal_chars(filename, replace_space=True):
    """
    清理文件名中的非法字符
    
    规则：
    1. 替换系统非法字符 / \ : * ? " < > | 为下划线
    2. 可选替换空格为下划线（避免路径空格问题）
    3. 去除连续下划线（美观）
    4. 去除首尾下划线
    
    Args:
        filename: 原始文件名
        replace_space: 是否替换空格为下划线（默认True）
    
    Returns:
        清理后的文件名
    """
    # 系统非法字符
    illegal_chars = r'[\/:*?"<>|]'
    
    # 第一步：替换非法字符
    clean_name = re.sub(illegal_chars, "_", filename)
    
    # 第二步：替换空格（可选）
    if replace_space:
        clean_name = clean_name.replace(" ", "_")
    
    # 第三步：去除连续下划线
    clean_name = re.sub(r"_+", "_", clean_name)
    
    # 第四步：去除首尾下划线
    clean_name = clean_name.strip("_")
    
    return clean_name

# 示例：
# "哑铃/臀腿训练*.mp4" → "哑铃_臀腿训练_.mp4"
# "【哑铃】 臀腿训练.mp4" → "【哑铃】_臀腿训练.mp4"
# "file:name?.txt" → "file_name_.txt"
```

#### 3.1.2 智能扩展名提取

```python
def get_file_ext(filename):
    """
    智能提取文件扩展名（支持多扩展名、无扩展名）
    
    规则：
    1. 无扩展名：返回 (filename, "")
    2. 单扩展名：返回 (name, ".ext")
    3. 多扩展名（如.tar.gz）：返回 (name, ".tar.gz")
    
    Args:
        filename: 原始文件名
    
    Returns:
        (original_name_without_ext, ext_with_dot)
    """
    # 常见多扩展名后缀
    multi_ext_suffixes = ['.tar.gz', '.tar.bz2', '.tar.xz', '.md5', '.sha1', '.sha256']
    
    # 先检查多扩展名
    lower_filename = filename.lower()
    for suffix in multi_ext_suffixes:
        if lower_filename.endswith(suffix):
            original_name = filename[:-len(suffix)]
            return original_name, suffix
    
    # 单扩展名处理
    name_parts = filename.rsplit(".", 1)
    if len(name_parts) == 1:
        # 无扩展名
        return filename, ""
    else:
        original_name = name_parts[0]
        ext = f".{name_parts[1]}"
        return original_name, ext

# 示例：
# "xxx.tar.gz" → ("xxx", ".tar.gz")
# "README" → ("README", "")
# "哑铃.mp4" → ("哑铃", ".mp4")
# "archive.zip" → ("archive", ".zip")
```

#### 3.1.3 物理文件名生成（高并发安全）

```python
import time
import uuid

def generate_physical_name(ext=""):
    """
    生成物理文件名（高并发安全）
    
    方案A（推荐）：毫秒级时间戳 + 6位随机串
    - 时间戳13位（精确到毫秒）
    - 随机串6位（16^6 = 1677万种组合）
    - 总长度约24字符（含扩展名）
    
    方案B（极简）：12位UUID
    - 完全无冲突
    - 总长度约20字符（含扩展名）
    
    Args:
        ext: 扩展名（含点，如".mp4"）
    
    Returns:
        物理文件名
    """
    # 方案A：毫秒级时间戳 + 6位随机（推荐，兼顾可读性和唯一性）
    timestamp = int(time.time() * 1000)  # 13位毫秒时间戳
    random_suffix = uuid.uuid4().hex[:6]  # 6位随机
    physical_name = f"{timestamp}_{random_suffix}{ext}"
    
    # 方案B：12位UUID（如需更短可用此方案）
    # physical_name = f"{uuid.uuid4().hex[:12]}{ext}"
    
    return physical_name

# 示例：
# generate_physical_name(".mp4") → "1773480302123_8d09d3.mp4"（24字符）
# generate_physical_name("") → "1773480302123_8d09d3"（无扩展名）
```

#### 3.1.4 逻辑文件名生成（防竞态）

```python
from django.db import transaction
from django.db.models import Max, Substr, Func, Value, IntegerField
import re

def generate_unique_name(FileModel, original_name, folder, user, max_original_length=50):
    """
    生成唯一逻辑名（name）- 数据库事务防竞态版本
    
    规则：
    1. 作用域：仅在「同一租户+同一文件夹」内保证唯一
    2. 序号逻辑：查询该文件夹下同名文件的最大序号，+1生成；无同名则不加序号
    3. 防竞态：用数据库事务+SELECT FOR UPDATE行锁，避免高并发生成重复序号
    4. 长度限制：原始名截断到50字符（避免数据库字段溢出），序号占3位，总长度≤54字符
    
    Args:
        FileModel: 文件模型类
        original_name: 原始文件名（含扩展名）
        folder: 目标文件夹对象（None表示根目录）
        user: 当前用户（用于获取tenant_id）
        max_original_length: 原始文件名最大长度（默认50）
    
    Returns:
        唯一逻辑文件名
    """
    # 步骤1：提取原始名和扩展名
    name_without_ext, ext = get_file_ext(original_name)
    
    # 步骤2：清理非法字符
    clean_original = clean_illegal_chars(name_without_ext)
    
    # 步骤3：截断超长原始名
    if len(clean_original) > max_original_length:
        clean_original = clean_original[:max_original_length]
    
    # 步骤4：查询同一文件夹下的同名文件（事务+行锁防竞态）
    folder_id = folder.id if folder else None
    tenant_id = getattr(user, 'tenant_id', None)
    
    with transaction.atomic():
        # 使用SELECT FOR UPDATE锁定该文件夹下的所有文件记录（防止并发插入）
        # 注意：这里锁定的是文件夹记录，而非文件记录，减少锁粒度
        
        # 查找该文件夹下所有以 clean_original 开头的文件
        prefix_pattern = f"{clean_original}_%"
        exact_pattern = f"{clean_original}{ext}"
        
        # 查询精确匹配（无序号）
        exact_exists = FileModel.objects.filter(
            folder_id=folder_id,
            tenant_id=tenant_id,
            name=exact_pattern
        ).exists()
        
        if not exact_exists:
            # 无同名文件，直接用清理后的原始名
            return f"{clean_original}{ext}"
        
        # 有同名文件，需要生成序号
        # 查询所有匹配前缀的文件，提取最大序号
        # 匹配模式：clean_original_XXX.ext
        import re
        regex_pattern = rf"^{re.escape(clean_original)}_(\d{{3}}){re.escape(ext)}$"
        
        existing_files = FileModel.objects.filter(
            folder_id=folder_id,
            tenant_id=tenant_id,
            name__regex=regex_pattern
        ).values_list('name', flat=True)
        
        # 提取最大序号
        max_counter = 0
        for existing_name in existing_files:
            match = re.match(regex_pattern, existing_name)
            if match:
                counter = int(match.group(1))
                max_counter = max(max_counter, counter)
        
        # 生成新序号
        new_counter = max_counter + 1
        
        # 序号溢出检查（999个同名文件，极罕见）
        if new_counter > 999:
            # 使用4位序号
            return f"{clean_original}_{new_counter:04d}{ext}"
        
        return f"{clean_original}_{new_counter:03d}{ext}"

# 示例场景：
# 文件夹内已有：哑铃-臀腿训练.mp4, 哑铃-臀腿训练_001.mp4
# 新文件生成：哑铃-臀腿训练_002.mp4
```

#### 5.2.1 新建 utils/naming.py

```python
"""
文件命名工具模块
提供生产级的文件名生成、清理、解析功能
"""

import re
import time
import uuid
import logging
from django.db import transaction

logger = logging.getLogger(__name__)


def clean_illegal_chars(filename, replace_space=True):
    """清理文件名中的非法字符"""
    illegal_chars = r'[\/:*?"<>|]'
    clean_name = re.sub(illegal_chars, "_", filename)
    if replace_space:
        clean_name = clean_name.replace(" ", "_")
    clean_name = re.sub(r"_+", "_", clean_name)
    clean_name = clean_name.strip("_")
    return clean_name


def get_file_ext(filename):
    """智能提取文件扩展名"""
    multi_ext_suffixes = ['.tar.gz', '.tar.bz2', '.tar.xz', '.md5', '.sha1', '.sha256']
    lower_filename = filename.lower()
    for suffix in multi_ext_suffixes:
        if lower_filename.endswith(suffix):
            original_name = filename[:-len(suffix)]
            return original_name, suffix
    name_parts = filename.rsplit(".", 1)
    if len(name_parts) == 1:
        return filename, ""
    return name_parts[0], f".{name_parts[1]}"


def generate_physical_name(ext=""):
    """生成物理文件名（毫秒级时间戳+6位随机）"""
    timestamp = int(time.time() * 1000)
    random_suffix = uuid.uuid4().hex[:6]
    return f"{timestamp}_{random_suffix}{ext}"


def generate_unique_name(FileModel, original_name, folder, user, max_original_length=50):
    """生成唯一逻辑名（数据库事务防竞态）"""
    name_without_ext, ext = get_file_ext(original_name)
    clean_original = clean_illegal_chars(name_without_ext)
    
    if len(clean_original) > max_original_length:
        clean_original = clean_original[:max_original_length]
    
    folder_id = folder.id if folder else None
    tenant_id = getattr(user, 'tenant_id', None)
    
    with transaction.atomic():
        exact_pattern = f"{clean_original}{ext}"
        exact_exists = FileModel.objects.filter(
            folder_id=folder_id,
            tenant_id=tenant_id,
            name=exact_pattern
        ).exists()
        
        if not exact_exists:
            return exact_pattern
        
        # 查找最大序号
        regex_pattern = rf"^{re.escape(clean_original)}_(\d{{3}}){re.escape(ext)}$"
        existing_files = FileModel.objects.filter(
            folder_id=folder_id,
            tenant_id=tenant_id,
            name__regex=regex_pattern
        ).values_list('name', flat=True)
        
        max_counter = 0
        for existing_name in existing_files:
            match = re.match(regex_pattern, existing_name)
            if match:
                max_counter = max(max_counter, int(match.group(1)))
        
        new_counter = max_counter + 1
        if new_counter > 999:
            return f"{clean_original}_{new_counter:04d}{ext}"
        return f"{clean_original}_{new_counter:03d}{ext}"


def parse_old_name_to_display(old_physical_name):
    """从旧物理名提取display_name（兼容历史数据）"""
    # 旧名格式：{file_base}_{user_id}_{timestamp}_{random8}{ext}
    parts = old_physical_name.rsplit("_", 3)
    if len(parts) >= 4:
        # 尝试提取原始名
        file_base = parts[0]
        ext = parts[-1]
        # 如果最后部分包含.，认为是扩展名
        if "." in ext:
            return f"{file_base}.{ext.split('.')[-1]}"
        return old_physical_name
    return old_physical_name
```

```python
    # 步骤1：提取扩展名
    original_name_without_ext, ext = get_file_ext(original_name)
    
    # 步骤2：生成物理文件名（短、随机）
    physical_name = generate_physical_name(ext)
    
    # 步骤3：生成逻辑文件名（可读+唯一）
    logical_name = generate_unique_name(
        FileModel, 
        original_name, 
        folder, 
        request.user
    )
    
    # 步骤4：display_name使用原始文件名
    display_name = original_name
    
    # 步骤5：构建完整路径
    file_path = os.path.join(
        get_document_absolute_path(is_public, request.user.id, folder_id),
        physical_name
    )
    
    # 步骤6：保存到数据库（新增physical_name字段）
    file_obj = FileModel.objects.create(
        name=logical_name,           # 逻辑名：哑铃-臀腿训练_001.mp4
        display_name=display_name,   # 显示名：哑铃-臀腿训练.mp4
        physical_name=physical_name, # 物理名：1773480302123_8d09d3.mp4
        file_path=file_path,         # 完整路径
        # ... 其他字段
    )
    
    # 步骤7：记录映射日志（运维排查）
    logger.info(
        f'[FileMapping] tenant_id={request.user.tenant_id} | '
        f'user_id={request.user.id} | '
        f'logical_name={logical_name} | '
        f'physical_name={physical_name} | '
        f'display_name={display_name}'
    )
```

### 5.4 风险评估与缓解

| 风险 | 等级 | 影响 | 缓解措施 |

| 多扩展名处理错误 | 中 | 扩展名识别错误 | 智能提取逻辑覆盖常见场景 |
