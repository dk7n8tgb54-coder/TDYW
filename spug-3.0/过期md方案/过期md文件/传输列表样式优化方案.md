# 传输列表边框样式优化方案

## 当前问题

当前传输列表使用硬边框 (`border: 1px solid #f0f0f0`)，存在以下问题：
1. 边框颜色过于生硬，视觉上不够柔和
2. 各区域之间分隔感太强，缺乏整体感
3. 缺乏层次感，各组之间区分不明显
4. 阴影效果缺失，界面显得扁平

---

## 方案一：柔和阴影卡片式（推荐）

### 设计思路
使用卡片式布局 + 柔和阴影替代硬边框，营造现代感。

### 视觉效果
```
┌─────────────────────────────────────┐  ← 轻微阴影 + 圆角
│  📤 正在传输 (3)              [暂停] │  ← 渐变背景色区分
├─────────────────────────────────────┤
│  📄 file1.pdf    ████████░░░  80%  │  ← 内部分隔线改用淡色
│  📄 file2.zip    ██████░░░░░  60%  │
├─────────────────────────────────────┤
│  ⏸️ 已暂停 (1)                      │  ← 黄色调背景
├─────────────────────────────────────┤
│  📄 file3.jpg    ░░░░░░░░░░░   0%  │
└─────────────────────────────────────┘
```

### 具体改动

#### 1. 外层容器
```javascript
// 原样式
style={{ 
  border: '1px solid #f0f0f0',
  borderRadius: 4 
}}

// 新样式
style={{ 
  boxShadow: '0 2px 8px rgba(0, 0, 0, 0.08)',
  borderRadius: 8,
  backgroundColor: '#fff',
  overflow: 'hidden'  // 确保子元素圆角裁切
}}
```

#### 2. 区域分组标题栏
```javascript
// 正在传输 - 蓝色调
style={{
  padding: '12px 16px',
  background: 'linear-gradient(135deg, #e6f7ff 0%, #f0f9ff 100%)',
  borderBottom: '1px solid #d9f7be',  // 改为淡色分隔线
}}

// 已暂停 - 黄色调
style={{
  padding: '12px 16px',
  background: 'linear-gradient(135deg, #fffbe6 0%, #fff7e6 100%)',
  borderBottom: '1px solid #ffd666',
}}

// 传输失败 - 红色调
style={{
  padding: '12px 16px',
  background: 'linear-gradient(135deg, #fff2f0 0%, #fff5f5 100%)',
  borderBottom: '1px solid #ffccc7',
}}

// 已完成 - 绿色调
style={{
  padding: '12px 16px',
  background: 'linear-gradient(135deg, #f6ffed 0%, #f0f9ff 100%)',
}}
```

#### 3. 列表项分隔
```javascript
// 移除硬边框，改用淡色底部分隔线
style={{
  padding: '12px 16px',
  borderBottom: '1px solid #f5f5f5',  // 更淡的颜色
  transition: 'background-color 0.2s',
  '&:hover': {
    backgroundColor: '#fafafa',  // 悬停效果
  },
  '&:last-child': {
    borderBottom: 'none',  // 最后一项无边框
  }
}}
```

## 方案二：极简无框式

### 设计思路
完全移除边框，仅用留白和背景色区分。

### 视觉效果
```
  📤 正在传输 (3)              [暂停]
  ─────────────────────────────────
  📄 file1.pdf    ████████░░░  80%
  📄 file2.zip    ██████░░░░░  60%
  
  ⏸️ 已暂停 (1)
  ─────────────────────────────────
  📄 file3.jpg    ░░░░░░░░░░░   0%
```

### 具体改动
```javascript
// 外层容器 - 只有轻微阴影
style={{
  boxShadow: '0 1px 3px rgba(0, 0, 0, 0.05)',
  borderRadius: 6,
}}

// 区域分组 - 用背景色区分，无硬边框
style={{
  padding: '10px 0',
  backgroundColor: '#fafafa',  // 交替或不同色
}}

// 标题栏 - 仅用文字和图标区分
style={{
  padding: '8px 16px',
  fontWeight: 500,
  color: '#595959',
}}

// 列表项 - 无边框，仅用间距
style={{
  padding: '10px 16px',
  margin: '0 8px',  // 左右留白
  borderRadius: 4,
  '&:hover': {
    backgroundColor: '#f5f5f5',
  }
}}
```

## 方案三：左侧色条标识式

### 设计思路
用左侧彩色竖条标识不同状态，类似 GitHub/GitLab 的列表风格。

### 视觉效果
```
┌─────────────────────────────────────┐
│▐  📤 正在传输 (3)            [暂停] │  ← 左侧蓝色竖条
├─────────────────────────────────────┤
│▐  📄 file1.pdf   ████████░░░  80%  │
│▐  📄 file2.zip   ██████░░░░░  60%  │
├─────────────────────────────────────┤
│▐  ⏸️ 已暂停 (1)                     │  ← 左侧黄色竖条
├─────────────────────────────────────┤
│▐  📄 file3.jpg   ░░░░░░░░░░░   0%  │
├─────────────────────────────────────┤
│▐  ❌ 传输失败 (2)            [清空] │  ← 左侧红色竖条
├─────────────────────────────────────┤
│▐  📄 file4.exe   ████░░░░░░░  40%  │
│▐  📄 file5.iso   █░░░░░░░░░░  10%  │
└─────────────────────────────────────┘
```

### 具体改动
```javascript
// 外层容器
style={{
  boxShadow: '0 2px 10px rgba(0, 0, 0, 0.06)',
  borderRadius: 8,
}}

// 区域分组标题栏 - 左侧色条 + 背景色
const groupStyles = {
  uploading: {
    borderLeft: '4px solid #1890ff',
    backgroundColor: '#f0f9ff',
  },
  paused: {
    borderLeft: '4px solid #faad14',
    backgroundColor: '#fffbe6',
  },
  error: {
    borderLeft: '4px solid #ff4d4f',
    backgroundColor: '#fff2f0',
  },
  completed: {
    borderLeft: '4px solid #52c41a',
    backgroundColor: '#f6ffed',
  }
};

// 列表项 - 继承父级左侧色条
style={{
  padding: '12px 16px',
  paddingLeft: 12,  // 考虑色条宽度
  borderBottom: '1px solid #f0f0f0',
}}
```

## 推荐选择

**推荐方案一（柔和阴影卡片式）**，原因：
1. 视觉上最符合现代 UI 设计趋势
2. 渐变背景色能有效区分不同状态
3. 柔和阴影增加层次感但不突兀
4. 对现有代码改动较小

---

## 实施建议

1. **先实现方案一**，观察效果
2. 如果希望更简洁，可调整为方案二
3. 如果状态区分不明显，可采用方案三
