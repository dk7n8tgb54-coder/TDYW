# 文件夹上传问题修复方案

## 问题描述

### 问题 1: 大文件分片上传没有进度条变动

**原因**: `uploadFileToFolder` 方法只使用普通上传，没有根据文件大小判断是否使用分片上传

**代码位置**: `spug_web/src/pages/document/stores/upload/core/fileUpload.js` 第 227-399 行

```javascript
// 当前实现：直接普通上传，没有分片判断
await http.post(API_ENDPOINTS.FILE_UPLOAD, formData, {
  ...
  onUploadProgress: (e) => {
    // 只有这里更新进度
  }
});
```

### 问题 2: 上传文件夹时没有显示待传文件

**原因**: 文件在创建文件夹结构后才逐个添加到队列，不是一开始就全部添加

**代码位置**: `spug_web/src/pages/document/stores/upload/core/folderUpload.js`

```javascript
// 第 85 行：只设置了文件夹整体进度
this.queueStore.setFolderUploadProgress(0, files.length);

// 第 203-204 行：文件开始上传时才添加到队列
await this.fileUploadStore.uploadFileToFolder(file, targetId, folderPath, isPublic);
```

## 修复方案

### 方案 1: 修复大文件分片上传（fileUpload.js）

在 `uploadFileToFolder` 方法中添加文件大小判断，大文件使用分片上传：

```javascript
// 判断文件大小，选择上传方式
if (file.size > UPLOAD_CONSTANTS.CHUNK_SIZE) {
  // 大文件使用分片上传
  await this.rootStore.chunkUploadStore.uploadFileChunked(
    file, targetFolderId, uploadId, targetIsPublic
  );
} else {
  // 小文件使用普通上传（保持现有代码）
  await http.post(API_ENDPOINTS.FILE_UPLOAD, formData, {...});
}
```

### 方案 2: 显示待传文件（folderUpload.js）

在选择文件夹后立即将所有文件添加到队列（waiting 状态）：

```javascript
// 在 handleFolderSelect 方法中，创建文件夹结构之前

// 1. 预先将所有文件添加到队列（waiting 状态）
for (const file of files) {
  const uploadId = generateUploadId();
  const relativePath = file.webkitRelativePath || file.name;
  const pathParts = relativePath.split('/');
  const folderPath = pathParts.slice(0, -1).join('/');
  const fileName = folderPath ? `${folderPath}/${file.name}` : file.name;
  
  this.queueStore.addToQueue({
    id: uploadId,
    file: file,
    name: fileName,
    percent: 0,
    status: 'waiting',  // 等待状态
    error: null,
    canAbort: false,
    uniqueKey: this.queueStore.generateUniqueKey(file, targetFolderId, isPublic),
    tenantId: tenantId,
    isPublic: isPublic,
  }, tenantId);
}

// 2. 上传时从队列中找到对应的项，更新状态为 uploading
// 3. 使用队列项的 id 作为 uploadId，确保进度能正确关联
```

### 方案 3: 修改 uploadFolderFiles 方法

从遍历原始 files 数组改为遍历队列中的 waiting 项：

```javascript
async uploadFolderFiles(folderMap, targetFolderId, folderUniqueKey) {
  const tenantId = this.rootStore.getCurrentTenantId?.() || 'default';
  const queue = this.queueStore.uploadQueue[tenantId];
  
  // 获取所有 waiting 状态的文件夹上传项
  const waitingItems = queue.filter(item => 
    item.status === 'waiting' && item.isFromFolderUpload
  );
  
  for (let i = 0; i < waitingItems.length; i++) {
    const item = waitingItems[i];
    const file = item.file;
    
    // 更新状态为 uploading
    this.queueStore.updateUploadItem(item.id, { 
      status: 'uploading',
      canAbort: true 
    });
    
    try {
      // 使用已存在的 uploadId
      await this.fileUploadStore.uploadExistingItem(item, folderMap, targetFolderId);
      successCount++;
    } catch (error) {
      failCount++;
    }
    
    this.queueStore.setFolderUploadProgress(i + 1, waitingItems.length);
  }
}
```

### 方案 4: 修改 uploadFileToFolder 支持已存在的队列项

```javascript
// 新增方法：上传已存在的队列项（用于文件夹上传）
async uploadExistingItem(item, folderMap, targetFolderId) {
  const { file, id: uploadId } = item;
  const relativePath = file.webkitRelativePath || file.name;
  const pathParts = relativePath.split('/');
  const folderPath = pathParts.slice(0, -1).join('/');
  const targetId = folderPath ? folderMap.get(folderPath) : targetFolderId;
  
  // 判断文件大小选择上传方式
  if (file.size > UPLOAD_CONSTANTS.CHUNK_SIZE) {
    await this.rootStore.chunkUploadStore.uploadFileChunked(
      file, targetId, uploadId, item.isPublic
    );
  } else {
    // 普通上传，使用现有的 uploadId
    await this.uploadFileNormalWithExistingId(file, targetId, uploadId, item.isPublic);
  }
}
```

## 修复后效果

1. 选择文件夹后，所有文件立即显示在传输列表中（waiting 状态）
2. 大文件（>32MB）自动使用分片上传，显示正确进度
3. 文件夹创建过程中用户可以查看待传文件列表
4. 进度条能正确反映上传进度
