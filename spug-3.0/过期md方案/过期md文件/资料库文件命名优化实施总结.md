### 3.2 三层命名规范

| 层级 | 字段 | 生成规则 | 示例 |
|-----|------|---------|------|
| **display_name** | 显示名称 | 原始文件名（用户上传时的名字） | `哑铃-臀腿训练.mp4` |
| **name** | 逻辑名称 | 清理后的原始名+3位序号（防重名） | `哑铃-臀腿训练_001.mp4` |
| **physical_name** | 物理名称 | 毫秒时间戳(13位)+6位随机串 | `1773480302123_8d09d3.mp4` |

### 4.2 非法字符处理（兼容性提升）

**优化前**：直接报错，用户无法上传含非法字符的文件

**优化后**：自动清理，100%兼容
```python
def clean_illegal_chars(filename):
    # 替换 / \ : * ? " < > | 为下划线
    clean_name = re.sub(r'[\/:*?"<>|]', "_", filename)
    # 替换空格为下划线（可选）
    clean_name = clean_name.replace(" ", "_")
    # 去除连续下划线
    clean_name = re.sub(r"_+", "_", clean_name)
    return clean_name.strip("_")

# 示例：
# "哑铃/臀腿训练*.mp4" → "哑铃_臀腿训练_.mp4"
# "【哑铃】 臀腿训练.mp4" → "【哑铃】_臀腿训练.mp4"
```

### 4.3 多扩展名支持（完善性提升）

**优化前**：`xxx.tar.gz` 被错误识别为 `.gz`

**优化后**：智能识别多扩展名

```python
def get_file_ext(filename):
    multi_ext_suffixes = ['.tar.gz', '.tar.bz2', '.tar.xz', '.md5']
    for suffix in multi_ext_suffixes:
        if filename.lower().endswith(suffix):
            return filename[:-len(suffix)], suffix

```

### 4.4 历史数据兼容（零迁移成本）

**双模式支持**：
```python
def get_file_display_name(file_obj):
    # 新数据：直接使用display_name
    if file_obj.display_name:
        return file_obj.display_name
    
    # 旧数据：从physical_name解析
    if file_obj.physical_name:
        return parse_old_physical_name_to_display(file_obj.physical_name)
    
    # 兜底：使用name
    return file_obj.name
```

**兼容策略**：
- 新上传文件：使用新规范（三层分离）
- 旧文件：自动解析，正常展示
- 无需数据迁移，零停机时间
