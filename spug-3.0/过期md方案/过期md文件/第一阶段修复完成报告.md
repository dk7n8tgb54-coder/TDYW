### 2.1 P0-1: 数据加载竞态条件修复

#### 问题描述
- 刷新页面时30%概率无数据
- 多个组件同时发起数据请求，造成竞态条件
- 使用`setTimeout`临时解决方案不可靠

#### 修复方案

**1. 新增统一初始化机制** (`stores/index.js`)

```javascript
// 全局初始化状态管理
let initializationPromise = null;

export async function initializeStores() {
  // 如果正在初始化，返回现有的Promise（防止重复初始化）
  if (initializationPromise) {
    return initializationPromise;
  }
  
  // 创建初始化Promise
  initializationPromise = (async () => {
    // 并行获取基础数据
    await Promise.all([...]);
    scheduleStore.setInitialized(true);
  })();
  
  return initializationPromise;
}
```

**2. 添加初始化状态标记** (`stores/scheduleStore.js`)

```javascript
@observable isInitialized = false;

@action
setInitialized(value) {
  this.isInitialized = value;
}
```

**3. 页面入口统一初始化** (`index.js`)

```javascript
import { initializeStores } from './stores';

useEffect(() => {
  initializeStores().catch(error => {
    setInitError('数据加载失败，请刷新页面重试');
  });
}, []);

// 添加加载状态和错误状态显示
if (!store.isInitialized && !initError) {
  return <Spin size="large" tip="正在加载排班数据..." />;
}
```

**4. 子组件移除重复初始化** (`Calendar/index.js`)

```javascript
// 删除 useScheduleInit() 调用
// 删除 setTimeout 临时解决方案

// 只在store已初始化后获取数据

  if (store.isInitialized && internalDate) {
    fetchExtendedScheduleData();
  }
```

### 2.2 P0-2: 批量操作缺乏事务保护修复

#### 问题描述
- 批量删除时部分失败导致数据不一致
- 循环单次操作性能差
- 缺乏租户隔离验证

#### 修复方案

**1. 新增批量删除视图** (`views/batch.py`)

```python
class ScheduleBatchDeleteView(View):
    """批量删除排班 - 带事务保护"""

    @auth('schedule.schedule.del')
    @transaction.atomic  # 事务装饰器
    def post(self, request):
        # 1. 验证所有ID是否属于当前租户
        queryset = apply_tenant_filter(
            Schedule.objects.filter(pk__in=form.ids),
            request.user
        )
        
        # 2. 检查跨租户ID
        invalid_ids = requested_ids - found_ids
        if invalid_ids:
            return json_response(error='部分记录不存在或无权操作')
        
        # 3. 事务保护下的批量删除
        deleted_count = queryset.delete()[0]
```

**2. 优化批量创建** (`views/batch.py`)

```python
# 原代码：循环单次创建（无事务保护）
for record_data in form.records:
    ScheduleSwap.objects.create(**record_data)

# 修复后：验证+批量创建（带事务保护）
@transaction.atomic
def post(self, request):
    # 第一阶段：验证所有记录
    for record_data in form.records:
        valid_ids, invalid_ids = SwapService.validate_staff_ids(...)
        valid_records.append(record_data)
    
    # 第二阶段：事务保护下的批量创建
    created_records = ScheduleSwap.objects.bulk_create([
        ScheduleSwap(**record_data) for record_data in valid_records
    ])
```

**3. 前端使用批量删除API** (`ScheduleModal/index.js`)

```javascript
// 原代码：循环单次删除
for (const id of checkedIds) {
  await store.deleteSchedule(id);
}

// 修复后：使用批量删除API
const result = await store.batchDeleteSchedules(checkedIds);
message.success(`已删除 ${result.deleted_count} 条排班记录`);
```

**4. Store添加批量删除方法** (`stores/scheduleStore.js`)

```javascript
@action
batchDeleteSchedules(ids) {
  return http.post('/api/schedule/batch_delete/', { ids })
    .then(result => {
      return this.fetchSchedule(...).then(() => result);
    });
}
```
