# 搜索范围扩展功能实现说明

**实现日期**: 2026-03-28  
**功能**: 修复"搜索范围局限"问题，添加"全库搜索"入口  
**相关文件**:
- `spug_web/src/pages/document/index.js`
- `spug_web/src/pages/document/Explorer/hooks/useExplorerState.js`
- `spug_web/src/pages/document/Explorer/index.js`

---

## 一、功能概述

### 1.1 问题描述
原搜索功能只能搜索当前文件夹及其子文件夹，用户无法直接从根目录搜索整个资料库。

### 1.2 解决方案
在搜索框添加"当前"/"全库"切换按钮，让用户明确选择搜索范围：
- **当前**: 在当前文件夹及其所有子文件夹中搜索
- **全库**: 在整个资料库（公共空间/私有空间）中搜索

---

## 二、实现细节

### 2.1 前端修改

#### 2.1.1 DocumentIndex 组件 (`index.js`)

**新增状态**:
```javascript
const [searchScope, setSearchScope] = React.useState('current'); // 'current' | 'global'
```

**修改搜索处理函数**:
```javascript
// 传递搜索范围和当前文件夹ID
explorerRef.current.handleSearch(value, searchScope, navigationStore.currentFolderId);
```

**新增搜索范围切换函数**:
```javascript
const handleSearchScopeChange = React.useCallback((scope) => {
  setSearchScope(scope);
  // 如果已有搜索内容，重新搜索
  if (searchText && explorerRef.current?.handleSearch) {
    explorerRef.current.handleSearch(searchText, scope, navigationStore.currentFolderId);
  }
}, [searchText]);
```

**搜索框UI修改**:
```javascript
<Input.Search
  placeholder={searchScope === 'global' ? '搜索整个资料库' : '搜索当前文件夹'}
  addonBefore={
    <Button.Group size="small">
      <Button
        type={searchScope === 'current' ? 'primary' : 'default'}
        onClick={() => handleSearchScopeChange('current')}
        title="在当前文件夹及其子文件夹中搜索"
      >
        当前
      </Button>
      <Button
        type={searchScope === 'global' ? 'primary' : 'default'}
        onClick={() => handleSearchScopeChange('global')}
        title="在整个资料库中搜索"
      >
        全库
      </Button>
    </Button.Group>
  }
/>
```

## 三、用户交互流程

```
用户进入资料库
    │
    ▼
搜索框显示 [当前|全库] 切换按钮（默认"当前"）
    │
    ├── 点击 [当前] → 在当前文件夹及其子文件夹中搜索
    │
    ├── 点击 [全库] → 在整个资料库中搜索
    │
    └── 输入关键词 → 根据当前选择的范围进行搜索
```

## 六、兼容性

- **向后兼容**: 原有搜索功能不受影响（默认"当前"范围）
- **API兼容**: 后端接口无需修改，已支持 `folder_id=null`
- **权限兼容**: 保持原有的租户隔离和公共空间权限控制

---

## 七、性能考虑

1. **全库搜索范围更大**，可能返回更多结果，已受限于 `MAX_SEARCH_RESULTS = 200`
2. **防抖处理**: 300ms 防抖避免频繁请求
3. **分页加载**: 搜索结果支持分页，避免一次性加载过多数据
