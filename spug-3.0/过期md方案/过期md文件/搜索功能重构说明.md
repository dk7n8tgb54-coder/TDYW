# 搜索功能重构说明

**重构日期**: 2026-03-28  
**重构原因**: 原实现逻辑混乱，搜索功能分散在多个文件中，难以维护  
**重构目标**: 将搜索功能独立成组件，简化主页面逻辑

---

## 一、重构前的问题

### 1.1 代码分散
- 搜索状态管理在 `useExplorerState.js`
- 搜索UI在 `index.js`
- 搜索结果显示在 `Explorer/index.js`
- 参数传递链路过长

### 1.2 逻辑混乱
- `handleSearch` 依赖 `searchScope`，但依赖关系不清晰
- 防抖函数使用 `useRef`，可能获取不到最新状态
- 搜索和正常列表数据混合处理

---

## 二、重构后的架构

```
DocumentIndex (index.js)
    │
    ├── SearchBox (components/SearchBox.js)  ← 新增：独立搜索组件
    │       ├── 搜索UI (Input + Button.Group)
    │       ├── 防抖处理
    │       └── API调用
    │
    └── Explorer (Explorer/index.js)
            │
            ├── 接收 searchState prop
            ├── 根据 isSearching 决定显示数据
            └── 正常列表逻辑不变
```

---

## 三、文件变更

### 3.1 新增文件

#### `components/SearchBox.js`
独立的搜索组件，包含：
- 搜索输入框
- 当前/全库切换按钮
- 防抖搜索逻辑
- API调用

**Props**:
```javascript
{
  folderId,          // 当前文件夹ID
  isPublic,          // 是否公共空间
  onSearchStart,     // 搜索开始回调
  onSearchResult,    // 搜索结果回调
  onSearchError,     // 搜索错误回调
  onClearSearch      // 清空搜索回调
}
```

### 3.2 修改文件

#### `index.js`
- 移除搜索相关状态 (`searchText`, `searchScope`)
- 新增 `searchState` 统一管理搜索状态
- 使用 `SearchBox` 组件替代原 `Input.Search`
- 通过回调函数接收搜索结果

#### `Explorer/index.js`
- 新增 `searchState` prop
- 根据 `searchState.isSearching` 决定显示数据
- 移除 `handleSearch` 相关逻辑

#### `Explorer/hooks/useExplorerState.js`
- 移除搜索相关状态 (`filteredItems`, `isSearching`, `searchText`)
- 移除 `handleSearch` 和 `handleSearchDebounced`
- 只负责正常列表数据获取

## 四、数据流

### 4.1 正常列表
```
useExplorerState.fetchItems()
    ↓
items (状态)
    ↓
Explorer 显示 items
```

### 4.2 搜索列表
```
用户输入关键词
    ↓
SearchBox.doSearch()
    ↓
API 调用 /api/document/folder/search/
    ↓
onSearchResult(result)
    ↓
index.js setSearchState()
    ↓
searchState.results (prop)
    ↓
Explorer 显示 searchState.results
```

## 五、关键代码

### 5.1 SearchBox 组件
```javascript
const SearchBox = ({ folderId, isPublic, onSearchResult }) => {
  const [keyword, setKeyword] = useState('');
  const [scope, setScope] = useState('current');

  const doSearch = async (searchKeyword, searchScope) => {
    const searchFolderId = searchScope === 'global' ? null : folderId;
    const res = await http.get('/api/document/folder/search/', {
      params: { folder_id: searchFolderId, keyword: searchKeyword }
    });
    onSearchResult({ items: [...res.folders, ...res.files] });
  };

  return (
    <Space.Compact>
      <Button.Group>
        <Button onClick={() => setScope('current')}>当前</Button>
        <Button onClick={() => setScope('global')}>全库</Button>
      </Button.Group>
      <Input onChange={debouncedSearch} />
    </Space.Compact>
  );
};
```

### 5.2 Explorer 组件
```javascript
const Explorer = ({ searchState }) => {
  const isSearching = searchState?.isSearching;
  const displayItems = isSearching ? searchState.results : items;

  return <Table dataSource={displayItems} />;
};
```

## 六、优点

### 6.1 职责清晰
| 组件 | 职责 |
|-----|------|
| SearchBox | 搜索UI + 搜索逻辑 + API调用 |
| Explorer | 列表展示（正常数据或搜索结果） |
| useExplorerState | 正常列表数据管理 |

### 6.2 易于维护
- 搜索功能集中在 `SearchBox.js`
- 修改搜索逻辑只需改一个文件
- 新增搜索功能不影晌其他组件

### 6.3 可复用
- `SearchBox` 可以在其他页面复用
- 只需传入不同的 `folderId` 和 `isPublic`
