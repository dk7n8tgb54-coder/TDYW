class SoftDeletedManager(models.Manager):
    """默认管理器：只返回未删除的记录"""
    def get_queryset(self):
        return super().get_queryset().filter(is_deleted=False)

class AllObjectsManager(models.Manager):
    """全量管理器：返回所有记录（包括已删除）"""
    def get_queryset(self):

#### DocumentFilePrivate 字段修改
| 字段 | 修改前 | 修改后 |
|------|--------|--------|
| physical_name | `null=True, blank=True` | `null=True, blank=True, editable=False` |
| file_path | 无约束 | `editable=False` |
| is_deleted | 无 | `BooleanField(default=False)` |
| deleted_at | 无 | `DateTimeField(null=True, blank=True)` |
| 管理器 | objects | objects (过滤删除) + all_objects (全量) |

#### 新增方法
```python
def delete(self, *args, **kwargs):
    """默认软删除，支持 hard=True 硬删除"""
    hard = kwargs.pop('hard', False)
    if hard:
        super().delete(*args, **kwargs)
    else:
        self.is_deleted = True
        self.deleted_at = timezone.now()
        self.save(update_fields=['is_deleted', 'deleted_at'])

def restore(self):
    """恢复软删除的文件"""
    self.is_deleted = False
    self.deleted_at = None
    self.save(update_fields=['is_deleted', 'deleted_at'])
```

## 四、API 变更说明

### 4.1 删除接口

**请求方式**: `DELETE /api/document/file/delete`

**参数变更**:
| 参数 | 类型 | 必需 | 说明 |
|------|------|------|------|
| id | int | 是 | 文件ID |
| is_public | bool | 否 | 是否公共空间 |
| hard | bool | 否 | **新增**: true=硬删除, false=软删除(默认) |

**示例**:
```bash
# 软删除（默认）
DELETE /api/document/file/delete?id=123

# 硬删除（彻底删除）
DELETE /api/document/file/delete?id=123&hard=true
```

### 4.2 移动接口

**行为变更**:
- **修改前**: 物理文件被移动到新目录，同时修改 `file_path`
- **修改后**: 只修改数据库中的 `folder_id`，物理文件位置不变

**影响**:
- ✅ 移动操作性能提升（无磁盘IO）
- ✅ 符合"物理名终身不变"原则
- ⚠️ 注意：文件物理路径不再随文件夹变化
