# 资料库新建文件夹交互优化方案

## 一、现状分析

当前新建文件夹流程：
1. 用户右键点击空白处或点击"新建文件夹"按钮
2. 弹出模态窗口输入文件夹名称
3. 点击确认后创建

**痛点**：
- 打断用户操作流程
- 需要两次点击（打开弹窗 + 确认）
- 弹窗遮挡背景内容

---

## 二、优化方案对比

| 方案 | 交互方式 | 优点 | 缺点 | 适用场景 |
|------|---------|------|------|---------|
| **A. 行内编辑** | 直接在列表新增一行，输入框编辑 | 最直观，不打断流程 | 需要处理取消/保存状态 | **推荐** |
| **B. 顶部输入栏** | 在工具栏下方显示输入框 | 不遮挡列表 | 占用固定空间 | 备选 |
| **C. 简化弹窗** | 保留弹窗但自动聚焦+回车确认 | 改动最小 | 仍有弹窗打断 | 保守方案 |
| **D. 侧边抽屉** | 从右侧滑出输入面板 | 不遮挡中心区域 | 交互稍复杂 | 不推荐 |

---

## 三、推荐方案：行内编辑

### 3.1 交互流程

```
用户点击"新建文件夹"
    ↓
列表第一行插入临时文件夹项
    ↓
文件夹名称输入框自动聚焦
    ↓
用户输入名称
    ↓
按回车或失焦保存 / 按ESC取消
```

### 3.2 视觉设计

```
┌─────────────────────────────────────────┐
│ 📁 [新建文件夹          ] ✓  ✗          │  ← 临时行，输入框带边框
├─────────────────────────────────────────┤
│ 📁 现有文件夹1                           │
│ 📄 文件1.txt                             │
└─────────────────────────────────────────┘
```

**元素说明**：
- 图标：📁 文件夹图标（灰色表示未创建）
- 输入框：带蓝色边框，placeholder="请输入文件夹名称"
- 确认按钮：✓ 绿色，点击或回车保存
- 取消按钮：✗ 红色，点击或ESC取消

### 3.3 状态流转

| 状态 | 表现 | 操作 |
|------|------|------|
| 编辑中 | 输入框聚焦，显示确认/取消按钮 | 输入名称 |
| 保存中 | 显示 loading，按钮禁用 | 等待API响应 |
| 成功 | 临时行变为正常文件夹行 | 可继续操作 |
| 失败 | 显示错误提示，保持编辑状态 | 修改后重试 |
| 取消 | 临时行消失，列表恢复原状 | - |

### 4.2 核心代码实现

#### 1) 修改 useExplorerState.js

```javascript
// 添加新建文件夹相关状态
const [creatingFolder, setCreatingFolder] = useState(false);
const [tempFolderName, setTempFolderName] = useState('');

// 开始新建文件夹
const startCreateFolder = useCallback(() => {
  setCreatingFolder(true);
  setTempFolderName('');
}, []);

// 取消新建文件夹
const cancelCreateFolder = useCallback(() => {
  setCreatingFolder(false);
  setTempFolderName('');
}, []);

// 确认创建文件夹
const confirmCreateFolder = useCallback(async () => {
  if (!tempFolderName.trim()) {
    message.warning('请输入文件夹名称');
    return;
  }
  
  try {
    await handleCreateFolder(tempFolderName.trim());
    setCreatingFolder(false);
    setTempFolderName('');
    message.success('文件夹创建成功');
  } catch (error) {
    message.error('创建失败：' + error.message);
  }
}, [tempFolderName, handleCreateFolder]);
```

#### 2) 修改 useColumns.js

```javascript
// 第一列渲染函数增加临时文件夹处理
{
  title: '文件名',
  dataIndex: 'name',
  key: 'name',
  render: (text, record) => {
    // 临时文件夹行内编辑模式
    if (record.isTemp) {
      return (
        <div style={{ display: 'flex', alignItems: 'center', gap: 8 }}>
          <span style={{ fontSize: 16 }}>📁</span>
          <Input
            autoFocus
            size="small"
            value={tempFolderName}
            onChange={(e) => setTempFolderName(e.target.value)}
            onPressEnter={confirmCreateFolder}
            onBlur={() => {
              // 延迟失焦，避免点击按钮时先触发失焦
              setTimeout(() => {
                if (!tempFolderName.trim()) {
                  cancelCreateFolder();
                }
              }, 200);
            }}
            placeholder="请输入文件夹名称"
            style={{ width: 200 }}
          />
          <CheckOutlined 
            style={{ color: '#52c41a', cursor: 'pointer' }}
            onClick={confirmCreateFolder}
          />
          <CloseOutlined 
            style={{ color: '#ff4d4f', cursor: 'pointer' }}
            onClick={cancelCreateFolder}
          />
        </div>
      );
    }
    
    // 正常文件夹渲染...
    return (
      <div style={{ display: 'flex', alignItems: 'center' }}>
        {record.isFolder ? (
          <span style={{ marginRight: 8, fontSize: 16 }}>📂</span>
        ) : (
          getFileIcon(record.name, record.file_type)
        )}
        <span>{record.display_name || text}</span>
      </div>
    );
  }
}
```

## 五、边界情况处理

| 场景 | 处理方案 |
|------|---------|
| 名称为空 | 失焦时自动取消，或提示"请输入名称" |
| 名称重复 | API 返回错误，保持编辑状态，显示错误提示 |
| 快速多次点击新建 | 只允许同时存在一个临时文件夹项 |
| 切换文件夹 | 自动取消当前新建操作 |
| 进入搜索模式 | 隐藏新建功能或自动取消 |
| 网络异常 | 显示错误，保持编辑状态，可重试 |

---

## 六、优点总结

1. **无弹窗打断**：操作流程连贯，不打断用户思路
2. **减少点击次数**：从原来的"点击新建→输入→点击确认"3步，变为"点击新建→输入→回车"3步（但无弹窗切换）
3. **即时反馈**：创建成功立即在列表中显示
4. **符合直觉**：类似 Windows 资源管理器、Mac Finder 的交互
5. **易于取消**：ESC 或点击 ✗ 即可取消，比关闭弹窗更便捷

## 七、备选方案：顶部输入栏

如果行内编辑实现复杂，可采用顶部输入栏方案：

```
┌─────────────────────────────────────────┐
│ [工具栏按钮]                            │
├─────────────────────────────────────────┤
│ 📁 新建文件夹: [输入框      ] [确认][取消]│  ← 临时显示的工具栏
├─────────────────────────────────────────┤
│ 📁 文件夹1                               │
└─────────────────────────────────────────┘
```

**实现更简单**，但占用固定空间，视觉干扰稍大。
