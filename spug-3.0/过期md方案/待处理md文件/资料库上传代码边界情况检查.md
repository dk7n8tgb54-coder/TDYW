    """校验文件名，防止路径遍历和非法字符"""

## 九、关键风险点

### 9.1 高风险

1. **总分片大小与声明大小不一致**
   - 当前代码没有验证各分片大小之和是否等于声明的 `file_size`
   - 可能导致合并后的文件大小与预期不符
   - **建议**: 在合并过程中累加分片大小，最后验证

2. **上传过程中文件被篡改**
   - 分片上传时没有实时校验MD5
   - 如果传输过程中分片被篡改，只能在最终合并后才发现
   - **建议**: 前端计算每个分片的MD5，后端验证

### 9.2 中风险

1. **分片索引越界**
   - 没有验证 `chunk_index` 是否在有效范围内
   - 可能导致额外的分片文件残留

2. **文件名控制字符**
   - 没有过滤控制字符（\x00-\x1f）
   - 可能导致文件系统异常

### 9.3 低风险

1. **文件名空格**
   - 没有 trim 文件名
   - 可能导致文件系统显示问题

def validate_chunk_index(chunk_index, total_chunks):

# 2. 添加分片大小校验
def validate_chunk_sizes(chunk_dir, total_chunks, expected_total_size):
    actual_size = sum(
        os.path.getsize(os.path.join(chunk_dir, f'{i}.part'))
        for i in range(total_chunks)
    )
    if actual_size != expected_total_size:
