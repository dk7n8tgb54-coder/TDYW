# 部门值班日志与资料库使用说明

---

## 一、部门值班日志

### 1.1 功能简介

部门值班日志用于记录每日值班情况，支持草稿编辑、电子签名签署、退回更正、PDF 导出等完整生命周期管理。

### 1.2 权限说明

| 权限 | 说明 |
|------|------|
| 查看 | 可查看已签署的值班日志（草稿仅本人可见） |
| 新建 | 新建本人值班草稿 |
| 编辑 | 编辑本人未签署的草稿 |
| 删除 | 删除本人未签署的草稿 |
| 签署 | 对本人草稿进行电子签名签署 |
| 退回 | 将已签署记录退回为草稿（管理员操作） |
| 导出 | 导出已签署记录为 PDF |

> 超级管理员拥有全部权限。普通用户仅能操作自己创建的草稿。

### 1.3 操作流程

#### 新建值班日志

1. 进入 **部门值班日志** 页面，点击右上角 **新建** 按钮。
2. 填写表单：
   - **值班日期**：选择日期（不可选未来日期）。日历面板中已有日志的日期会标记浅绿色底纹，避免重复登记。
   - **值班人员**：自动显示当前登录用户，不可修改。
   - **天气情况**：填写当日天气（必填，最多 50 字）。
   - **值班记录**：填写当班情况（必填，最多 10000 字）。
   - **上级工作要求**：填写上级交办事项（选填，最多 2000 字）。
3. 点击 **确定** 保存草稿。

#### 编辑草稿

- 列表中点击 **编辑** 按钮（仅本人草稿可见此按钮）。
- 修改内容后点击 **确定**。
- 系统使用乐观锁机制，若他人同时修改了该记录，会提示版本冲突。

#### 签署

1. 列表中点击 **签署** 按钮（仅本人草稿可见此按钮）。
2. 系统检查当前用户是否已设置电子签名。
   - 若未设置签名，会提示先前往 **账号签名** 页面设置。
3. 签署弹窗中预览签名图片，确认无误后点击 **确认签署**。
4. 签署后记录状态变为 **已签署**，不可再编辑或删除。

> 签署后记录的内容将被固化（生成业务快照哈希），确保签署内容不可篡改。

#### 退回已签记录

- 列表中点击 **退回** 按钮（仅已签署记录可见，需退回权限）。
- 确认后原签署信息将被清除，记录恢复为草稿状态，可重新编辑和签署。

#### 删除草稿

- 列表中点击 **删除** 按钮（仅本人草稿可见此按钮）。
- 确认后软删除，记录不再显示。

#### 导出 PDF

1. 点击右上角 **导出 PDF** 按钮（需导出权限）。
2. 系统按当前筛选条件导出 **已签署** 的记录（草稿不导出）。
3. 每条值班日志独占一页，包含完整记录信息和电子签名图片。
4. 单次最多导出 500 条。

### 1.4 列表筛选

| 筛选项 | 说明 |
|--------|------|
| 日期范围 | 按值班日期筛选，最大范围 365 天 |
| 值班人员 | 按值班人员姓名筛选 |
| 状态 | 草稿 / 已签署 |
| 关键字 | 搜索值班记录和上级工作要求中的内容 |

### 1.5 查看详情

- 点击列表行可打开详情抽屉，查看完整记录信息。
- 已签署记录会额外显示签署信息区块（签署人、签署时间、电子签名图片）。

## 二、资料库

### 2.1 功能简介

资料库提供文件和文件夹的集中管理，支持分片上传、断点续传、在线预览、文件夹打包下载、拖拽上传、传输列表等功能。

资料库包含三个子模块：

| 子模块 | 路径 | 说明 |
|--------|------|------|
| 文档管理 | `/document` | 个人文件与公共共享库 |
| 党建工作 | `/document/party-building-documents` | 党建专用文档空间 |
| 规章管理 | `/regulation` | 规章制度分类管理 |

### 2.2 权限说明（文档管理 / 党建工作）

| 权限 | 说明 |
|------|------|
| 查看 | 浏览文件和文件夹列表 |
| 上传文件 | 上传单个文件或整个文件夹 |
| 下载文件 | 下载文件或打包下载文件夹 |
| 删除文件 | 删除文件或文件夹 |
| 新建文件夹 | 创建子文件夹 |
| 复制文件 | 复制文件到其他目录 |
| 移动文件 | 移动文件到其他目录 |
| 重命名文件 | 修改文件或文件夹名称 |

> 文档管理权限码前缀为 `document.document`，党建工作权限码前缀为 `document.party_building_document`，权限独立分配。

### 2.3 空间说明

资料库分为两个空间：

| 空间 | 说明 |
|------|------|
| **我的文件**（私有空间） | 仅本人可见的文件和文件夹 |
| **公共共享库**（公共空间） | 所有用户均可查看和下载 |

通过左侧文件夹树顶部切换空间。上传文件到公共共享库时会提示"所有用户均可查看下载"。

### 2.4 文件操作

#### 上传文件

1. 点击工具栏 **上传** 下拉按钮，选择 **上传文件** 或 **上传文件夹**。
2. 或直接将文件/文件夹 **拖拽** 到文件区域（拖拽时显示上传遮罩提示目标目录）。
3. 上传方式：
   - **小文件**：直接上传。
   - **大文件**：自动分片上传 + 断点续传。
4. 上传过程中可在底部 **传输面板** 查看进度。

#### 下载文件

- **单个文件**：点击文件行的下载按钮。
- **文件夹**：点击文件夹的下载按钮，系统打包为 ZIP 后下载。打包过程异步执行，完成后通知下载。

#### 在线预览

- 点击文件行的预览按钮，调用 kkFileView 在线预览。
- 支持常见办公格式（Word、Excel、PPT、PDF、图片等）。

#### 文件管理

| 操作 | 说明 |
|------|------|
| 新建文件夹 | 工具栏点击 **新建文件夹** 按钮 |
| 复制 | 选中文件后复制到指定目录 |
| 移动 | 选中文件后移动到指定目录 |
| 重命名 | 修改文件或文件夹名称 |
| 删除 | 删除文件或文件夹（直接物理删除，不可恢复） |

> 删除操作需二次确认，确认后文件将被永久删除。

#### 多选模式

- 点击工具栏 **多选** 按钮进入多选模式。
- 可勾选多个文件/文件夹进行批量复制、移动、删除。

#### 搜索

- 顶部搜索框输入关键字搜索文件。
- 可选择搜索范围：当前目录或全部目录。

### 2.5 传输面板

底部传输面板（仿百度网盘抽屉模式）显示所有上传/下载任务：

| 功能 | 说明 |
|------|------|
| 展开收起 | 点击右上角传输图标或底部小条展开/收起 |
| 三 Tab 分类 | 上传中 / 已完成 / 失败 |
| 拖拽调整高度 | 拖动顶部把手调整面板高度（240~720px） |
| 闪烁提示 | 收起态下有任务完成（绿色）或失败（红色）时底部小条闪烁 |
| 批量操作 | 全部暂停、全部继续、清空已完成 |

**键盘快捷键：**

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Shift+U` | 打开/关闭传输面板 |
| `Ctrl+Shift+P` | 全部暂停 |
| `Ctrl+Shift+R` | 全部继续 |
| `Ctrl+Shift+C` | 清空已完成 |
| `Shift+/`（即 `?`） | 显示快捷键帮助 |

### 2.6 视图模式

| 模式 | 说明 |
|------|------|
| 列表视图 | 按名称、大小、类型、修改时间列展示 |
| 缩略图视图 | 以网格形式展示文件缩略图（图片文件显示缩略图） |

### 2.7 党建工作

党建工作是资料库的专用空间，有以下特点：

- 进入页面后自动锁定到党建工作根目录，不可切换到其他空间。
- 所有用户均可查看和下载党建工作文件。
- 文件上传、下载、管理等操作与文档管理一致。
- 权限独立控制（`document.party_building_document.*`）。

### 2.8 磁盘状态

页面右上角显示当前磁盘使用状态（缓存 60 秒），便于了解存储空间情况。

## 三、常见问题

### 部门值班日志

**Q: 为什么看不到他人的草稿？**
A: 草稿仅创建人可见。已签署记录所有有查看权限的用户均可见。

**Q: 签署时提示"未找到有效签名"？**
A: 请先前往 **账号签名** 页面上传或设置个人电子签名。

**Q: 同一天可以创建多条值班日志吗？**
A: 可以。日历面板会标记已有日志的日期，但不限制同一天多条记录。

**Q: 退回后原来的签署记录还在吗？**
A: 退回操作会清除签署字段，但审计日志中保留完整的签署和退回记录以供追溯。

### 资料库

**Q: 上传大文件时断网了怎么办？**
A: 系统支持断点续传，重新上传同一文件时会从断点继续。传输面板中失败的任务可点击重试。

**Q: 文件删除后能恢复吗？**
A: 不能。文件删除为直接物理删除，请确认后再操作。

**Q: 上传到公共共享库的文件谁能看到？**
A: 所有具有查看权限的用户均可查看和下载公共共享库中的文件。

**Q: 文件夹下载为什么需要等待？**
A: 文件夹打包为 ZIP 是异步操作，完成后会通知。大文件夹打包可能需要较长时间。

**Q: 传输面板的快捷键在输入框里能用吗？**
A: 不能。当焦点在输入框、文本域等可编辑元素中时，快捷键不响应，避免影响正常输入。
