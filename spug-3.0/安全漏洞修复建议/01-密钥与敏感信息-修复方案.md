## 修复项 #1：SECRET_KEY 改为环境变量

### 涉及文件
- `spug_api/spug/settings.py`
- `spug_api/spug/overrides.py`

### 修改方案

#### 文件：`spug_api/spug/settings.py`

**修改前（第28行）：**
```python
SECRET_KEY = 'vk0do47)egwzz!uk49%(y3s(fpx4+ha@ugt-hcv&%&d@hwr&p7'
```

**修改后：**
```python
# SECURITY: Read SECRET_KEY from environment variable
SECRET_KEY = os.environ.get('DJANGO_SECRET_KEY')
if not SECRET_KEY:
    if os.environ.get('DEBUG', 'False').lower() == 'true':
        SECRET_KEY = 'dev-only-insecure-key-do-not-use-in-production'
    else:
        raise ValueError(
            "DJANGO_SECRET_KEY environment variable is required in production! "
            "Generate one with: python -c \"from django.core.management.utils import "
            "get_random_secret_key; print(get_random_secret_key())\""
        )
```

## 修复项 #2：db_config.ini 加入 .gitignore

### 涉及文件
- `.gitignore`

### 修改方案

在 `.gitignore` 文件末尾添加：
```
# Database config (contains credentials - DO NOT commit)
db_config.ini
```

### 从Git历史中移除
```bash
git rm --cached db_config.ini
git commit -m "security: remove db_config.ini from tracking"
```

### 创建模板文件 `db_config.ini.example`
```ini
[database]
host = ${MYSQL_HOST:-localhost}
user = ${MYSQL_USER:-spug_app}
password = ${MYSQL_PASSWORD:-change_me_in_production}
name = ${MYSQL_DATABASE:-spug}

[index]
size_threshold = 10000

[log]
level = INFO
```

## 修复项 #4：默认管理员密码改为环境变量

### 涉及文件
- `docker/config/entrypoint.sh`

### 修改方案

**修改前（第35-44行）：**
```bash
python manage.py shell -c "
import os
os.environ.setdefault('DJANGO_SETTINGS_MODULE', 'spug.settings')
import django
django.setup()
from apps.account.models import User
if not User.objects.filter(username='admin').exists():
    user = User.objects.create(
        username='admin',
        nickname='管理员',
        password_hash=User.make_password('Admin888..'),
        is_supper=True,
        is_active=True
    )
    print('管理员账号已创建: admin / Admin888..')
else:
    print('管理员账号已存在')
" || echo "初始化管理员失败或已跳过"
```

**修改后：**
```bash
# Initialize admin account with password from environment variable
ADMIN_PASSWORD=${ADMIN_INIT_PASSWORD:-}
if [ -z "$ADMIN_PASSWORD" ]; then
    echo "WARNING: ADMIN_INIT_PASSWORD not set, using generated random password"
    ADMIN_PASSWORD=$(python -c "import secrets, string; print(''.join(secrets.choice(string.ascii_letters + string.digits + '!@#\$%') for _ in range(16)))")
    echo "=========================================="
    echo "Generated admin password: $ADMIN_PASSWORD"
    echo "Please save this password and change it after first login!"
    echo "=========================================="
fi

python manage.py shell -c "
import os
os.environ.setdefault('DJANGO_SETTINGS_MODULE', 'spug.settings')
import django
django.setup()
from apps.account.models import User
if not User.objects.filter(username='admin').exists():
    password = os.environ.get('ADMIN_INIT_PASSWORD', '$ADMIN_PASSWORD')
    user = User.objects.create(
        username='admin',
        nickname='管理员',
        password_hash=User.make_password(password),
        is_supper=True,
        is_active=True
    )
    print('管理员账号已创建，请使用设定的密码登录')
else:
    print('管理员账号已存在')
" || echo "初始化管理员失败或已跳过"
```
