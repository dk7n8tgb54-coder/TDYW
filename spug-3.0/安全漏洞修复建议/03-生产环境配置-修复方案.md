## 修复项 #5 + #6：DEBUG和ALLOWED_HOSTS改为环境变量

### 涉及文件
- `spug_api/spug/settings.py`

### 修改方案

**修改前（第30-33行）：**
```python
DEBUG = True

ALLOWED_HOSTS = ['127.0.0.1', 'localhost', '*']
```

**修改后：**
```python
# SECURITY: Read from environment, default to safe values
DEBUG = os.environ.get('DEBUG', 'False').lower() == 'true'

# Parse ALLOWED_HOSTS from environment (comma-separated)
_allowed_hosts = os.environ.get('ALLOWED_HOSTS', '127.0.0.1,localhost')
ALLOWED_HOSTS = [h.strip() for h in _allowed_hosts.split(',') if h.strip()]
```

### Docker Compose 配置调整

**文件：`docker/docker-compose.yml` 第37行**

**修改前：**
```yaml
- ALLOWED_HOSTS=*
```

**修改后（生产环境示例）：**
```yaml
- ALLOWED_HOSTS=${ALLOWED_HOSTS:-127.0.0.1,localhost}
```

在 `.env` 文件中配置实际值：
```bash
ALLOWED_HOSTS=192.168.1.100,your-domain.com
```

## 修复项 #17：数据库端口绑定localhost

### 涉及文件
- `docker/docker-compose.yml`

### 修改方案

**修改前（第82行）：**
```yaml
    ports:
      - "3308:3306"  # 数据库端口
```

**修改后：**
```yaml
    ports:
      - "127.0.0.1:3308:3306"  # Database port - only accessible from localhost
```

### 说明
- `127.0.0.1:3308:3306` 表示仅本机可通过3308端口访问数据库
- 外部网络无法直接连接数据库
- 应用容器通过Docker内部网络（`tdyw-network`）连接数据库，不受影响
