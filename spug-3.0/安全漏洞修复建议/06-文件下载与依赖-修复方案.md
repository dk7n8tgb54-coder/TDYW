## 修复项 #12：文件下载改为流式响应

### 涉及文件
- `spug_api/apps/document/views/file/download.py`

### 修改方案

**修改前（第57-70行）：**
```python
with open(file.file_path, 'rb') as f:
    response = HttpResponse(f.read())
    display_name = file.display_name or file.name
    encoded_filename = quote(display_name)
    response['Content-Disposition'] = f'attachment; filename="{encoded_filename}"; filename*=UTF-8\'\'{encoded_filename}'
    response['Content-Type'] = file.file_type
    log_operation(...)
    return response
```

**修改后（完整替换下载逻辑）：**
```python
from django.http import FileResponse

# Use FileResponse for streaming download (memory-efficient)
display_name = file.display_name or file.name
encoded_filename = quote(display_name)

response = FileResponse(
    open(file.file_path, 'rb'),
    content_type=file.file_type or 'application/octet-stream',
)
response['Content-Disposition'] = (
    f'attachment; filename="{encoded_filename}"; '
    f'filename*=UTF-8\'\'{encoded_filename}'
)
response['Content-Length'] = os.path.getsize(file.file_path)

log_operation(
    action="FILE_DOWNLOAD",
    user=request.user,
    resource_type="FILE",
    resource_id=file.id,
    is_public=form.is_public,
    file_name=display_name,
    file_size=file.file_size
)
logger.info(f'[Document] File download successful: {file.name}, is_public={form.is_public}')
return response
```

### 同时修改文件顶部导入

**修改前：**
```python
from django.http import HttpResponse
```

**修改后：**
```python
from django.http import FileResponse
```

### 内存对比

| 方式 | 100MB文件内存占用 | 10并发下载 |
|------|-------------------|-----------|
| `HttpResponse(f.read())` | ~100MB | ~1GB |
| `FileResponse(open(...))` | ~8KB | ~80KB |

## 修复项 #11 + #22：依赖版本升级

### 涉及文件
- `spug_api/requirements.txt`

### 最小安全升级方案（低风险）

仅升级有已知CVE的包，不做大版本跳跃：

**修改前：**
```
Django==2.2.28
paramiko==2.11.0
```

**修改后（最小修复）：**
```
paramiko==3.4.1
```

> **注意**：Django 2.2 → 4.2 是大版本升级，需要大量代码适配，建议单独排期。paramiko升级到3.4.1可直接修复Terrapin攻击，兼容性影响较小。

### Django升级路线图（中长期）

```
当前: Django 2.2.28 (EOL)
  ↓ 第一步: Django 3.2 LTS (需修改少量废弃API)
  ↓ 第二步: Django 4.2 LTS (推荐目标，支持到2026年4月)
```

#### Django 4.2 升级需要的代码修改

1. 添加 `DEFAULT_AUTO_FIELD = 'django.db.models.BigAutoField'` 到 settings.py
2. `url()` 改为 `path()` / `re_path()`
3. 检查废弃的中间件API
4. 运行完整测试套件

### paramiko 升级注意事项

paramiko 2.x → 3.x 主要变化：
- 移除了 `py3compat` 模块（当前代码有引用）
- 需要修改 `spug_api/libs/ssh.py` 中的导入

**修改 `ssh.py` 导入：**

```python
# 修改前：
from paramiko.py3compat import b, u

# 修改后（paramiko 3.x）：
def b(s):
    """Convert string to bytes"""
    return s.encode() if isinstance(s, str) else s

def u(s):
    """Convert bytes to string"""
    return s.decode() if isinstance(s, bytes) else s
```
