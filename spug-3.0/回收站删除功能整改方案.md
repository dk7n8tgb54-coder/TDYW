# 回收站删除功能整改方案

## 当前问题分析

### 1. 用户体验问题
- **问题**：删除文件后提示"删除任务已提交，请稍后查看结果"
- **影响**：用户无法立即知道删除是否成功，需要手动刷新页面
- **痛点**：
  - 不知道删除进度
  - 不知道删除是否完成
  - 需要反复刷新页面确认

### 2. 技术现状
```javascript
// 当前实现（伪代码）
async deleteFile(fileId) {
  const result = await http.post('/api/document/recycle-bin/delete/', { id: fileId });
  // result: { task_id: 'celery-task-xxx', status: 'pending' }
  message.success('删除任务已提交，请稍后查看结果');
  // 用户需要手动刷新才能看到结果
}
```

---

## 整改目标

1. **实时反馈**：删除提交后立即显示进度
2. **自动刷新**：删除完成后自动更新列表
3. **进度可视**：显示删除进度百分比
4. **批量支持**：支持批量删除的进度展示

---

## 整改方案

### 方案一：前端轮询进度（推荐）

#### 1. 前端实现

```javascript
// stores/recycleBin.js
class RecycleBinStore {
  @observable deleteProgress = new Map(); // 记录删除进度 {taskId: {percent, status, message}}
  
  /**
   * 删除文件（带进度轮询）
   */
  async deleteFile(fileId, fileName) {
    try {
      // 1. 提交删除任务
      const { task_id } = await http.post('/api/document/recycle-bin/delete/', { 
        id: fileId,
        async: true  // 异步执行
      });
      
      // 2. 显示进度消息（不自动关闭）
      const hideLoading = message.loading(
        `正在删除 "${fileName}"...`, 
        0  // 0表示不自动关闭
      );
      
      // 3. 开始轮询进度
      this.pollDeleteProgress(task_id, fileName, hideLoading);
      
      return { success: true, taskId: task_id };
    } catch (error) {
      message.error(`删除失败: ${error.message}`);
      return { success: false };
    }
  }
  
  /**
   * 轮询删除进度
  */
  async pollDeleteProgress(taskId, fileName, hideLoading) {
    const maxAttempts = 60; // 最多轮询60次（2分钟）
    const interval = 2000;  // 每2秒轮询一次
    
    for (let i = 0; i < maxAttempts; i++) {
      await new Promise(resolve => setTimeout(resolve, interval));
      
      try {
        // 查询任务状态
        const status = await http.get(`/api/document/tasks/${taskId}/status/`);
        
        if (status.status === 'completed') {
          hideLoading();
          message.success(`"${fileName}" 删除成功`);
          this.fetchRecycleBinList(); // 自动刷新列表
          return;
        } else if (status.status === 'failed') {
          hideLoading();
          message.error(`删除失败: ${status.error || '未知错误'}`);
          return;
        } else if (status.status === 'progress') {
          // 更新进度
          const percent = status.progress || 0;
          hideLoading();
          message.loading(
            `正在删除 "${fileName}"... ${percent}%`,
            0
          );
        }
        // 继续轮询...
      } catch (error) {
        console.error('查询删除进度失败:', error);
      }
    }
    
    // 超时处理
    hideLoading();
    message.warning('删除任务超时，请手动刷新查看结果');
  }
}
```

### 方案二：WebSocket 实时推送（高级方案）

适用场景：
- 删除大文件（>1GB）
- 批量删除大量文件
- 需要实时进度反馈

```javascript
// 使用 WebSocket 接收实时进度
class RecycleBinStore {
  @action
  async deleteFile(fileId) {
    // 1. 提交删除任务
    const { task_id } = await http.post('/api/document/recycle-bin/delete/', { id: fileId });
    
    // 2. 订阅 WebSocket 进度推送
    this.ws.subscribe(`task:${task_id}`, (data) => {
      if (data.status === 'completed') {
        message.success('删除成功');
        this.fetchRecycleBinList();
      } else if (data.status === 'progress') {
        this.updateProgress(task_id, data.progress);
      }
    });
  }
}
```

### 方案三：同步删除 + 超时处理（简单方案）

如果删除操作通常在 5 秒内完成，可以直接同步等待：

```javascript
async deleteFile(fileId, fileName) {
  const hideLoading = message.loading(`正在删除 "${fileName}"...`, 0);
  
  try {
    // 设置 30 秒超时
    const result = await Promise.race([
      http.post('/api/document/recycle-bin/delete/', { id: fileId }),
      new Promise((_, reject) => 
        setTimeout(() => reject(new Error('删除超时')), 30000)
      )
    ]);
    
    hideLoading();
    message.success('删除成功');
    this.fetchRecycleBinList();
  } catch (error) {
    hideLoading();
    if (error.message === '删除超时') {
      message.warning('删除操作超时，将在后台继续执行，请稍后刷新查看');
    } else {
      message.error(`删除失败: ${error.message}`);
    }
  }
}
```

1. 实现简单，不需要 WebSocket
