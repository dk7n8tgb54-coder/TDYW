## 无线电台执照 - 附件下载认证 bug 修复

**问题**：附件下载/查看弹出新页面，显示"验证失败，请重新登录"

**根因**：`AttachmentList.js` 使用 `localStorage.getItem('token')` 获取 token，但项目 token 存储在 **sessionStorage**（见 `functools.js:18`），导致拿到空字符串 → 中间件认证失败

**修复**：
1. 导入 `X_TOKEN`（项目全局 token 变量，从 sessionStorage 初始化）
2. 用 `X_TOKEN` 替代 `localStorage.getItem('token')`
3. 移除 `link.target = '_blank'`（下载文件不需要开新标签页）

**教训**：项目 token 存在 sessionStorage（非 localStorage），下载链接的 x-token GET 参数应使用 `X_TOKEN` 全局变量
