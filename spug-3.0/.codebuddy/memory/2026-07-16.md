### 关键设计决策
1. **存储路径**：`storage/documents/regulation/{regulation_id}/{yyyy}/{mm}/{uuid_filename}`，DB 存相对路径 `regulation/...`
2. **安全校验**：删除前 `is_safe_path(regulation_base, abs_path)` 校验路径在 regulation/ 子目录内
3. **权限**：view/add/edit/delete/upload/download/category_manage，不再用 require_supper
4. **迁移重建**：旧 0001_initial 已 fake 回滚 → 手动 DROP TABLE → 重新 migrate（模块全新无生产数据）
5. **is_leaf 维护**：后端自动维护（新建子分类设父非叶子；删除最后子分类恢复父叶子），前端不再可手动编辑

### 测试教训
- `access_token` 必须 32 字符，`token_expired` 必须设未来时间戳
- 测试 URL 用 `/regulation/` 不带 `/api/` 前缀（nginx 会 strip `/api/`）
- `@auth` 装饰器返回 HTTP 200 + error 字段（不是 403），测试要检查 `resp.json()['error']`
- `AppSetting.set('bind_ip', False)` 禁用 IP 绑定
