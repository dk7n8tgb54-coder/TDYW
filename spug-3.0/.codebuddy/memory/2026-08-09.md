### 完整回归测试修复记录（5 个问题）

1. **T13 冷却期问题**: `file.delete()` 失败时 `DocumentFileDeleteMixin` 设置 `last_clean_attempt=now()`，`retry_clean_pending_files` 有 3600s 冷却期会跳过。修复：调用 retry 前重置 `last_clean_attempt=None`。

2. **T14 Celery 任务名错误**: Celery 任务是 `merge_file_chunks`（`@shared_task(bind=True)`），不是 `merge_chunks`（后者是 `ChunkMerger` 类的方法）。修复：patch 目标和 import 改为 `merge_file_chunks`。

3. **T17 幂等测试重写**: 原测试直接调用 Celery 任务（签名 `merge_file_chunks(self, job_data)` 9 参数不匹配）。改为通过 API `/document/direct_merge/` 测试：创建 COMPLETED transfer + 文件记录，POST 请求验证 `is_idempotent=True`。

4. **T17 模型字段错误**: `DocumentFilePrivate` 没有 `file_hash` 字段；`folder` 是 ForeignKey 不能用 `folder_id=` 传参。修复：去掉 `file_hash`，改 `folder=folder`。

5. **T19 枚举值修正**: `TransferStatus.CALCULATING` 不存在（实际有 PENDING/UPLOADING/DOWNLOADING/PAUSED/MERGING/COPYING/COMPLETED/FAILED/CANCELED）；`FAILED` 不是终态（允许重试到 UPLOADING/DOWNLOADING/COPYING/CANCELED）。修复：移除 CALCULATING，从终态列表移除 FAILED。
