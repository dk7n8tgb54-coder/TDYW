# 2026-07-27

## 修复登录页 import 相对路径错误（构建失败）

### 现象
Docker frontend-builder 构建报错：
```
./src/pages/login/index.js
Cannot find file '../routes' in './src/pages/login'.
```

### 根因
2026-07-26 给工作台菜单加 auth 时，在 `spug_web/src/pages/login/index.js` 引入 `routes` 写成了 `import routes from '../routes'`，少了一层。

路径推算：`src/pages/login/index.js` → 上一层 `src/pages/` → 再上一层 `src/` → `routes.js` 在 `src/routes.js`，所以正确写法是 `../../routes`。

### 修复
`spug_web/src/pages/login/index.js`：`'../routes'` → `'../../routes'`

### 验证
- `fs.existsSync('src/pages/login/../../routes.js')` → true
- @babel/parser 语法 OK
- read_lints 0 错误

### 教训
- **改完代码必须本地构建验证一次**，不能只靠 Babel parser 语法检查（语法对≠路径对）。Babel parser 不解析 import 路径，所以路径错误溜过去了
- Windows 本地没装 node_modules 跑不了 `npm run build`，但可以用 `node -e "require.resolve('...')"` 或 `fs.existsSync` 验证相对路径
- 项目内 import 路径校验应纳入 post-write-verification 流程：相对路径必须手动算层数验证
