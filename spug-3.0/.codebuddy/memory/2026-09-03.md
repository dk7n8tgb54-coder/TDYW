## ⚠️ 重要框架事实：Django 会截断超长上传文件名（预防再次误报）
- `django/core/files/uploadedfile.py:57-61`，`UploadedFile.__init__`：
  `if len(name) > 255: ext=splitext; name = name[:255-len(ext)] + ext` —— **保留扩展名**
- 后果：**视图收到的 `file.name` 恒 ≤255 字符**，无需也不应该在业务层校验文件名长度
- 因此"上传 304 字符文件名 → original_name 静默截断"是**框架归一化，不是 MySQL 静默砍尾**，原 REG-VALID-001 定性为误报并撤销
- 实测：`SimpleUploadedFile('a'*300+'.pdf').name` 长度就是 255；直接 ORM 写 304 字符才报 DataError（因为绕过了 UploadedFile）
- 教训：**"文件名长度上限"必须以字节为单位**，字符数仅对 ASCII 成立；定级缺陷前先量化触发条件与影响面
