## 干扰模块导出：ZIP 打包（Excel + 原始附件）+ 原图嵌入

### 背景
用户反馈"缩略图根本看不清嵌入了的白"，要求要么不嵌入、要么嵌入原图。同时希望导出能把图片和文档都纳进去。

### 方案
- **有附件时**导出 ZIP：`干扰信息统计_xxx.zip`
  - `干扰信息统计_xxx.xlsx` — 列表 + 嵌入第一张图片原图（非缩略图）
  - `附件/001_频率xxx_汇报科室A/` — 该记录的所有原始附件文件（图片+文档）
- **无附件时**导出纯 Excel（兼容原有行为）

### 改动（1 文件）
| 文件 | 改动 |
|---|---|
| `spug_api/apps/interference/exporters.py` | 重写：原图嵌入（不重新编码，读取原始 bytes）；ZIP 打包（Excel + 附件目录树）；按 `{序号:03d}_{频率}_{汇报科室}` 组织附件文件夹 |

### 关键设计决策
1. **原图嵌入**：直接 `open(f, 'rb').read()` 读取原始文件数据，不通过 PIL 重新编码。PIL 仅用于获取原始尺寸计算显示比例
2. **显示尺寸**：按原始比例缩放到 480x360 以内（Excel 显示用），嵌入的是完整原图数据（可放大查看）
3. **行高自适应**：`row_height = display_height * 0.75 + 5`（px->point 转换）
4. **大图跳过**：超过 10MB 的图片跳过 Excel 嵌入（避免 Excel 过大），但仍包含在 ZIP 中
5. **嵌入上限**：最多嵌入 50 张图片到 Excel（`MAX_EMBED_IMAGES`），全部附件仍打包到 ZIP
6. **文件夹名清理**：`_sanitize_zip_name()` 替换 Windows 非法字符 `/\:*?"<>|`
7. **重名处理**：同一文件夹内同名文件加 `_1`, `_2` 后缀
8. **N+1 优化**：`object_id__in=record_ids` 批量查询，`defaultdict(list)` 按 object_id 分组
