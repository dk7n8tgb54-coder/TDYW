## 关键接口事实（已对照视图源码核实）
- 登录：`POST /api/account/login/` JSON `{username,password,type}` → token 在 `data.access_token`；login 有限流（IP 1h≥30 失败拒绝，用户 15min≥5 失败锁 15min），**只用正确密码才安全**。
- 文件夹：`POST /api/document/folder/` JSON `{name,parent_id,is_public}`；`DELETE ?id=&is_public=`。
- 普通上传：`POST /api/document/upload/` multipart `folder_id`+`is_public`（**不是 parent_id**）。
- 分片：`POST /api/document/upload_chunk/` multipart `{file_name,file_size,chunk_index,total_chunks,file_hash,folder_id,is_public}`+FILE（**不传 transfer_id**，目录按 file_hash+user 隔离）。
- 合并：`POST /api/document/merge_chunks/` JSON `{file_name,file_size,total_chunks,file_hash,folder_id,is_public}`（字段是 **folder_id 不是 parent_id**），返回 `task_id`，异步 Celery 落地。
- 回收站接口 2026-06-23 已移除，任何脚本都不可再出现 `/recycle-bin/*`。

## PowerShell → Docker 操作坑（本机 docker 在 WSL）
- PowerShell 不支持 `<` 重定向、会拦截 `|`、`<` 报“保留运算符”。
- 容器内需读文件给 `manage.py shell`：用 `docker exec 容器 cat /tmp/x.py | docker exec -i 容器 python .../manage.py shell`（cat 在容器内执行）。
- 复制宿主机文件进容器用 WSL 路径：`docker cp /mnt/e/TDYW/.../file 容器:/tmp/file`（Windows 反斜杠路径 `docker cp` 会报 “copying between containers”）。
- 命令里避免出现 `<` / `|` / 圆括号 / 内层单引号（会被 bash -c 包裹破坏）；`-c` 参数用绝对路径。
