### 关键设计

1. **复用 thumbnail_service**：`generate_document_thumbnail` 内部调用 `generate_thumbnail_for_file`，不重写图片处理逻辑。
2. **transaction.on_commit**：保证事务提交后才投递任务，避免任务查不到文件记录。auto-commit 模式下回调立即执行，行为无变化。
3. **软删除安全**：`FileModel.objects` 默认是 `SoftDeletedManager`，已删除文件查不到，任务自动安全退出。
4. **幂等保护**：任务内检查 `thumbnail_path` 已存在则跳过。
5. **失败隔离**：缩略图生成失败只记日志，不重试（图片损坏重试无意义）；数据库更新失败才重试。
6. **投递函数独立**：`_dispatch_thumbnail_task` 独立成函数，延迟 import 任务模块，避免 on_commit lambda 闭包内重 import。
