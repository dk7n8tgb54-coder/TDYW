### Bug 修复：详情态看不到上传按钮（21:25）
- 现象：用户反馈"没看到上传按钮"。
- 根因：`radioLicense/Form.js` 详情态 `AttachmentManager` 传了 `readOnly={viewMode}`，而详情态 `viewMode` 恒为 true → `canUpload=false`，上传/删除按钮被隐藏。
- 关键认知：详情态只读的应是执照字段（Descriptions），附件区必须可交互；附件按钮可见性已由 `uploadPerm/deletePerm` 的 `hasPermission` 内部控制，无需外部 readOnly。
- 权限树确认：`system/role/codes.js` 已注册 `radio_license.attachment.upload/download`（附件管理页），普通角色可分配；超管 `has_perms` 直接放行。
- 修复：`readOnly={viewMode}` → `readOnly={false}`。ESLint 0 errors。
