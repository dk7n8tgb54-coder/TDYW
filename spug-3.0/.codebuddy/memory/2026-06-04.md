## 运行日志事件类型管理功能

### 问题诊断
- `view_utils.py` 缺少 `is_safe_path` 导出，导致 `views/base.py` 导入报错
- `EventTypeConfig` 模型定义缺少 `models.Model` 继承，导致 `'NoneType' object has no attribute '_meta'` 运行时错误

### 修复内容
1. `spug_api/apps/document/libs/view_utils.py` - 添加 `from ..libs.document_utils import is_safe_path` 重新导出
2. `spug_api/apps/runlog/models.py` - `EventTypeConfig` 类添加 `models.Model` 继承：`class EventTypeConfig(models.Model, TenantModelMixin):`

### 新增功能：事件类型管理界面
因为之前只实现了后端 API 和表单下拉框，没有管理界面，新增：

1. **前端新增文件** `spug_web/src/pages/runlog/EventTypeModal.js` - 事件类型管理弹窗组件，支持：
   - 查看所有事件类型列表
   - 添加新事件类型
   - 编辑已有事件类型（名称、颜色、排序）
   - 删除/停用事件类型（软删除）

2. **store.js 更新** - 添加事件类型管理相关状态和方法：
   - `eventTypeModalVisible` - 弹窗可见性
   - `showEventTypeModal()` / `hideEventTypeModal()`
   - `addEventType()` / `updateEventType()` / `deleteEventType()`

3. **Table.js 更新** - 在工具栏添加"类型管理"按钮

### 关键教训
- Django 模型必须同时继承 `models.Model` 和 `TenantModelMixin`，缺一不可
- `TenantModelMixin` 只提供租户隔离逻辑，不提供 Django 模型核心功能
