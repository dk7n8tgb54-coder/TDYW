3. **团队并行**：3 个 code-explorer worker 分别处理视图/服务+任务/前端，主线程处理 libs+模型+迁移+测试
4. **tenant_id 差异**：`DocumentFolderPrivate` 有 `tenant_id`，`DocumentFolderPublic` 没有，测试需移除 `tenant_id='admin'` 参数
5. **DocumentTransfer.is_public 保留**：避免数据库迁移，字段改为 default=True 但不删除
