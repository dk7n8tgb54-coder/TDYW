## 资料库单文件大小限制 100MB

### 背景
用户要求设置单个文件最大 100MB 限制。现有架构已支持文件大小限制（后端 `_get_max_file_size()` + `validate_file_upload()`），但前端 `MAX_FILE_SIZE` 常量定义后从未被用于校验。

### 执行内容
1. **改 2 个常量**（用户说的核心改动）：
   - 后端 `constants.py`：`DEFAULT_MAX_FILE_SIZE` 10GB→100MB
   - 前端 `upload.js`：`MAX_FILE_SIZE` 10GB→100MB
2. **后端硬编码 "10GB" 消息改为动态**（AGENTS.md 要求：同字符串≥3处抽出）：
   - 新增 `format_file_size()` helper in `constants.py`
   - `validators.py`/`merge.py`/`merge_orchestrator.py`：`'文件大小超出限制（最大10GB）'` → `f'...最大{format_file_size(max_file_size)}）'`
   - `upload.py`：`max_file_size=10*1024*1024*1024` → `max_file_size=DEFAULT_MAX_FILE_SIZE`
   - `merge_orchestrator.py`：2 处 `10*1024*1024*1024` → `DEFAULT_MAX_FILE_SIZE`
3. **前端文件大小校验**（原架构缺失，MAX_FILE_SIZE 定义但未使用）：
   - `upload-utils.js`：新增 `formatMaxFileSizeDisplay()` + `validateFileSize(file)`
   - `FileUploadCoordinator.handleFileSelect`：超限文件收集到 `oversizedFiles`，红色错误提示
   - `folderUpload._validateFiles`：超限文件归入 `invalidFiles`
4. **3 处标注**：
   - 上传面板标题栏右侧灰色小字「单个文件最大 100MB」
   - 拖拽区域底部灰色提示「支持单文件最大 100MB」
   - 超限拒绝红色错误「文件超过 100MB 限制，无法上传」

### 验证结果
- py_compile 全部通过

- 前端 lint 0 错误（仅预存 HINT）
- 回归测试 14/14 通过（2.2s）
