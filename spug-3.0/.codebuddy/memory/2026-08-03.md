## 铃铛永远加载 + 告警列表条数少 修复

**用户澄清**：两个问题都是关于铃铛/系统告警，不是操作日志。
**注意**：第一轮编辑未实际写入文件，第二轮重新编辑才生效，已通过 read_file 验证。

**问题 1 - 铃铛一直在加载中 + 有时候刷新完不显示（P0）**：
- 根因：`layout/Header.js` 是普通函数组件，直接读取了 `AlertStore` 的 MobX observable（`loading`/`recentAlerts`/`unreadCount`），但**没有用 `observer` 包裹**
- 触发流程：用户点铃铛 -> `setBellOpen(true)` -> 组件重渲染 -> `loading=true`（刚被 fetchRecent 设置）-> Spin 显示 -> API 完成 `loading=false` -> 但无 observer 不触发重渲染 -> Spin 永远不停
- "有时候刷新完不显示"：同理，fetchRecent 完成后 loading=false 但组件不重渲染
- 修复：`import { observer } from 'mobx-react'` + `export default observer(function (props) { ... })`

**问题 2 - 铃铛只显示七八条（轮询竞态）**：
- `AlertStore.fetch()`（30 秒轮询）用 `page_size=5`
- `AlertStore.fetchRecent()`（点开铃铛）用 `page_size=20`
- `fetchRecent` 拿回 20 条后，30 秒后 `fetch` 只拿 5 条覆盖掉，列表条数缩水
- 修复：
  1. `fetch()` 的 `page_size` 从 5 改为 20（统一常量 `FETCH_PAGE_SIZE`）
  2. 加 `if (!this.loading)` 守卫：铃铛加载中时轮询不覆盖 `recentAlerts`，但仍更新 `unreadCount`/`errorCount`

**告警数据量说明**：DB 里只有 7-8 条告警是正常数据量（系统健康则少告警）。告警由 Celery 生成（磁盘 10 分钟/次、DB 5 分钟/次），有冷却去重（5-30 分钟同 `alert_key` 不重复）。告警页面 (`/maintenance/alert`) 本身有 observer + pageSize=20，无默认过滤，显示的就是 DB 里的实际数量。

**顺手改进（audit/index.js）**：筛选切换时未重置页码 + 90 天默认过滤提示 Tag。

## 告警页面刷新后空表修复（同一根因第三次）

**问题**：系统告警页面 (`/maintenance/alert`) 刷新后空表，切换菜单再切回来才显示。

**根因**：`pages/system/alert/index.js` 中 `AlertTable` 是普通函数组件，读取了 `store.records`/`store.isFetching`/`store.summary`/`store.total` 等 MobX observable，但**没有 `observer` 包裹**。父组件 `AlertIndex` 有 `observer` 但不直接读这些字段，所以 `fetchRecords` 完成后不触发重渲染。

**修复**：`AlertTable` 加 `observer` 包裹。

**教训（重要模式）**：直接读取 MobX observable 的组件**必须**用 `observer` 包裹，否则数据更新后不触发重渲染。本轮三次修复都是同一根因：
1. `Header.js` - 铃铛永远加载
2. `AlertStore.js` - 轮询竞态
3. `alert/index.js` - 告警页面刷新空表

## 数据分析 Tab 无响应修复

**问题**：点击 Tab 菜单无反应。
**根因**：所有读取 `store` observable（`activeTab`/`tabData`/`tabFetching`）的组件缺少 `observer` 包裹，MobX 变更不触发重渲染。
**修复**：6 个文件全部加 `observer`：
- `index.js`：`function DataAnalysisIndex() {...}` -> `export default observer(DataAnalysisIndex)`
- 5 个页面（Overview/FaultAnalysis/InterferenceAnalysis/DeviceAnalysis/UpgradeAnalysis）：`export default observer(function Xxx() {...});`
- 注意 `observer(function() {...})` 需要闭合 `)` + `;`
**教训**：MobX 项目中凡读取 `@observable` 的组件必须用 `observer` 包裹，否则 UI 不响应 store 变更
