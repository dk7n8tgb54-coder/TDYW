### 关键技术经验
- **前端使用 `createBrowserHistory()`**，不是 hash 路由。路由路径是 `/home` 而非 `/#/home`
- **antd Button 中文文字有空格**：`getByRole('button', { name: /登\s*录/ })` 而非 `'登录'`
- **登录 API**：POST `/api/account/login/`，JSON body `{username, password, type: "default"}`
- **认证机制**：token 存 sessionStorage `token`，请求头 `X-Token`，`updatePermissions()` 在 `index.js` 模块加载时调用
- **injectAuth 方法**：`page.addInitScript()` 设置 sessionStorage 后 `page.goto('/home')` 可免 UI 登录
- **未认证用户访问受保护路由**：渲染空 Layout（无菜单/无内容），不重定向到 `/`。API 调用仍需 Token，功能上等同拒绝访问
