🔒 TDYW 证书安装

安装根证书以信任 TDYW 内部系统

下载根证书

下载后根据下方说明安装到您的系统

🚀 Windows 一键安装（推荐）

如果您是 Windows 用户，可以下载以下脚本，右键以管理员身份运行：

下载安装脚本
1

下载证书

点击上方"下载根证书"按钮，保存 ca.crt 文件

2

安装证书

双击下载的 ca.crt 文件，选择"安装证书" → "本地计算机" → "将所有证书放入下列存储" → "受信任的根证书颁发机构"

3

重启浏览器

完全关闭并重新打开浏览器，访问 https://192.168.1.49:8443

1

下载证书

点击上方"下载根证书"按钮，保存 ca.crt 文件

2

安装证书

双击 ca.crt 文件，在"钥匙串访问"中找到该证书，双击后设置为"始终信任"

3

命令行安装（可选）

sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain ca.crt

1

Ubuntu/Debian

sudo cp ca.crt /usr/local/share/ca-certificates/tdyw-ca.crt
sudo update-ca-certificates

2

CentOS/RHEL

sudo cp ca.crt /etc/pki/ca-trust/source/anchors/
sudo update-ca-trust

1

iOS (iPhone/iPad)

下载证书后，前往"设置 → 通用 → VPN与设备管理"，安装描述文件，然后在"关于本机 → 证书信任设置"中启用完全信任

2

Android

下载证书后，前往"设置 → 安全 → 加密与凭证 → 安装证书"，选择"CA证书"，找到下载的文件安装

⚠️ 注意事项

安装此证书后，您的浏览器将信任由此 CA 签名的所有证书。请勿将此证书安装到公共或不受信任的设备上。
