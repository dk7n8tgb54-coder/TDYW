# 证书文件结构说明

## certs 文件夹结构

```
certs/
│
├── ca/                          # 【根证书CA】私有的证书颁发机构
│   ├── ca.crt                  # 根证书公钥（需要分发给客户端信任）
│   ├── ca.key                  # 根证书私钥（绝密，用于签发服务器证书）
│   └── ca.srl                  # 序列号文件（CA内部使用）
│
├── prod/                        # 【生产环境】服务器证书（已挂载到Nginx）
│   ├── spug.crt                # 服务器证书（由ca签发）
│   └── spug.key                # 服务器私钥（绝密）
│
├── dev/                         # 【开发环境】服务器证书
│   ├── spug.crt
│   └── spug.key
│
└── client-dist/                 # 【客户端】证书安装包
    ├── ca.crt                  # 根证书副本（用于客户端安装）
    ├── install-ca.bat          # Windows 安装脚本
    ├── uninstall-ca.bat        # Windows 卸载脚本
    └── README.md               # 安装说明
```

## 证书层级关系

```
┌─────────────────────────────────────────────┐
│           根证书 (CA)                        │
│  ca/ca.crt  ←→  ca/ca.key                   │
│      ↓                                       │
│   签发                                      │
│      ↓                                       │
│  ┌──────────────────────────────────────┐  │
│  │   服务器证书                          │  │
│  │  prod/spug.crt  ←→  prod/spug.key    │  │
│  │  dev/spug.crt   ←→  dev/spug.key     │  │
│  └──────────────────────────────────────┘  │
└─────────────────────────────────────────────┘
```

## 各文件作用

### 1. 根证书（ca/）
- **ca.crt**：客户端需要信任的根证书
- **ca.key**：签发服务器证书的密钥，必须严格保密
- **ca.srl**：证书序列号记录，CA内部使用

### 2. 服务器证书
- **spug.crt**：Nginx配置的SSL证书，发给浏览器
- **spug.key**：服务器私钥，用于解密通信
- 两个环境：prod（生产）、dev（开发）

### 3. 客户端安装包（client-dist/）
- 包含根证书副本和安装脚本
- 用于让客户端浏览器信任你的证书
- 支持Windows自动安装/卸载

## 信任链

```
浏览器验证：
spug.crt
  └─ 由 ca.crt 签发
      └─ 是否已安装到系统？
          ├─ 是 → 显示绿色锁 🔒
          └─ 否 → 显示警告 ⚠️
```

## 使用流程

### 服务端配置
1. 使用 `prod/spug.crt` 和 `prod/spug.key` 配置 Nginx
2. 在 docker-compose.yml 中挂载：
   ```yaml
   volumes:
     - ./certs/prod:/etc/nginx/ssl:ro
   ```

### 客户端配置
1. 分发 `client-dist/` 文件夹给所有内网用户
2. 运行 `install-ca.bat` 安装根证书
3. 重启浏览器，访问 `https://你的域名`

### 更新证书
当证书过期时：
1. 使用 `ca/key` 重新签发服务器证书
2. 替换 `prod/spug.crt` 和 `prod/spug.key`
3. 重启服务

## 安全注意事项

- **ca.key** 和 **spug.key** 必须严格保密，绝不能泄露
- 不要提交到版本控制系统
- 定期更新证书
- 定期轮换密钥

## 证书类型说明

- **自签名证书**：内网使用，需要客户端信任根证书
- **CA签名证书**：公网使用，浏览器自动信任
- 当前使用的是自签名证书方案，适合内网生产环境
